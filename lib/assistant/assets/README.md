Moaon Briefing Medium is a static weight-500 instance derived from the repository's
desktop/ui/fonts/PretendardVariable.ttf using fontTools 4.60.1 varLib.instancer.
Font family/name records were renamed to Moaon Briefing to respect the original
reserved font names. Original copyrights and the SIL Open Font License are in
OFL.txt. This font is bundled server-side for deterministic Korean PNG rendering;
no runtime font download or browser dependency is required.
