# 25단계 키워드 작업대 운영 검증·복구 기록

25단계는 네이버 직접 입찰 운영과 쿠팡 WING 수동 적용 작업표를 서로 분리한 상태로 인수한다. 운영 인수 검사는 네이버 캠페인·광고그룹·키워드·성과·공식 예상 자료를 읽기 전용으로 확인하며 실제 입찰가는 변경하지 않는다.

## 정상 운영 기준

- 고정 운영 주소는 `https://harin-cafe24-sync.vercel.app/`이다.
- 네이버 등록 키워드 화면에는 네이버 자료만 표시하고 쿠팡 자료나 쓰기 경로를 섞지 않는다.
- 인수 검사는 캠페인·광고그룹·키워드·성과·공식 예상 자료를 읽되 실제 입찰 변경 요청은 보내지 않는다.
- 실제 입찰 변경은 기존 `확인창 → 현재값 재조회 → 네이버 반영 → 반영값 재조회 → 기록` 흐름에서만 실행한다.
- 마지막 핵심 읽기 검사가 24시간을 지나면 `운영 사용 가능`으로 꾸미지 않고 `다시 확인 필요`로 표시한다.
- 390px·430px 모바일과 데스크톱에서 선택 상세·닫기·행 초점 복귀가 정상 동작해야 한다.

## 복구 경계

- 25-9 직전 정상 태그: `v1.38.67`
- 25-9에는 Supabase 스키마 변경이 없으므로 **데이터베이스 되돌리기 불필요**
- 문제가 있으면 애플리케이션만 직전 태그로 복구하고 기존 입찰 변경·검증·복구 기록은 보존한다.
- 운영 복구 뒤 네이버 읽기 검사와 고정 운영 주소를 다시 확인한다.

## 복구 명령

```powershell
git fetch --tags origin
git checkout v1.38.67
pnpm test
pnpm build
pnpm dlx vercel@58.9.4 --prod --yes
```

## 복구 후 확인

1. 고정 운영 주소가 열리는지 확인한다.
2. `/keywords/registered?platform=naver`에서 네이버 전용 자료만 표시되는지 확인한다.
3. 실계정 읽기 검사를 실행하고 실제 입찰가가 바뀌지 않았는지 확인한다.
4. 선택 상세·닫기·모바일 초점 복귀와 기존 변경 기록이 유지되는지 확인한다.
