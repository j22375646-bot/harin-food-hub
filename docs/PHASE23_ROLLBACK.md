# 23단계 운영 검증·복구 기록

23단계는 기존 V8 파스텔 화면을 유지하면서 페이지별 데이터 로더, 즉시 변경 반영, 고밀도 목록 제한, 인사이트 작업대와 연결 API 자동화를 정리한 애플리케이션 변경입니다.

## 정상 운영 기준

- 고정 운영 주소: `https://harin-cafe24-sync.vercel.app/`
- 일반 화면의 서버 자료 준비 목표는 2.5초, 키워드·원인 분석은 4초입니다.
- 메뉴 클릭 즉시 선택 상태와 부분 로딩 리본이 표시되고 전체 화면 로딩으로 바뀌지 않습니다.
- 390px·430px 모바일과 데스크톱에서 가로 넘침 없이 주요 버튼을 누를 수 있습니다.
- 네이버·쿠팡 키워드 자료와 변경 경로는 서로 섞이지 않습니다.
- 한 공급자 호출이 실패해도 성공한 채널과 이전 성공 자료는 유지됩니다.

## 복구 경계

- 23-8 직전 정상 태그는 `v1.37.28`입니다.
- 23-8에는 Supabase 스키마 변경이 없으므로 데이터베이스 되돌리기 불필요합니다.
- 화면 전환, 모바일 배치 또는 클라이언트 계측 문제가 생기면 운영 데이터는 유지하고 애플리케이션만 직전 태그로 다시 배포합니다.

```powershell
git fetch --tags origin
git checkout v1.37.28
pnpm test
pnpm build
pnpm dlx vercel@58.9.4 --prod --yes
```

복구 뒤 `X-Harin-Version`, 로그인, 메인, 주문, 재고, 인사이트, 키워드, 상품, 데이터수집과 고정 운영 주소를 확인합니다. 외부 플랫폼 변경 기록과 실패 재시도 이력은 삭제하지 않습니다.
