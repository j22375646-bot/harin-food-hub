# Phase 28 메인 화면 수용 기준

## 적용 원칙

Phase 28 메인은 새 서비스나 별도 미리보기 주소를 만들지 않고 현재 허브의 `/` 주소를 유지한다. 인증, 서버 데이터 적재, 매출 계산, 채널 분리, 작업 이력은 기존 구현을 그대로 사용하고 표시 전용 어댑터만 추가한다.

코드가 병합돼도 기본값에서는 기존 메인이 계속 표시된다. 새 메인은 서버가 직렬화한 런타임 설정에서 `home`이 활성화되고, 메인 어댑터가 정상적인 ViewModel을 만든 요청에만 렌더링한다. 둘 중 하나라도 실패하면 기존 메인으로 돌아간다.

## 승인된 환경에서만 사용하는 페이지 단위 활성화

```dotenv
HARIN_PHASE28_ENABLED=true
HARIN_PHASE28_PAGES=home
```

위 설정은 승인된 검증 환경에서 데스크톱, 430px, 390px 화면과 실제 로그인 데이터를 확인할 때만 사용한다. 저장소에 비밀값이나 운영 환경 파일을 커밋하지 않는다.

## 검증

```powershell
pnpm verify:phase28-main
pnpm test
pnpm build
```

- 메인 ViewModel은 누락된 금액을 0으로 만들지 않는다.
- 확인된 숫자 0은 정상 값으로 유지한다.
- 제목 밑줄, 44px 컨트롤, 균형 잡힌 선택 상태, 우측 보조석 전환, 모션 축소 설정을 확인한다.
- 기존 메인 테스트를 함께 실행해 기능 플래그가 꺼진 폴백을 보존한다.
- `home` 어댑터가 준비돼도 전체 `cutover: BLOCKED`가 정상이다. 주문·CS 등 나머지 어댑터와 `/product-analysis` 운영 라우트가 아직 남아 있기 때문이다.

## 롤백

문제가 있으면 다음 설정으로 즉시 기존 메인만 표시한다.

```dotenv
HARIN_PHASE28_ENABLED=false
```

또는 `HARIN_PHASE28_PAGES`에서 `home`을 제거한다. 롤백은 `/` 주소, 인증, 데이터, 주문·CS 작업 기록, 계산 결과를 삭제하거나 변경하지 않는다.
