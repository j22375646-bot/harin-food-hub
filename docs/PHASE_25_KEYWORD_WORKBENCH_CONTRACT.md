# 25단계 키워드 작업대 기능 보존 계약

25단계는 기존 기능을 다시 만드는 단계가 아니다. 24단계까지 검증한 네이버 직접 입찰 운영과 쿠팡 WING 수동 작업을 보존하면서, 한 화면에서 더 빨리 찾고 비교하고 변경하도록 배치를 재구성한다.

## 25-0 기준선

- 기준 소스: `05c20cb` (`v1.38.55`)
- 기준 테스트: `991/991` 통과
- UI 기준: 기존 V8 파스텔 색상·글자 토큰·버튼 규격 유지
- 화면 문맥 소유자: `KeywordOwnerShell` 한 곳
- 운영 원칙: 네이버와 쿠팡의 데이터·선택 상태·쓰기 경로는 합치지 않음
- 표시 원칙: 누락·오래된 값은 `0`으로 꾸미지 않고 `판단 보류` 또는 `확인 필요`로 표시

## 그대로 유지하는 기능

### 네이버

- 현재 입찰가 조회와 직접 변경
- 변경폭·예산·목표 ROAS 안전 규칙
- 광고그룹별 자동입찰 예약과 긴급 중지
- 실행 직전 현재값 재조회, 반영 뒤 일치 검증
- 변경·복구·검증 기록
- 일별 평균순위, 목표 적중률, 경쟁 신호
- 검색·필터·정렬·페이지 나누기·현재 보기 CSV
- 네이버 실제 검색 결과 확인

### 쿠팡

- 쿠팡 전용 WING 수동 적용 작업표
- 쿠팡 데이터를 네이버 표와 쓰기 경로에 섞지 않는 잠금
- 자동 입찰 쓰기를 지원하는 것처럼 표시하지 않는 안내

### 공통

- 현재 화면 선택, 검색 결과 전체선택, 선택 해제
- 페이지별 키워드 AI 분석
- 기존 도구와 연결 상태는 기본 접힘 보조 영역으로 유지

## 제외하는 기능

- 다중 사용자 초대·역할·권한 관리
- 여러 광고계정을 전환하는 계정 관리
- 쿠팡 키워드를 네이버 자동 입찰 표에 합치는 기능
- 변경승인 전용 페이지의 부활

사장님 실행은 한 번의 명확한 확인창 뒤 진행한다. 확인창을 줄여도 실행 전 최신값 재조회, 중복 실행 방지, 변경 이력, 실패 복구, 오래된 데이터 잠금은 유지한다.

## 25-0 화면 정리

- 키워드 제목·플랫폼·작업공간·채널 분리 안내는 상단 `KeywordOwnerShell`에서만 표시한다.
- 하단 운영표가 반복하던 두 번째 설명 띠는 제거한다.
- 광고그룹 작업대, 도구막대, 일괄선택, 표, 상세 패널, 안전설정, 예약, 기록, 기존 도구 접기 영역은 그대로 유지한다.
