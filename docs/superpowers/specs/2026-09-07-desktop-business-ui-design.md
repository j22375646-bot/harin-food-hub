# Windows 사업장 허브 앱 UI 기획안

작성일: 2026-09-07. 디자인 방향 제안이며 구현된 화면/확정 시안이 아니다.

## 1. 범위

기존 Phase28 공통 UI와 검증된 업무 기능을 재사용한다. 오늘·주문·CS를 고정 참조로 삼아 앱 상단/사업장 선택/여백/우측 상세/연결 설정을 조정한다. 기존 데이터 계산·송장·답변 전송 규칙을 외관 변경과 함께 재작성하지 않는다. 모바일 앱과 새 모바일 시안은 제외한다. 기존 웹의 좁은 창 대응은 퇴행시키지 않는다.

## 2. 첫 버전 화면 구조

```text
Windows 기본 창 컨트롤                         최소화 / 최대화 / 닫기
사업장: 듀모르 ▾  | 페이지 제목 | 업무 검색 | 연결 상태 | 사용자
왼쪽 업무 메뉴   | 본문 목록·작업 도구            | 선택 항목 상세
                 | 선택한 사업장 데이터만 표시    | 접기 / 펼치기
하단 상태 영역   | 마지막 수집 / 진행 작업 / 파일·인쇄 결과
```

초기에는 Windows 표준 창 컨트롤을 유지해 Snap/Alt+F4/드래그/접근성 회귀를 줄인다. 커스텀 타이틀바를 반드시 만들지는 않는다. 앱용 공통 상단에서 웹의 중복 로고/큰 소개 영역을 정리하되 메뉴와 핵심 설명은 보존한다. 앱 모드는 외관 분기일 뿐 인증·권한 신뢰 신호가 아니다.

## 3. 바꿀 것과 유지할 것

| 영역 | 앱용 변경 | 보존/안전 조건 |
|---|---|---|
| 상단 | 현재 사업장·개인 계정 명확히 분리 | 색뿐 아니라 이름/로고/계정 식별 표시 |
| 메뉴 | 업무 메뉴 유지, 설정에 사업장·연결·사용자·프린터 추가 | 기존 URL 호환, 권한은 API에서 재검증 |
| 본문 | 넓은 모니터의 좌우 여백 축소, 큰 소개문 축약 | 글자 크기를 줄여 억지로 밀어 넣지 않음 |
| 목록 | 선택 수/현재 필터/실행 버튼을 가까이 배치 | 가려진 행 포함 여부와 실제 대상 수 명시 |
| 우측 상세 | 기존 공통 패널 재사용, 충분한 폭과 접기 상태 | 긴 주소/상품명 줄바꿈, 페이지마다 별도 패널 규칙 금지 |
| 하단 작업 상태 | 수집·발급·출력·저장 상태를 같은 용어로 표시 | 진행률을 모르면 가짜 % 대신 현재 단계 |
| 브랜드 | 사업장 이름·검증된 이미지 로고 | 하린식품 문구의 무조건 전체 치환 금지; 과거 문서 발행자 보존 |
| 테마 | 라이트/다크, 기존 디자인 토큰 | 앱 초기/로그인/스켈레톤/오류/인쇄미리보기까지 검증 |

설정은 `내 계정`, `사업장 정보`, `멤버·권한`, `플랫폼 연결`, `자동화 상태`, `이 PC의 프린터`, `프로그램 정보`로 구분한다. 프린터는 PC 설정이고 발송인/반송지/배송 계약은 사업장 설정이다. 두 설정을 혼합 저장하지 않는다.

## 4. 첫 사용 흐름

로그인/초대 수락 → 접근 가능 사업장 선택 → 사업장 등록 → 플랫폼 연결 → 첫 수집 → 발송/원가 기준 → 홈.

- 한 사업장만 있으면 자동 진입하되 이름을 상시 표시한다.
- 연결 중 종료해도 인증정보 원문을 남기지 않고 완료한 설정 단계에서 재개한다.
- 연결하지 않은 플랫폼은 '연결 필요', 권한 일부만 있으면 가능한 기능/불가능한 기능을 각각 표시한다.
- 정상 0건, 아직 미수집, 권한 부족, 실패, 오래된 자료를 다른 상태로 표현한다.
- 샘플 모드가 필요하면 별도 표시와 분리된 가상 데이터만 사용하며 실사업장 화면에 자동 삽입하지 않는다.

## 5. 사업장 전환 UX

전환 메뉴에는 소속 사업장만 나온다. 기본은 한 창·한 활성 사업장이다. 두 사업장을 동시에 보이는 탭/비교 창은 1차 제외한다.

전환 시 순서:
1. 작성 중 내용·선택·진행 중 발급/인쇄 확인. 실행 중 위험 작업이 있으면 전환을 막고 결과 확인 화면 제공.
2. 저장하지 않은 편집은 취소/돌아가기 선택. 자동으로 다른 사업장에 저장하지 않음.
3. 기존 요청·구독·선택·상세·미리보기·사업장별 캐시를 해제하고 중립 전환 화면 표시.
4. 서버에서 새 멤버십 확인. 성공한 응답의 tenant가 선택 tenant와 같을 때만 새 화면 표시.
5. 늦게 도착한 이전 사업장의 응답·알림을 버림. 접근 불가면 사업장 선택으로 돌아감.

부모가 서로 다른 사업장의 주문이 일괄 실행 대상에 섞이면 버튼에서 조용히 제외하지 말고 요청 전체를 거부한다. 확인창에는 사업장·판매계정·대상 수·동작을 표시한다. 스냅샷 이후 주문 상태 변경은 서버에서 다시 검사한다.

## 6. 앱 작업 흐름

- Ctrl+K: 기존 검색 통합. 검색 결과도 사업장 범위 적용.
- Esc: 상세/모달 닫기. 작성 중 변경은 경고하고 위험 작업 취소로 오인하지 않게 함.
- Ctrl+P: 현재 문서의 출력 경로로 연결하되 새 송장 발급 동작을 실행하지 않음.
- Windows 닫기 버튼: 기본 종료. 자동 시작·트레이 상주 기본 OFF.
- 출력 대기/서버 전송/사용자 확인 필요를 구분. 프린터 전송 성공만으로 실물 출력 완료라 쓰지 않음.
- 잠금/로그아웃 후 OS 알림과 화면 미리보기에 고객정보가 남지 않게 점검.
- 재시작 시 UI 설정만 복원하고 미확정 외부 쓰기는 재실행하지 않음.

## 7. 검증할 시안과 순서

U1: 앱 기본창+로그인+사업장 선택.
U2: 오늘 화면+연결 안 된 신규 사업장+수집 중/실패/오래됨 상태.
U3: 주문·배송 목록+우측 상세+선택/발급/인쇄+사업장 전환 차단.
U4: 플랫폼 연결센터+권한 부족+키 교체+연결 해제.
U5: 고객·CS와 정산 페이지에 공통 규칙 적용.

먼저 인터랙티브 시안으로 검토하고 승인된 공통 변경만 확장한다. 이번 문서 작성에서는 시안을 생성하지 않았다. 색상만 달리한 스크린샷이 아니라 빈 상태/실패/권한 차이도 시안에 포함한다.

## 8. 디자인·접근성 완료 기준

100/125/150% 화면 배율, FHD/QHD와 실제 모니터, 창 최소 크기, 한글 IME, 긴 문자열, 마우스/키보드, 포커스 복귀, 스크린리더 이름, 고대비·동작 줄이기 설정을 확인한다. 1차 한국어 UI 기준이며 다국어 서비스는 범위 밖이다.

선택 표현은 균형 잡힌 전체 테두리/배경을 쓰고 한쪽 세로 강조띠를 새로 만들지 않는다. 기존 제목 밑줄 모션 시작 규칙과 읽기 쉬운 글자 크기를 유지한다. 모션은 조작 피드백에만 사용하고 데이터 표시를 늦추지 않는다.

합격: 같은 업무에서 선택 대상·금액·권한이 기존 기준과 일치하고, 현재 사업장·진행 작업·실패 원인이 식별되며, 좁은 창에서도 버튼/내용에 접근할 수 있음. 사업장 혼동·지워지지 않는 이전 데이터·가짜 성공 표시가 있으면 출시하지 않는다.
