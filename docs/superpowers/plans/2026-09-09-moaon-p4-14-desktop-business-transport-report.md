# P4-14 Windows 앱 사업장 목록 연결부

## 완료 범위

- 고정 운영 주소로만 GET하는 메인 프로세스 통신 추가. 기존 Electron 비공개 로그인 세션을 사용하며 쿠키를 화면에 전달하지 않는다.
- READY(빈 목록 포함), LOGIN_REQUIRED, FORBIDDEN, TIMEOUT, UNAVAILABLE, CANCELLED/DISCONNECTED 상태 분리.
- 최대 200건, 256KiB 응답 제한, 사업장 ID·역할·버전 검증, 중복 ID 거부, 필요한 필드만 반환.
- 15초 제한 및 연결 해제 시 진행 중 요청 취소. 해제 이전에 시작한 응답은 generation 검사로 폐기.
- preload와 신뢰된 메인 프레임 전용 무인자 IPC 연결. 임의 URL·사업장 인자는 받지 않음.
- 설치파일 포함 목록에 새 통신 모듈 등록.

## 검증

구현 전 누락 테스트 실패 확인 후 수정. desktop npm test 119개 통과, 실패/스킵 0. 기존 주문·송장 처리 검증 포함. 실제 운영 API 성공은 P4-13에서 확인했으나 이번 Electron 연결부의 운영 로그인 종단간 시험은 아직 하지 않았다.

## 아직 하지 않은 것

사업장 선택 화면 호출/표시, 다른 사업장 업무 조회, 새 EXE 빌드·설치·배포는 미실시. 기존 설치앱의 화면이나 버전은 바뀌지 않았다. 서버 변경·DB 이전·자원 구매는 없다.

## 다음 단계

앱 시작/로그인 후 목록을 요청해 선택 화면에 연결한다. 목록이 있어도 기존 하린식품 주문 연결을 다른 사업장에 재사용하지 않는다. 빈 목록·재시도·만료 화면을 검증한 뒤 버전 갱신과 EXE 설치 검증을 묶어 진행한다.
