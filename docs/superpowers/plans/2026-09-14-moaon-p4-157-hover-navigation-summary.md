# P4-157 · Hover·접힌 메뉴·분석 요약

## 변경

- 선택 상태와 별도로 hover 상태에 전체 1px 테두리/안쪽 보강선을 적용하고 행 이동을 제거했다. 실제 CSS hover를 CDP로 강제하여 검증하며 사용자의 마우스는 이동하지 않는다.
- Cafe24 채널 뱃지: 밝음 블루그레이, 다크 청회색 표면과 명확한 테두리. 보라색 선택 배경과 구분.
- 선택 주문 도구의 자동 발급·등록 버튼에서 고정 파란색을 제거하고 공통 보라색 토큰 적용. 발급 절차·승인·비활성 상태는 유지.
- 접힌 메뉴는 모든 텍스트/배지를 숨기고 단일 grid 셀에 아이콘을 중앙 배치. 활성 상태 장식이 아이콘 위치에 영향을 주지 않음.
- 분석 ‘이번 기간 살펴볼 점’: 네이버 광고 전환매출/광고비/전환율을 근거 → 변화 → 다음 행동으로 표시. 현재·이전 기간의 실제 수치와 날짜 표시. 전환율 변화는 %p, 금액 변화는 상대 증감률.
- 누락 기간·부분 자료·미확인 수치·금액 기준값0은 판단 보류. 원인/캠페인 기여를 만들어내지 않는다. 광고비 감소를 성과 개선으로 단정하지 않음. 기존 캠페인/키워드·규칙 진단 유지, 키워드 확인은 페이지 이동만 수행.

## 검증

- 순수 비교 규칙: 상승/하락, %p, 부분/누락/무한값/이전0 검사.
- 가시 격리 Electron: hover 테두리·Cafe24 대비·공통 버튼색, 접힘 활성 메뉴 중앙 오차1px 미만(1040/1440), 분석 3개 카드/부분자료3개 판단보류/초기화, 밝음·다크 700/1040/1440 PASS.
- 고객 자료·광고비·실주문 발급 변경 없음. 화면은 가상 원장으로 검증하며 실제 로그인 사용자 인수와 구분.
