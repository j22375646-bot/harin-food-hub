# P4-68 — 다중 상품 연결 조회 / 0.57.0

## 구현
- 한 마스터 상품/채널에 연결이 여러 개이면 전체 목록 오류를 내던 동작을 변경했다. 해당 채널만 수량·가격 확인을 보류하고 나머지 상품과 정상 채널은 계속 반환한다.
- 다중 연결의 수량·가격·대표 연결 번호·자료 시각은 null이며 UNKNOWN 상태다. 임의의 첫 연결을 선택하거나 합산하지 않는다.
- 상세에서 후보 상품명·외부 연결 번호·활성/비활성/확인 필요·네이버 광고 참고를 구분한다. 연결 검토 필요 필터와 후보 이름/번호 검색을 추가했다.
- 각 채널 후보는 최대 20개 표시하고 실제 전체 연결 건수를 따로 제공한다. 20개를 넘으면 표시 범위와 검색 범위를 명시한다. 활성 연결만 임의로 선택하거나 비활성 연결을 숨기지 않는다.
- 앱은 후보 개수/목록 길이/중복 식별자/필드 길이/활성 상태를 검증한다. 다중 연결인데 수량·대표 연결·가격이 확정되어 오는 모순된 응답은 거절한다.
- 기존 응답과 앱의 UNKNOWN 상태 계약을 유지한다. 연결 생성/삭제/변경은 추가하지 않았다.
