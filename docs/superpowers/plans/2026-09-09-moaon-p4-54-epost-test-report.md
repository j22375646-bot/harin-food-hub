# P4-54 / 0.38.5 송장 도구 정리와 우체국 실제 시험 접수

## 요청과 범위

프린터 없이 송장 API를 검증한다. 사용자가 승인한 합성 시험 주문 1건만 사용하며 실제 고객 주문을 시험 대상으로 바꾸지 않는다. 프린터 실물 검증은 별도 작업이며 API 검증의 선행 조건이 아니다.

## 앱 변경

- 별도 로그인 창의 기본 제목 표시줄을 숨기고 창 이동 영역과 최소화·최대화·닫기를 유지했다.
- 송장·출력 도구를 접지 않고 바로 표시한다.
- 등록된 송장의 미리보기·인쇄 버튼을 앞에 배치했다.
- `저장 주문 다시 확인`을 하단의 선택적 `주문 정보 새로고침`으로 변경했다. 사용자가 먼저 누를 필요는 없다. 발급 직전 서버의 취소·주소·중복 송장 확인은 유지한다.
- 배송정보·추가정보·출고 확인 영역의 중복 구분선을 줄였다.

## 검증 구분

- 실제 외부 API: 우체국 시험 접수 성공.
- 로컬 단위: 앱 230개, 서버 송장·출고 관련 27개 통과.
- 로컬 UI: 로그인, 발급, 미리보기, 주문 도구, 새로고침·변경 목록 무효화, 자동 발급·등록, 단건·다건 등록 검증. 플랫폼 응답은 합성이므로 실제 플랫폼 등록 성공 증거가 아니다.
- 실제 플랫폼 등록: 미검증. 시험 번호를 실제 송장번호로 변조하거나 고객 주문에 등록하지 않았다.
- 배포 패키지 UI 7종 통과: 로그인, 발급, 라벨 미리보기, 주문 도구, 자동 발급·등록, 단건·다건 등록, 1040/1440px 밝음·어두움 레이아웃.
- 0.38.5 설치 프로그램 종료코드 0. 설치 후 실제 주문 읽기 전용 검사는 로그인 진입 화면이 30초 안에 해제되지 않아 미통과했다. 따라서 이번 설치본의 실제 주문 화면 검증까지 성공했다고 표시하지 않는다. 비밀번호·세션은 삭제하거나 변경하지 않았다.

## 남은 일과 조건

쿠팡은 별도 테스트 환경을 제공하지 않는다고 공식 안내한다. [공식 FAQ](https://developers.coupang.com/ko/faq/is-a-test-account-or-test-environment-provided-for-api)

따라서 우체국 시험 번호를 쿠팡 실주문에 넣어 종단간 성공으로 처리할 수 없다. 플랫폼별 시험 가능한 주문 생성 경로를 별도로 확보하거나 정상 출고 대상과 유효 송장을 이용한 실등록 확인이 필요하다. 이 작업은 프린터 구매·연결과 무관하다. 주문 페이지 종단간 인수가 끝나기 전 다른 페이지 완료로 넘어가지 않는다.
