# P4-66 — 재고 대량 조회·상품 연결 상세 / 0.55.0

## 상태
구현·관련 검사·D 앱 패키지 생성·가시 UI 검증 완료. 서버 운영 배포는 Vercel 일일 무료 배포 한도로 거절되어 미적용이다. P4-65 서버가 운영 기준이다. 이번 기능의 전체 운영 완료로 표시하지 않는다.

## 변경
- 재고 조회를 고유 키 기준 250행 페이지로 나눴다. 다음 페이지는 마지막 고유 키보다 큰 행부터 읽는다. 채널 연결은 id, 쿠팡 옵션은 vendor_item_id로 정렬하므로 같은 상품 아래 옵션이 여러 페이지에 걸려도 처리한다.
- IN 조건은 중복 제거 후 100개씩 묶는다. 마지막 빈 페이지까지 읽으며 250행보다 적게 반환되어도 종료로 단정하지 않는다.
- 마스터 최대 1,000행, 하위 테이블마다 최대 5,000행, 공유 20초 제한이다. 초과·오류·중복·취소는 전체 조회 실패이며 잘린 합계를 표시하지 않는다. 조회 중 동시 변경에 대한 DB 트랜잭션 스냅샷을 보장하는 구현은 아니다.
- 앱 목록은 50개씩 이전/다음 이동. 검색·필터는 받아온 전체 상품 대상이며 조건 변경 시 첫 페이지와 닫힌 상세로 초기화한다.
- 상품 상세에 채널 연결 번호를 표시하고 연결 번호 검색을 지원한다. 원본 응답의 raw_data는 앱에 전달하지 않는다.
- 구 서버의 연결 번호 없는 응답도 수용하며 확인 필요로 표시한다. 운영 서버 배포 전에는 조회 상한도 여전히 P4-65 기준이다.
- 수량 변경·상품 연결 편집·가격 변경 기능은 추가하지 않았다.
