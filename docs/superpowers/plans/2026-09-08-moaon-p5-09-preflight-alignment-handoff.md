# P5-09 보완 — 모아온 0.9.1 출고 사전 확인 정합성

## 완료 범위

AWS 연결 없이 수행할 수 있는 앱 사전 확인 보완이다. 실제 발급 버튼, 실행 확인 화면, 작업 진행 상태 연결은 이번 범위가 아니며 여전히 미완료이다.

- 송장 이력 조회 상태가 READY로 확인되지 않으면 최종 확인 후보로 분류하지 않는다.
- Cafe24/쿠팡 판매자배송 주문 식별번호가 채널에 맞는 정규 형식인지 검사한다.
- 서버의 주문 페이지 데이터가 송장 이력 상태를 전달하도록 보완했다. 누락을 정상으로 추측하지 않는다.
- 상세 패널에 `송장 이력 조회 상태 확인 필요` 사유를 표시한다.
- 네이버/로켓그로스 별도 경로, 로그인 유지, 외부 쓰기 차단은 그대로다.

서버 DTO 변경이 아직 운영 반영되지 않았다면 앱은 이력 확인 필요로 표시한다. 신규 상태를 받더라도 저장 자료 기준의 후보 표시일 뿐 실제 발급 승인이 아니다.

## 검증

누락된 이력과 잘못된 주문번호가 REVIEW_ONLY가 되는 실패를 먼저 재현했다. 실제 서버 adapter에서 이력 필드가 빠지는 실패도 재현한 뒤 수정했다.

- desktop 테스트 48/48 통과.
- 전체 허브 테스트 2,546/2,546 통과.
- 격리 Electron 재조회 UI: 신규 사유 표시, 동일 선택 복원, 스냅샷 변경 시 이전 자료 폐기 통과.
- 패키지 app.asar 격리 실행: 상세 표시 및 라이트/다크·창 크기 3종 검사 통과.
- 독립 코드 리뷰: 중요 신규 결함 없음.
- git diff --check 통과.

모든 주문 시험은 합성 자료이며 실주문 발급/변경은 수행하지 않았다. 패키지 검증은 개발 Electron으로 app.asar를 실행한 것으로, 새 설치본의 실제 사용자 로그인/프린터 검증을 뜻하지 않는다.

## 인도와 남은 적용

설치 파일: `output/moaon-preview-0.9.1/Moaon-Preview-0.9.1-Setup.exe` (canonical checkout 기준).

- 설치 파일 SHA256: `49D575A5E3FC171390DB91D28180896D8B735BCB3E21F89803D5EFDD6AB4991C`
- app.asar SHA256: `FCC56A261D08679F29E88DA2FEB5C9BBAAB32046D65C9EDCD2BAAB735CC4EC28`
- 서명 상태: NotSigned. 개인 시험용이며 보안 경고를 우회하지 않는다.
- 실행 중인 기존 앱을 종료하거나 새 버전을 설치하지 않았다.
- 운영 웹/worker 적용은 이번 실행에서 확인하지 않았다. Git 반영과 실제 서버 적용을 구분한다.
- 새 유료 서버나 DB 리소스를 만들지 않았다.

다음은 AWS worker 적용 확인, 서버의 최신 자료 재검증과 앱의 명시적 발급 확인·접수/진행/완료/결과 불명 표시 연결이다. 결과 불명 요청은 자동 재발급하지 않는다.
