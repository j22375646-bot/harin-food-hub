- [x] 0.224.0 변경을 원격에 반영한다. 서명한 설치 파일을 공개 업데이트 채널에 올리고, 공개 피드의 버전·서명과 설치 파일의 해시를 검증한다.
- [x] 별도 Electron 프로필에서 앱 시작을 계측한다. 프로세스 시작, Electron 준비, 창 생성, 로컬 화면 로딩, 조회 준비의 시간을 각각 기록한다.

계측 결과에는 구간명, 경과 시간, 건수와 상태만 사용한다. 실제 주문 발급·출고, 로그인 비밀번호 입력, 업무 중인 프로세스 종료는 사용하지 않는다.

## 공개 배포 확인

소스 커밋 `8352e4ff`를 원격 브랜치에 올렸다. 공개 `moaon-stable`의 0.224.0 설치 파일은 HTTP 200, 114,474,343바이트, SHA-256 `b8a8231f58e9cb7224ffb829b823d5784fd9cfa5a62dd271e8bf75d71d432c14`이다. 11월 22일 05:11:50 KST에는 앱의 서명 매니페스트 요청과 Electron 업데이트 메타데이터 요청이 모두 0.224.0을 반환했고 Ed25519 서명 및 버전·크기·해시 일치 검사가 통과했다.

## 계측 실행

```powershell
node desktop/test/order-startup-measure.cjs D:/GPT/Apps/Moaon/releases/0.224.0/resources/app.asar --ui
```

설치 패키지의 앱 코드를 별도 프로필과 숨김 Electron 창에서 실행한다. 브라우저 자동화 연결 없이 측정하며, 로그인과 주문 조회에는 합성 응답만 사용한다. 결과의 주문 메뉴 복귀는 오늘 화면에서 주문 메뉴로 되돌아오는 지연이다. 배송 상태 탭 재조회나 운영 서버 응답을 의미하지 않는다.

첫 시도에서 실행부터 창 표시 준비까지 95,717ms가 걸렸다. 런타임 코드 시작 전 23,286ms, 창 생성 이후 화면 탐색 시작까지 18,466ms, 탐색 시작 이후 DOM 준비까지 32,862ms였다. 첫 시도는 선택한 주문 화면 계측을 끝내지 못했다. 파일 읽기와 화면 초기화를 구분하기 위해 아이콘과 프로토콜 읽기 계측을 추가해 재실행했다.

두 번째 0.224.0 실행에서는 표시 준비까지 77,572ms, 창 생성부터 최초 탐색까지 13,633ms였다. 아이콘 파일 읽기 691ms와 쓰기 8,848ms가 탐색보다 앞서 있었다. 탐색부터 DOM까지는 24,011ms였다. 병렬로 시작된 로컬 리소스 읽기의 누적 대기 시간은 실제 시작 시간에 더하지 않는다. 같은 시간대의 D 드라이브 상태는 Healthy였고 최근 저장장치 오류 이벤트는 없었다. 별도 Windows 성능 카운터에서 읽기 평균 30~40ms와 대기열 5~7을 관측했다. 저장장치 부하가 있었지만 전체 지연의 원인으로 확정할 수는 없다.

별도 0.224.0 세 번째 실행에서는 표시 준비 3,605ms, 주문 샘플 20건 첫 렌더 26ms, 주문 메뉴 복귀 8~11ms, 현재 페이지 검색 3~4ms였다. 시작 편차가 커 버전 간 단일 실행의 총시간을 개선율로 사용하지 않는다.

## 0.225.0 검증

```powershell
node desktop/test/order-startup-measure.cjs D:/GPT/Apps/Moaon/releases/0.225.0/resources/app.asar --delay-icon-write-ms=1500 --ui
```

0.224.0 대조 시험에서는 기존 아이콘 쓰기가 탐색과 표시 준비보다 앞선 순서를 검출했다. 0.225.0 패키지에서는 탐색과 표시 준비가 아이콘 쓰기 요청보다 먼저였고, 쓰기에 1,509ms를 추가해도 화면 표시 순서가 유지됐다. 쓰기 완료 후 아이콘 적용이 확인됐다. 창 생성부터 첫 탐색은 291ms, 샘플 목록 첫 렌더 25ms, 주문 메뉴 복귀 8~12ms, 로컬 검색 3~6ms였다. 실제 로그인 세션에서의 응답 시간은 측정하지 않았다.

0.225.0 소스 커밋 `744d61c0`을 원격에 반영했다. 코드 시험 574개가 통과했고 관리 설치본의 166개 파일이 패키지 및 소스와 일치했다. 이 PC의 바로가기 4개는 0.225.0을 가리킨다.

11월 22일 05:22:45 KST에 `moaon-stable` 0.225.0 공개 배포를 재검증했다. 설치 파일 HTTP 200, 114,474,176바이트, SHA-256 `919fd18c131209c71663b15c26de7340643266c8f86e7a5f0bef9d94c5e73dd5`. 공개 피드 서명과 Electron 메타데이터, GitHub 자산 3개의 크기와 해시가 로컬 빌드와 일치했다.

11월 22일 05:35 KST에 세 채널 주문 수집과 목록 반영 완료를 확인한 뒤 0.223.0 프로세스를 종료하고 설치된 0.225.0 실행 파일을 직접 시작했다. Windows 창 확인까지 약 54.6초가 걸렸다. 실제 사용자 세션은 기존 로그인으로 열렸고, 오늘 화면의 주문 작업대에 송장 발급 전 저장 주문 3건과 갱신된 조회 시각이 표시됐다. 이는 실제 1회 시작 관측이며 조회 API만의 시간과 배송 상태 탭 간 왕복은 포함하지 않는다.

관리 설치본의 같은 `app.asar`로 주문 작업실 격리 시험도 다시 통과했다. 배송정보 사유 5종, 해당 주문만 재조회, 탭 집계, 두 테마와 900·1040·1440px 너비를 확인했다. 격리 도구 준비 165,611ms와 합성 재조회 3,941ms는 실제 사용자 세션 측정과 구분한다. 이후 Windows 조회 시점까지 같은 실행 파일의 새 충돌 이벤트 없이 0.225.0 창이 응답했다.
