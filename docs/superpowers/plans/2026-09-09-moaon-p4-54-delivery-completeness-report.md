# P4-54 배송정보 보완 조회 — 0.38.3

## 발견한 문제와 수정

기존 주문 상세는 수취인 이름 또는 주소가 없을 때만 보완 조회를 시작했다. 연락처 또는 우편번호만 누락된 경우 조회하지 않는 문제를 재현했다.

- 카페24·쿠팡 주문의 이름·주소·연락처·우편번호 중 하나라도 비어 있으면 기존 배송정보 조회를 호출한다. 공백 문자열도 누락으로 취급한다.
- 응답 상태가 READY여도 필수 정보가 빠져 있으면 조회 완료라고 표시하지 않는다. 누락 안내와 명시적 재조회 버튼을 유지한다. 자동 반복 조회는 추가하지 않았다.
- 누락된 결과에는 성공 후의 발급 조건 재확인 버튼을 만들지 않는다. 완전한 결과여도 화면 조회만으로 발급 자격을 부여하지 않고 기존 서버 재확인을 거친다.
- 배송정보 재조회·발급 조건 재확인 버튼의 클릭 높이, 모서리, hover·disabled 상태를 앱의 기존 디자인에 맞췄다.

이는 필수 값 존재 여부에 대한 UI 보완이다. 전화번호·우편번호의 실제 유효성이나 송장 발급 성공을 보장하지 않으며 서버의 출고 검증은 그대로 유지한다.

## 검증

- 연락처만 누락된 시험 주문에서 조회 횟수 0으로 실패함을 확인한 뒤 수정했다.
- 연락처/우편번호 단독 누락, 불완전 READY 응답, 재조회 버튼 유지, 발급 권한 유지, 로그아웃 후 배송정보 제거 통과.
- 앱 단위 테스트 230/230 통과.
- 패키지 UI 5종 통과: 배송정보 상세, 목록 밀도·패널, 주문 수집, 자동 발급·등록, 플랫폼 송장 등록.
- 1440/1040px·라이트/다크 목록 밀도 기준 유지. 작은 창의 결과/이력 접근성 유지.
- NSIS 0.38.3 빌드 성공. 설치본 확인은 아래 기록을 따른다.
- 이 PC 설치 완료. 설치본·빌드 app.asar SHA256 일치: `35A59685FC20C3BE01F7F511F0A2402EFF1F60D17B99344E3A7827E2CE4050D8`.
- 실제 설치 EXE 읽기 전용 확인: 0.38.3, 로그인 재입력 없이 주문 진입, 열 정렬 오차0px, 패널21프레임·inert·스크롤바 숨김 통과. 개인정보 값은 로그에 남기지 않았다.

시험 응답과 격리 프로필을 사용한 테스트를 실제 출고 검증으로 표시하지 않는다. 실제 송장 발급·플랫폼 전송·물리 인쇄, 서버·DB 변경, 유료 인프라 추가는 실행하지 않았다.
