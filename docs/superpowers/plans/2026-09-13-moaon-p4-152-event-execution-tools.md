# P4-152 · 이벤트 실행 도구

2026-09-13 · 모아온 0.138.2 / 웹 1.59.2

## 사용자가 할 수 있는 일

1. 행사 준비: 배너·상품/사은품 재고·할인/쿠폰·메시지 대상 체크. 시작 3일 전부터 종료일까지 미완료 준비 표시. 발송 예정일 도래/경과 후 미발송 표시.
2. Windows 알림: 기존 로그인·프로필 알림 설정·트레이 동작을 사용. 행사 시작일별 준비 알림과 메시지 예정일별 미발송 알림을 중복 없이 보존하며 클릭 시 이벤트로 이동. 완료·삭제·종료·잘못된 설정 제외. 앱/서버 조회가 가능해야 하며 PC 전원 OFF 상태 알림이나 Telegram 서비스는 이번 기능이 아니다.
3. 복제: 선택 날짜를 시작일로 기간과 혜택·목표·비용을 복사한다. 새 CREATE로 저장하며 준비 체크·발송 완료/날짜·기존 문구·회고·기존 UTM 행사명은 초기화한다. 재구매 감사/시즌 선물전/신상품 소개 3개 기본 템플릿 제공. 별도 사용자 템플릿 보관함은 아니며 저장된 행사는 복제로 재사용한다.
4. 예상 이익: 한 상품·한 플랫폼 가정의 판매가/수량/원가/수수료율/개당 배송·사은품비/행사 광고비. 할인 후 매출에서 입력 비용을 차감한다. 빈 비용은 0원으로 보정하지 않고 판단 보류. 0원은 직접 입력. 세금·고정비가 빠진 가정 기반 계산이며 실제 정산 이익 아님.
5. 메시지: 행사명·기간·할인·조건·링크로 문자/카카오/SNS 초안 생성, 직접 수정·저장·복사. HTTPS 상품 링크의 기존 쿼리/해시를 유지하며 UTM 출처·매체·행사명을 추가. 원격 발송 없이 복사 버튼 클릭에만 신뢰된 메인 IPC를 통해 클립보드 기록.
6. 회고: 목표 주문 건수와 기존 결과·회고를 저장. 상세 버튼으로 행사 전/중/후 동일 길이 기간의 수집 주문을 넓은 비교 창에서 확인. 네이버/카페24/쿠팡 판매자배송/로켓그로스 분리. 현재 연결은 플랫폼 전체 주문 원장이므로 행사 대상 상품만의 매출이나 마케팅 인과를 주장하지 않는다. 취소·환불 차감 전 원장 금액이며 순매출·정산 아님을 표시. 미래 구간·실패/누락 금액은 확인 필요/시작 전, 확인된 수집 0건과 구분한다.

## 저장·호환·보안

- 선택적 execution 필드를 기존 이벤트 body에 저장한다. 전체 4000자 제한 유지, 초과 시 설명·기획·메시지를 줄이도록 안내한다. DB 스키마 변경 없음.
- 구버전이 execution 없이 수정해도 서버에서 이전 준비·비용·메시지를 보존한다. 새 앱은 저장 응답을 대조해 누락/변경된 실행 정보를 성공으로 표시하지 않는다.
- 현재 단일 하린식품 캘린더 인증 경계를 유지한다. 새 성과 GET은 기존 대시보드 인증과 캘린더 소속/이벤트/미삭제 검증 후 고정된 원장만 읽는다. 고객 이름·주소·전화번호 조회/반환 없음.
- 원장당 최대 5000행, 500개씩 고정 정렬과 count 대조. 중복/잘림/실패를 금액 0으로 표시하지 않는다. 원장 수집의 역사적 완전성은 별도 확인 필요.
- 데스크톱 성과 조회는 정확한 메인 프로세스 URL 허용, 고정 IPC 인자, 크기 제한·시간 제한·연결 세대 확인. 메시지·가격·실주문 변경을 자동 실행하지 않는다.
