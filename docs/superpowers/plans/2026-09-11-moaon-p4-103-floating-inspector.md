# P4-103 · 주문 상세와 플로팅 작업바 / 0.89.0

사용자 캡처의 과도한 사전 확인 박스, 복잡한 상세 패널, 목록 안에서 공간을 차지하는 선택 도구, 보라색/남색 혼용을 수정했다.

- 선택 도구를 body에 옮기고 화면 하단 고정 배치했다. 페이지 애니메이션과 목록 스크롤에 영향받지 않는다. 다른 페이지에서는 숨기고, 추가 메뉴는 외부 클릭/Escape로 닫는다.

- 상세 패널은 중복 채널·수량 표시와 배송정보 박스를 줄였다. 상품명19px, 배송 본문15px, 등록 송장번호23px로 계층을 정리했다. 사전 확인은 접힌 추가 정보 내부로 이동했다.
- 운영 주문 발급·캘린더 저장·서버 배포 없음. 이번 범위는 데스크톱 UI다.
