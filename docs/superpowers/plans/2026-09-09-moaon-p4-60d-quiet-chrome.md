# P4-60D / 0.49.1 — 주문 하단·연결 상태·오늘 화면 정리

- 주문 하단의 서버 송장 등록 이력과 기록 조회 버튼을 앱 설정 > 출고 기록으로 이동. 기본 닫힘 상태로 제공한다. 기록은 삭제하지 않았다.
- 현재 출고 실행 결과와 미완료 후속 알림은 주문 화면에 유지한다.
- 연결 상태에서 주문 범위와 0–0을 제거. 연결됨/일부 자료 확인 필요/연결 확인 필요로 구분한다.
- 주문이 비었을 때 범위 대신 조회된 주문 없음으로 안내한다.
- 오늘 화면의 기존 하린식품 계정으로 조회 카드를 제거. 계정 연결·해제는 설정에서 유지한다.

UI 스킬의 정보 분리 원칙을 적용해 평소 업무 화면과 관리용 기록을 분리했다. 송장 발급·등록 로직, 자동 기록 복구, 로그인 프로필은 변경하지 않았다.

검증: 제거 전 UI 시험 실패 후 수정 통과. 앱 271개 테스트 통과. 주문 1040/1440 폭과 밝은/어두운 테마, 공통 제목·버튼 검증 통과. 시험 응답·임시 프로필을 사용했으며 실제 송장 발급을 실행하지 않았다.

기존 P4-60C 캘린더 서버 배포와 실데이터 검증은 여전히 남아 있다. 이번 변경은 앱 UI 수정이며 서버 배포를 하지 않는다.

설치: 0.49.1 종료 코드 0. 설치 app.asar와 빌드 산출물 SHA-256 일치. 패키지에서 정리된 화면/계정 관리 보존과 주문 레이아웃 시험 통과.
