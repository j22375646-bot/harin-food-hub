# P4-20 앱의 사업장별 주문 조회 연결 / 0.15.3

## 변경

Windows 앱 주문 조회를 P4-19에서 배포한 하린식품 고정 사업장 API로 전환했다. 송장 발급 전(ACTIVE), 배송대기(REGISTER), 배송중(IN_TRANSIT), 완료(COMPLETED)와 다음 페이지 offset/snapshot에 모두 적용한다.

기존 네트워크 허용 정책도 새 주소를 기준으로 검사한다. 이전 `/api/orders/page` 주소, 다른 사업장 UUID, 렌더러 직접 요청, POST, 임의 tenant query를 허용하지 않는다. 새 경로 실패 시 이전 주소로 우회하지 않는다. 송장 확인 단계의 주문 재조회도 공통 URL 생성기를 사용하므로 동일하게 적용된다.

로그인 세션 저장 방식, UI, 송장 발급 POST, 출력 방식은 바꾸지 않았다. 다사업장 선택 UI를 개방한 것은 아니며 여전히 하린식품 전용 연결이다.

## 검증

- 새 경로 생성과 이전 경로 차단 테스트 2개가 수정 전에 실패하는 것을 확인했다.
- 변경 후 데스크톱 전체 121개 테스트 통과, 실패/건너뜀 0개.
- 격리 Electron 화면 테스트에서 새 사업장 API로 실제 앱 코드가 요청하는 URL을 확인했다. 사업장 표시·시간 초과·문자열 안전 렌더링·연결 해제도 통과했다.
- 화면 테스트는 가명 응답과 분리된 임시 프로필을 사용했다. 운영 로그인/실주문 성공 증거와 구분한다.
- 버전 0.15.3. 기존 설치 앱이 실행 중이므로 강제 종료/덮어쓰기하지 않았다. 사용자 로그인 프로필은 변경하지 않았다.

## 다음

### 생성 산출물

`desktop/dist/Moaon-Preview-0.15.3-Setup.exe` 생성 완료, 패키징 종료 코드 0. 패키지 app.asar를 개발 Electron 바이너리로 실행한 격리 화면 시험도 통과했다. 이것은 설치된 새 EXE 시험이 아니다.

SHA256: `9ADBF7ADED995E2DFF93E5806E54D74832239D9B74BD3DF013CB38C438FFE7D5`

파일 크기 111,380,271 bytes. Authenticode 상태는 `NotSigned`이며 Windows 보안 경고가 표시될 수 있다. 코드 서명 완료 제품으로 표시하지 않는다.

앱 사용이 끝난 상태에서 0.15.3 설치 및 실제 로그인 유지/주문 행/페이지 전환 인수를 수행한다. 운영 차단 응답을 확인하고, 그 후 별도 사업장의 독립 원장 연결을 진행한다. 실제 발급/출고/출력은 이번 시험 범위가 아니다.
