# P4-105 · 우편번호 누락과 주문 목록 가독성 / 0.91.0

## 원인과 수정

- 네이버 수집기(`lib/naver-commerce/sync.js`)는 주소를 zipCode+baseAddress+detailedAddress로 저장하지만 주문 변환에서 별도 postCode를 전달하지 않았다. 모아온에서 이 수집 형식의 5자리 우편번호+한국 지역명 접두부만 분리해 표시한다. 일반 주소 숫자나 타 채널 주소를 우편번호로 추측하지 않는다.
- 세 채널의 명시적 postCode/zipCode/zipcode/zip_code/post_code/postalCode/postal_code를5자리 문자열로 정규화한다. 선행0을 보존하고 원본 비공개 필드는 전달하지 않는다.
- Cafe24·쿠팡 상세 조회가 이름/주소만 있으면 종료되던 조건을 고쳤다. 연락처·우편번호가 누락되면 기존 인증된 상세 API로 조회한다. 조회 화면의 보완이 송장 발급 승인으로 바뀌지 않는다.
- 공휴일 자료 미확정을 모두 ‘출고일 확인’으로 숨기던 표현을 개선했다. 확인된 당일 대상은 ‘당일출고’, 공휴일 미확정 당일 계획은 ‘당일출고 예정’, 과거 예정일의 불확실한 지연은 ‘출고 지연 확인’으로 구분한다. 상세 설명에는 서버 공휴일 확인 상태를 유지한다.15시 경계/배송 완료 판정은 유지한다.
- 목록 옵션·수량을 항상 표시한다. 옵션 원본이 비었으면 ‘정보 없음’으로 표시하고 임의로 기본 옵션이라 부르지 않는다. 목록 이미지64px, 상세72px. 추가 정보는 접힌 상태를 유지하고 제목 대비를 높였다. 새로고침 버튼을 블루 계열44px 버튼으로 변경했다.
