# P4-122 · 공통 상단·연결 상태·고정 헤더 (0.108.0)

## 원인과 수정

- Daybook 상단의 `padding-inline`이 기존 Windows 캡션 버튼용 오른쪽 여백을 덮어썼다. 모든 너비에서 네이티브 버튼 영역을 확보하고 좁은 창에서는 검색 문구·경로를 단계적으로 접는다.
- 사업장 펼침 카드의 260px 폭이 사이드바의 숨김 영역을 넘어갔다. 카드가 사업장 아래의 실제 레이아웃에 들어가도록 바꾸고, 사이드바 폭 안에서 줄바꿈·글자색·여백을 정리했다.
- 주문 상세의 고정 헤더를 투명하게 덮어쓴 규칙을 불투명 테마 배경으로 수정했다. 내용 스크롤과 헤더의 구분선·닫기 버튼은 유지한다.
- 캘린더 월 이동 도구의 긴 흰 배경을 제거하고 월 제목·이전/다음·이번 달 버튼만 정렬했다.
- 상단 공통 뒤로가기와 Alt+왼쪽 방향키를 추가했다. 최대 50개 페이지 이동을 보관하고 이전 페이지의 스크롤 위치를 복원한다. 뒤로가기 자체는 새 기록을 쌓지 않고, 열린 모달에서는 단축키로 페이지를 이동하지 않는다.

- 9개 페이지 × 1440/1060/820/680px에서 상단 캡션 영역 침범·본문 가로 넘침 검사.

- 기존 오늘 화면의 정상/미조회·펼침·짧은 창·테마 검증 유지.
