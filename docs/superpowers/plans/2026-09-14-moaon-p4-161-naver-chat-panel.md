# P4-161 네이버 분석 대화 패널

2026-09-14 사용자 범위 정정: 채널별 매출·상품 이익 확장(160C)은 보류한다. 네이버 분석만 유지한다. 160C 검토에서 코드 변경은 하지 않았다.

요청: 실제 AI 연결 상태를 확인하고 네이버 보고서 대화를 오른쪽 사이드 패널로 제공한다.

## 구현 범위

- 기존 네이버 광고 저장 보고서·CLOVA 계약·근거 검증·6턴 제한 유지.
- 오른쪽 대화 패널에 같은 보고서/snapshot의 사용자 질문과 검증 답변을 순서대로 표시.
- 스크롤 대화 영역, 고정 입력 영역, 추천 질문, 대기/취소/오류/미연결 상태.
- 상세 근거 패널과 상호 배타, 작은 화면 반응형, Escape/포커스/44px 버튼, reduced motion.
- 새 의존성·자동 모델 호출·다채널 데이터 조회 없음.

## 연결 확인

운영 환경변수 목록(p4161-env-names.log)을 재조회했으며 CLOVA_STUDIO_*와 MOAON_ANALYSIS_AI_ENABLED가 없다. 저장소의 .env/.env.local에도 설정 파일이 없다. 따라서 연결 코드와 실제 제공자 연결은 구분한다. API 키 원문을 채팅/일반 로그로 받거나 출력하지 않는다.

사용자에게 CLOVA Studio 키 발급 여부와 저장 위치를 질문했다. 키·단가·계정·크레딧·자료 처리 조건이 준비되면 승인된 범위에서 실제 시험한다. 현재 이 조건을 임의로 true로 만들지 않는다.

실제 소스·설치 Electron 앱을 오른쪽 보조 모니터 비활성 창으로 검증한다. 질문/답변 순서·자료 변경/로그아웃 초기화·취소와 늦은 응답 폐기·미연결 차단·근거 패널 전환·700/1040/1440 light/dark를 확인한다. 테스트 통과 후 서명된 앱 공개 업데이트와 CURRENT 반복을 확인한다.
