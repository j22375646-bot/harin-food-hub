# P5-13 / 0.14.0 출고 PC 프린터 점검

사용자는 실물 송장 프린터를 **다른 출고용 컴퓨터**에서 사용한다고 확인했다. 이 개발 PC의 가상 프린터 목록은 출고 PC 장비 상태가 아니다. 이번 단계는 출고 PC 현장 점검을 위한 앱 기능과 설치파일을 준비한 것이다.

## 추가 기능

앱 설정의 **출고 PC 프린터 점검** 버튼을 누르면 로그인 없이 현재 PC의 Windows 등록 프린터 개수·이름·기본 프린터 표시·드라이버 상태 코드를 네이티브 안내창으로 보여준다.

- 프린터 목록은 해당 PC에서만 표시하며 서버로 보내거나 별도 파일로 저장하지 않는다.
- 프린터 선택/설정 변경, 드라이버 설치, 기본 프린터 변경, 시험 출력은 실행하지 않는다.
- 등록 목록에는 PDF 등 가상 장치도 포함될 수 있다. 상태 코드가 있어도 실물 출력 성공으로 판단하지 않는다.
- 조회 실패·빈 목록·연속 클릭에 대응하고 응답 대기를 5초로 제한한다.
- 제한: 시간 초과가 네이티브 드라이버 조회 자체를 취소하는 것은 아니다. 드라이버가 멈췄다면 반복 클릭 대신 앱과 Windows 프린터 상태를 확인해야 한다.

## 검증 결과

- 데스크톱 테스트 **110/110 통과**.
- 실제 Electron에서 이 PC의 OS 프린터 조회 및 설정 버튼→IPC→안내 결과 시험 통과. 안내창 응답만 자동 대체했고 물리 출력은 하지 않았다.
- 패키징된 app.asar로 위 프린터 점검 시험 및 기존 송장 미리보기·연결 해제 시험 통과. 개발 Electron/격리 프로필로 실행했으므로 출고 PC 설치 인수와는 구분한다.
- 독립 코드 검토에서 중요 결함 없음. 네이티브 조회의 취소 불가 제한을 기록했다.
- Windows x64 NSIS 설치파일 생성, 서명 `NotSigned`.

## 출고 PC 적용 순서

1. `Moaon-Preview-0.14.0-Setup.exe`만 USB나 사내 파일 전달 수단으로 출고 PC에 옮긴다. 사용자 프로필·쿠키·로그인 파일은 복사하지 않는다.
2. 출고 PC에서 실행 중인 모아온을 정상 종료한 뒤 설치파일을 실행한다. 현재 PC의 앱은 이번에 자동 업데이트하지 않았고, 출고 PC에도 원격 설치하지 않았다.
3. 앱 설정 → **출고 PC 프린터 점검**을 눌러 실제 송장 프린터가 보이는지 확인한다.
4. 목록에 없다면 해당 PC의 연결/드라이버를 확인한다. 목록에 있더라도 실제 용지·여백·바코드 검증은 별도다.
5. 하린식품 로그인은 출고 PC에서 직접 진행한다. 운영 주문의 발급·인쇄는 사용자가 대상을 확인한 뒤 실행한다.
