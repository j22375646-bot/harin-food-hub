# P4-181 업무비서 UI 고도화

사용자가 Hermes 접속 대기 중 업무비서 페이지 고도화를 요청했다. 이번 배포는 데스크톱 UI 범위이며 기존 운영 조회 API를 사용한다. 진행 중인 외부 조회 키/서버 변경은 포함하지 않는다.

## 적용

- 홈: 저장한 브리핑 요일·시간·항목을 노트로 표시하고 자료 확인/브리핑 만들기를 제공한다.
- 모아온 조회 상태, Hermes 연결 대기, Telegram 수신 확인 전을 구분한다. 준비됨이나 연결 성공을 추정하지 않는다.
- 아침 업무, 발송 전 점검, 마감 점검의 3가지 구성을 선택한 뒤 시간/요일/항목을 조정한다. 기존 로컬 초안 형식과 저장 위치는 유지한다.
- 실제 조회 결과가 브리핑 미리보기에 반영된다. 채널별 수치를 합치지 않고 누락은 확인 필요로 남긴다. 보고서는 저장된 제목과 기간만 표시하며 AI 생성으로 표현하지 않는다.
- 조회 실패 시 이전 응답의 숫자를 미리보기에서 제거한다. 자동 발송은 꺼져 있으며 초안 저장으로 활성화되지 않는다.
- 테마 토큰, 기존 공통 닫기 버튼, 줄바꿈과 키보드 초점을 유지하고 reduced-motion을 존중하는 짧은 등장 효과를 적용했다.

## 검증

- 데스크톱 node:test 455/455 통과.
- 소스와 배포 패키지 각각 700/1060/1660 폭 × light/dark × 3개 탭 18조합 통과.
- 구성 적용, 저장 후 재실행 복원, 실제 형식 응답의 미리보기, 누락값 표시, 조회 실패 후 이전 숫자 제거 확인.
- 패키지 121개 파일 일치 확인.
- 설치 버전 0.147.18을 오른쪽 보조 모니터에 표시. 실제 사용자 세션에서 기존 운영 서버 조회 상태 `조회 가능`, 카드 4개 및 브리핑 데이터 반영 확인.
- 이번 UI 작업은 DB 스키마/API/운영 서버를 변경하지 않는다. 새 DB 시험/서버 배포는 수행하지 않았다.
