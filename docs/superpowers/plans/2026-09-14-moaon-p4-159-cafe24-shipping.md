# P4-159 · 카페24 자동 발급·주문 표시 수정

## 원인과 변경
- 카페24 목록에는 수취인이 없어 main-process 발급 사전검사가 DELIVERY_INFO로 차단했다. 단건 상세 조회 결과는 목록의 발급 판정에 반영되지 않았다.
- 인증된 페이지 조회에서 출고 가능한 카페24 주문의 수취인을 조회한다. 동시 4건, 전체 6.5초 제한이며 캐시하지 않는다. 여러 배송지, 주소/연락처 누락, 실패는 차단한다. 기존 취소·송장 이력·플랫폼 구분·확인 전후 fingerprint 검사는 유지한다.
- 복수 선택에는 2건 제한이 없다. 선택한 전체 주문이 적격이어야 하며, 차단 사유를 버튼 아래 노출한다. 가능한 주문만 명시적으로 선택하거나 최신 조건을 다시 확인할 수 있다.
- 배송대기중도 오늘 출고·예정·지연 뱃지를 표시한다. 공휴일 정보의 불확실성과 15시 기준은 유지한다. 송장 등록을 배송 출발로 간주하지 않는다.
- 상세/목록의 상태 라벨을 통일하고 Cafe24는 청색, 결제완료는 민트, 준비/발급은 주황, 등록/배송중은 보라, 취소/미확인은 붉은색으로 구분한다.
- 기존 Cafe24는 축약 상품명 뒤 총수량, Coupang은 상품명만 100자로 보내고 있었다. 이제 두 채널 모두 `총 N개 | 상품명 (짧은 옵션) 외 N종`으로 만든다. 총수량은 옵션의 묶음 개수 × 주문수량이며 개입/티백 내용물은 제외한다. UTF-8 100바이트는 자체 보수적 제목 정책이며 우체국 공식 한도라고 주장하지 않는다.
- 판다랭크 Chrome 확장은 사용자 설치 완료 제보를 반영한다.
