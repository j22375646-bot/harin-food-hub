# P4-54 출고 인수 준비 — 0.38.1

## 이번 변경

P4-54 전체 완료가 아니라 출고 인수 준비 보완이다. 웹 서버·DB·API 계약은 변경하지 않았다.

- 프린터 점검창에서 알려진 PDF·팩스·OneNote 출력 대상을 이름 기준으로 구분한다. 이름만으로 판단하므로 `가상 출력 추정`이며, 나머지도 `장비 확인 대상`이지 출력 성공 판정이 아니다.
- 등록된 장치가 있어도 실제 송장 프린터가 준비되었다고 표시하지 않는다. 100 × 150mm 송장·A4 작업표·여백·바코드 확인 항목을 제공한다.
- 잘못된 드라이버 항목 하나가 전체 목록 조회를 실패시키지 않도록 보완하고 제어문자·문자 방향 제어 문자를 정리한다.
- 설정과 시험 화면에 남은 과거 안내를 수정했다. 이미 연결된 플랫폼 송장 등록·출력·엑셀 기능을 미제공이라고 설명하거나 웹 화면으로 돌아가라고 안내하던 문구를 정리했다.
- 기존 UI 색상·레이아웃·서버 쓰기 경로와 송장 확인 절차는 변경하지 않았다.

## 검증

- 새 프린터 회귀 테스트 3개: 수정 전 실패 확인, 수정 후 통과.
- 앱 단위 테스트: **230/230 통과**.
- Windows NSIS 0.38.1 설치 파일 빌드: 성공.
- 이 PC 설치: 종료코드 0. 설치본과 빌드 app.asar SHA256 일치(`82C9D711362B249973F41B1FE09524587F93BC2D80AA1FF00611F0A9B694462A`).
- 실제 설치 EXE 읽기 전용 검사: 0.38.1 확인, 로그인 재입력 없이 진입, 채널·상태 열 오차 0px, 패널 확장 22프레임, 닫힘 후 inert·화면 밖 이동·스크롤바 숨김 통과. 개인정보 값은 로그에 출력하지 않았다.
- 패키지 코드로 프린터 조회 버튼·IPC 검증: 통과. 실제 OS 장치 조회, 대화상자 응답만 시험 대체. 인쇄 없음.
- 패키지 자동 발급/등록 UI: 통과. 시험 응답으로 단건·다건·중복 잠금·부분 완료·로그아웃 처리 검증.
- 패키지 송장 등록 UI: 통과. 시험 자료로 채널·선택·결과·오래된 응답 무시 검증.
- 레이아웃 검사: **미통과**. 1440px 창에서 첫 행 y=466.89px, 목록 높이 218px. 가로 넘침 없음, 메뉴 너비 84px. 수집·검색·상태 안내 누적으로 목록이 아래로 밀린다. 기준을 낮추지 않았고, 실패 시 화면과 측정값이 남도록 검사 진단을 보완했다.

단위 테스트와 시험 응답 검증은 실제 우체국 발급·플랫폼 송장 등록 성공을 대신하지 않는다.

## 이 PC 확인 결과

Windows 조회에는 Fax, Hancom PDF, Microsoft Print to PDF, Microsoft XPS Document Writer, OneNote (Desktop)만 등록되어 있다. 출고용 PC는 별도 컴퓨터이므로 이 결과로 출고용 프린터 상태를 판단하지 않는다.

## 남은 작업 / 주문 페이지 마감 기준

1. 상단 수집·검색·상태 도구의 세로 점유를 줄이되 기능·오류 안내·키보드 접근은 유지한다. 1040/1440px 및 라이트·다크에서 다시 검사한다.
2. 출고용 PC에 보완본을 설치하고 실제 프린터·라벨 용지·여백을 확인한다.
3. 대상 실주문을 명시한 소량 업무 인수에서 우체국 발급 → 플랫폼 등록 결과 → 인쇄물·바코드 판독을 확인한다. 불명확한 응답은 재발급하지 않고 이력을 조회한다.
4. 위 검증이 끝나야 주문 페이지를 마감하고 다음 페이지로 진행한다.
