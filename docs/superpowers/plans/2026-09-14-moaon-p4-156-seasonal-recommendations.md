# P4-156 · 월별 마케팅 추천

사용자 제공 마케팅 캘린더를 모아온 이벤트 기획으로 연결한다. 이미지의 고정 날짜를 연도와 무관하게 복사하지 않는다.

## 사용 흐름

- 이벤트 캘린더에서 선택한 달의 시즌 추천 카드 표시. 겨울 세일·설·밸런타인·봄·새학기·화이트데이·가정의달·여름·휴가·가을·추석·할로윈·블랙프라이데이·크리스마스 포함.
- 카드에 추천 기간/기념일, 목적, 혜택 아이디어, 펼칠 수 있는 대상·준비사항. 비슷한 이름의 기존 행사 안내. 현재 월 캘린더 자료 범위만 비교하며 전체 기간 중복을 보장하지 않는다.
- ‘이 기획으로 시작’은 기존 편집기를 열고 제목·날짜·목표·대상·혜택·준비사항만 채운다. DRAFT, 할인 없음, 사은품 없음, 플랫폼 미선택. 사용자가 날짜·플랫폼·혜택을 확인해 저장한다. 실제 메시지 발송/플랫폼 가격 변경 없음.
- 업무 캘린더에서는 숨김. 계절 기반 로컬 기획 아이디어이며 실시간 트렌드·매출 예측·AI 분석으로 표시하지 않는다.
- 명절은 조회된 같은 달 휴일 자료의 첫 날짜를 준비 기준으로 쓰며 중앙 날짜를 추론하지 않는다. 미조회 시 날짜를 비워 두고 날짜 확인 필요 안내. 미리 채운 기간은 사용자가 조정 가능하다.
- 블랙프라이데이: 미국 추수감사절(11월 넷째 목요일)의 다음 날 계산. 11월29일 고정 또는 넷째 금요일로 계산하지 않음. 2024~2029 시험 포함. 날짜 규칙 참고: [미국 OPM 공휴일 안내](https://www.opm.gov/frequently-asked-questions/pay-and-leave-faq/pay-administration/what-are-federal-holidays/).
