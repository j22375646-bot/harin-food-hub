# P4-17 실제 로그인 앱 연결 인수

## 결과

2026-09-09 사용자가 로그인 완료를 알린 뒤 설치된 모아온 Preview 창을 직접 확인했다. 모의 응답이나 브라우저 세션이 아닌 Windows 앱 화면 기준이다.

- 오늘: 하린식품 연결, 저장된 주문을 조회했습니다, 송장 발급 전 1–1 표시.
- 앱 설정: 버전 v0.15.2, 연결됨 표시.
- 내 사업장: 소속 사업장 1개, 하린식품, 소유자 표시.
- 기존 다크모드가 유지됐고 오늘에서 앱 설정으로 이동했다.

기존 P4-16의 사용자 로그인 대기를 해소한다. 화면의 저장 주문 조회 성공은 플랫폼 신규 수집 성공이나 전체 주문 대조 완료를 의미하지 않는다.

## 작업 범위와 제한

Computer Use로 현재 실행 앱을 관찰하고 앱 설정으로 이동했다. 로그인 비밀번호 입력, 세션 삭제, 발급, 출고, 출력, 운영 DB 변경은 하지 않았다. 이번 단계는 실계정 인수 및 계획서 갱신이며 새 기능 구현/새 EXE/서버 배포는 없다.

로그인 후 앱 재시작 유지와 만료 복구는 이번에 시험하지 않았다. 현재 사업장 목록은 조회 전용이며 다른 사업장 업무 접근을 허용하지 않는다.

## 다음 개발

기존 P4 사업장 전환 계획에 따라 서버의 소속·역할 재검증과 업무 접근 분리를 우선 연결한다. 사업장 선택값만으로 하린식품 기존 API를 재사용하지 않는다. 두 가명 사업장의 교차 접근, 권한 해제, 전환 중 늦은 응답 차단을 검증한 뒤 선택 UI를 개방한다. 운영 데이터를 복제하거나 유료 자원을 추가하지 않는다.
