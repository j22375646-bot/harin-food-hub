# P4-44 — 서버 송장 등록 이력

2026-09-09 / 모아온 Windows 0.30.0

## 이번에 사용할 수 있는 기능

주문 화면의 ‘서버 송장 등록 이력 조회’로 기존 웹 허브와 같은 서버 기록을 읽는다. 동일한 하린식품 계정으로 다른 출고 PC에서도 같은 서버 기록을 조회하는 구조다. 실제 다른 PC에서의 인수 시험은 아직 하지 않았다.

- 기존 GET /api/shipping/actions를 재사용했다. 서버·DB·고정 IP 및 웹 UI는 변경하지 않았다.
- Cafe24/쿠팡 플랫폼 송장 등록의 최신 상태를 주문별로 표시한다. 우체국 전체 발급 이력, 네이버 이력, 실시간 배송 상태가 아니다.
- 서버 최근 작업 최대 300개에서 주문별 최신 기록으로 추린 결과이며 쿠팡 주문 연결이 안 되는 항목은 기존 API에서 제외될 수 있다.
- 성공·대기·실패·확인 필요를 구분하고 ‘주문 찾기’로 기존 제한 조회 기능에 연결했다.
- 이 PC의 로컬 출고 확인 목록과 별도 접이식 영역으로 표시한다. 로그아웃/화면 조회 상태 변경 시 이전 서버 표시를 지운다.
- 수동 조회만 추가했으며 주기적인 서버 조회는 추가하지 않았다. 조회 전 로그인 재검증 및 이력 GET이 실행된다.
- Renderer의 직접 API 요청을 차단하고 Main에서 정확한 GET 주소만 허용한다. 최대 응답 크기·300개 한도·채널/주문 ID 일치·중복을 검사한다. 송장번호/원문 오류/내부 요청 ID는 화면에 전달하지 않는다.

## 검증 결과

- 미구현 시험 실패 확인 후 구현 시험 통과.
- 전체 단위 시험 169/169 통과. 인증 실패·채널 불일치·민감 필드 제외·읽기 전용 경로 포함.
- 개발 및 패키지 app.asar의 출고 UI 시험 통과. 서버 이력 상태 구분과 로그아웃 시 삭제는 시험자료로 검증했다.
- NSIS 빌드 성공, 설치 종료 코드 0.
- 실제 설치 EXE 0.30.0에서 기존 서버 이력 **25건 조회 확인**. 실제 주문 식별자와 개인정보는 보고서에 남기지 않았다.
- 설치 EXE 재실행 두 번 로그인 유지, 진입 3.271초/2.382초. 네 주문 구간 및 다음/이전 페이지 읽기 통과. 측정 시점 값이며 속도 보장은 아니다.
- 설치본 UI: 표 정렬 오차 0px, 패널 전환 22프레임 검사, 내용 유지·접힌 영역 비활성·스크롤바 숨김 통과.

## 남은 작업과 다음 단계

이번 작업은 서버 기록 조회이며 실제 우체국 접수·플랫폼 송장 전송·물리 출력은 실행하지 않았다. 따라서 주문 페이지 전체 실운영 인수 완료로 표시하지 않는다.

다음 P4-45는 주문 페이지 인수 항목을 웹 기능과 다시 대조해 남은 발급/등록/출력 장애 경로와 UI 상태를 정리한다. 결과 불명 작업을 자동 재발급하지 않는 안전장치를 유지한다. 실제 출고 주문의 종단간 처리와 출고 PC 프린터/용지 검증이 끝난 뒤 다음 페이지로 넘어간다.
