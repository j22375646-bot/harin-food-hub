# P4-62 — 버튼 배열·정렬 / 0.52.1

사용자가 개발 속도 개선과 실제 UI 디테일 정리를 요청해 서버 점검 단계에서 앱 화면 작업으로 전환했다. 기존 보라색/중성색, 글꼴과 공통 화면 구조는 유지한다. 기준8baef60, D:\GPT\moaon.

## 변경

- 소유 사업장 선택과 다시 확인 버튼을 한 행의 아래 기준선으로 맞췄다. 상태 메시지는 다음 행 전체 폭을 사용하고 빈 메시지 여백은 없앴다.
- PC 저장 버튼은 입력 폼 오른쪽에, 서버 상태 조회와 서버 저장은 도구 모음 양쪽에 배치했다. 확인창은 취소→저장 순서로 오른쪽 정렬하고 flex gap으로 줄바꿈 간격도 유지한다. 키 저장 승인/취소/충돌/결과 불명 처리 자체는 유지한다.
- API·기록 버튼의 높이와 line-height를40px 기준으로 통일했다. 저장 목록의 보조 동작은 오른쪽으로 정렬한다.
- 캘린더 새로 조회를 다른 조회 화면처럼 제목 오른쪽으로 이동했다. 이전/다음 달은40px 정사각형, 월 표기는 고정 최소 폭, 이번 달은 도구 모음 오른쪽에 배치한다.
- 주문 검색·채널·초기화·추가 필터를40px 높이로 맞추고 표시할 단계 버튼이 없는 빈 막대를 숨겼다. 작은 폭에서는 폼과 도구가 줄바꿈한다.
- 설치 EXE의 --display-right 실행 옵션은 오른쪽 보조 모니터 안에서 showInactive로 시작한다. 보조 모니터가 없으면 기본 모니터로 대체하지 않고 종료한다. 일반 실행 동작은 유지한다.
