# P5-09 작업판 보완 — 모아온 0.10.0

## 이번 개발

현재 페이지 검색 결과를 전체/확인 후보/제외/별도 처리/확인 필요로 요약하고 필터링한다. 주문을 하나씩 열기 전에 검토 순서를 정할 수 있다. 건수는 전체 채널·전체 기간이 아닌 현재 페이지의 검색 결과 기준이다.

행에도 사전 확인 상태를 표시하고 화면 읽기 프로그램용 버튼 설명에 포함했다. 네이버/로켓그로스 별도 경로는 유지한다. 미인식 상태는 확인 필요로 분류하며 실제 발급 권한을 부여하지 않는다.

필터는 메모리의 기존 자료만 이용한다. 별도 API 호출, 수집, 송장 발급, 비용 발생 작업은 추가하지 않았다. 필터로 선택 주문이 숨겨지면 상세를 닫는다. 재조회·연결 변경·인증 오류 때 집계와 필터를 비우고 새 자료에서 다시 시작한다. 샘플 모드에는 실제 주문 집계를 표시하지 않는다.

## UI

기존 글꼴과 라이트/다크 토큰을 사용했다. 프런트엔드 디자인 스킬에 따라 장식보다 현재 페이지의 검토 상태를 강조했다. 좁은 폭에서는 필터가 가로 스크롤되며, 낮은 창에서는 목록을 최소 144px 유지하고 작업 공간을 세로 스크롤한다. 버튼은 44px 이상이며 선택은 전체 배경과 균형 있는 테두리로 표시한다.

## 검증

- 새 필터가 없는 실패를 먼저 재현한 뒤 구현했다.
- 작은 창에서 목록 높이가 57px로 줄어드는 실패를 재현하고 최소 높이/스크롤을 보완했다.
- 스크린리더 버튼 설명에 상태가 없는 실패를 재현하고 수정했다.
- 앱 단위 테스트 48/48 통과.
- 전체 허브 테스트 2,546/2,546 통과 (최종 화면 읽기 설명 보완 이전 실행; 보완 후 앱 단위·UI 시험 재통과).
- 격리 Electron: 상태별 건수·검색과 필터 조합·숨긴 상세 제거·샘플 집계 숨김·401 집계 제거·필터 추가 GET 0회·라이트/다크 및 1040×720/1920×1080 검사 통과.
- 기존 재조회 UI 시험 통과.
- 독립 코드 검토: 병합 차단 결함 없음. 검토자의 실행 시험은 Electron 시작 오류로 완료하지 못했으며 위 실행 결과는 주 작업자의 결과이다.
- 검토의 접근성 보완을 반영했다. 미인식 preflight 상태 자체를 renderer에 직접 주입하는 시험은 향후 보완 항목이다.

실주문 변경/발급, 사용자 인증, 프린터는 시험하지 않았다. 운영 서버 적용 확인, 명시적 발급 확인창과 진행 상태 연결은 아직 미완료다. 이번 작업으로 P5-09 전체 완료를 선언하지 않는다.

## 인도

버전 0.10.0 설치 파일 생성 완료. 최종 app.asar를 격리 프로필/개발 Electron으로 실행한 필터 시험 및 작업 공간 라이트/다크·3종 크기 시험 통과. 직접 새 설치본의 실사용 로그인/출고 검증과는 구분한다.

설치 파일: `output/moaon-preview-0.10.0/Moaon-Preview-0.10.0-Setup.exe` (canonical checkout 기준).

SHA256: `CADD2D36FE82684BA0B2C16DA62B3B36036D1AEB858F85963823C0D6E62B3E2C`. 서명 상태 NotSigned, 개인 시험용이며 보안 경고를 우회하지 않는다.

기존 실행 중인 앱을 강제 종료하거나 자동 설치하지 않았다. 운영 웹/worker는 이번 작업에서 변경하지 않았으며, 기존 서버 사전 검증 배포는 별도 확인이 필요하다. 새 유료 리소스 없음.
