# P4-133 · 설정 정렬과 작업표시줄 로고

- 설치 EXE에서 추출한 아이콘은 모아온으로 정상임을 확인했다. 시작 메뉴에는 이전 C 드라이브 설치 경로가 남아 있었다.
- Windows 작업표시줄 AppDetails에 모아온 아이콘을 명시했다. Windows Shell이 asar 내부 파일을 직접 읽지 않도록 사용자 데이터 경로에 ICO를 복사하고 그 실제 파일을 지정한다. 실제 설치 EXE에서 실행한 경우에만 모아온 시작 메뉴 바로가기를 현재 경로/아이콘으로 갱신한다. 기존 ToastActivatorCLSID와 바로가기 인자는 유지한다.
- 설정에 독립적으로 끼어 있던 프로필을 화면 테마와 같은 행의 정식 카드로 통합했다. 사진·이름·직함과 공통 스타일 버튼을 표시한다.
- 프로그램 정보/업데이트를 전체 너비 영역으로 배치하고 연결/사업장, API/텔레그램/출고 기록의 폭을 통일했다. 내용 길이로 카드가 줄어들던 flex 배치를 stretch로 바로잡았다.
- 제목·설명·상태·버튼·입력·본문 간격과 글자 크기를 맞추고, 1100px 이하에서는 한 열로 재배치한다. API 저장과 연결 상태는 계속 구분한다.
