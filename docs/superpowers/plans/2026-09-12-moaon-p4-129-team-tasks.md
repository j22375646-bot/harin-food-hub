# P4-129 · 가족 공동 계정과 업무 보드

- 사장/직원/부사장 3개 프로필, 모두 OWNER 및 같은 사업장 전체 권한. 직함에 따른 권한 분기 없음.
- 직원은 기존 owner 계정/비밀번호 유지. 두 추가 계정은 지정 PIN 사용, 서버 인증 공급자에만 저장하며 소스/문서/로그에 값 기록 금지.
- 캘린더: 나의 업무 / 업무 지시 / 전체 업무. 한 폼에서 본인 또는 다른 사람에게 담당자 지정, 기한, 체크리스트를 등록. 같은 상세에서 체크 및 완료/재개.
- 오늘 오른쪽: 나의 미완료 업무, 오늘 기한, 체크리스트. 캘린더와 동일 DB 기록.
- 프로필: 표시 이름/직함/색상/알림 설정. 권한 선택 없음.
- DB 변경은 revision으로 동시 수정 충돌을 검출하고 등록 요청 ID로 중복 등록 방지. 완료한 사용자/시각, 배정자 이력 기록.
- 실행 중/최소화 상태에서 주기적으로 새 변경을 조회하고 UI 반영. 담당자가 새로 배정받으면 Windows 알림. 알림 클릭은 같은 업무 상세로 이동. 완전 종료/오프라인에는 실시간 알림을 보장하지 않으며 재접속 시 미확인 업무 조회.
- 순서: 기존 사용자 보존 및 새 계정/업무 DB → API/입력 검증 → 공통 업무 UI/프로필 → 앱 알림 및 갱신 → 격리 DB/서버/패키지 검증 → 운영 및 서명 업데이트.

## 적용 및 검증

- 0.114.0 구현·서버 운영 배포·Ed25519 서명 업데이트 배포·로컬 설치 경로 갱신 완료.
- 운영 DB에 `20260912012319_moaon_team_tasks` 적용. 사장/부사장 계정과 세 사람의 같은 사업장 OWNER 멤버십 확인. 직원의 기존 인증 정보 유지. 실제 비밀번호 로그인은 사용자 입력을 위해 수행하지 않았다.
- 업무 자료는 서버 DB에 저장하며 실행 중 10초 간격 조회로 다른 PC의 변경을 반영한다. 달력 날짜별 미완료 개수와 날짜별 업무 목록도 연결했다.
- 서버 전체 2,825개 PASS, 추가 API 출처/인증/행위자 위조 검증 1개 PASS. 격리 PGlite DB에서 등록 중복 방지, 동시 수정 충돌, 완료/재개, 세 사람 동일 권한, 세션 폐기, DB 권한 검증.
- 데스크톱 전체 372개 PASS 및 알림 중복/재시작/로그아웃 후 클릭 무효화 검증 1개 PASS.
- 소스 및 0.114.0 패키지에서 가시 Electron 자동 검증 PASS: 업무 등록, 체크리스트, 완료, 오늘 동기화, 프로필 저장, 1040/1440px 화면, 로그아웃 자료 제거. 합성 자료이며 실제 사용자 로그인/운영 업무 생성 시험과 구분한다.
- 패키지 82개 파일 대조 PASS. 0.113.0 기준으로 공개 릴리스 다운로드와 서명 검증 PASS, 자동 시험에서 설치파일 실행은 하지 않았다. 로컬 0.114.0 실제 창을 열었다.
- Vercel 최초 기본 범위 배포는 Not authorized. 올바른 scope를 명시해 `dpl_EDceoFRdwSazZotCYKwccXdcK1MK` READY 및 운영 별칭 확인. 공개 로그인 200/세 계정 선택, 비로그인 업무 API 401 확인.
- 설치파일: https://github.com/j22375646-bot/harin-food-hub/releases/download/moaon-stable/Moaon-0.114.0-Setup.exe

## 사용 범위

- 초기 PIN은 인증 공급자의 최소 길이와 호환되는 서버 인코딩을 사용한다. PIN 자체의 강도를 높이는 암호화는 아니며 기존 로그인 시도 제한을 유지한다. 원문은 코드/보고서에 남기지 않는다.
- Windows 알림은 앱 실행/최소화 및 네트워크 연결이 필요하고 OS 알림 설정에 영향을 받는다. 실제 사장/부사장 PC의 Windows 알림 수신은 미검증이다. 앱 완전 종료 중 알림을 보장하지 않는다.
- 업무 등록·체크·완료·재개 지원. 완료 자료는 최근 90일, 목록은 최대 1,000건이며 제한 표시를 제공한다. 업무 제목 수정/삭제와 여러 명 동시 담당자 지정은 이번 범위에 포함하지 않았다.
