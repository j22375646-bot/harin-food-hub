# P4-61B 사업장 지정 API 설정

## 구현

- 기존 하린식품 연결 / 내 사업장 / 미연결 임시 설정을 구분한다. 기존 앱의 입력칸·버튼·간격을 재사용한다.
- 기존 인증 사업장 조회 API에서 소유자 사업장만 선택한다. 저장 직전 메인 프로세스에서 다시 조회하여 OWNER와 사업장 ID를 확인한다. 렌더러가 보낸 이름·역할은 허용하지 않는다.
- Windows 암호화 저장 자료를 사업장 ID와 플랫폼으로 구분한다. 같은 이름의 다른 사업장 및 임시 설정과 충돌하지 않으며 이름 변경에도 기존 항목을 갱신한다.
- 목록에는 사업장 지정/임시 설정 및 미검증 상태만 표시한다. 키 원문은 반환하지 않는다. 기존 임시 저장 파일과 호환된다.

## 검증

- 신규 회귀 테스트 2개 실패 확인 후 구현, 앱 전체 282/282 통과.
- 조회·운영 권한, 미소속 사업장, 로그인 만료, 잘못된 ID, 렌더러 역할 위조, 기존 저장 IPC 우회 차단.
- 개발 실행 및 패키지 app.asar 실행에서 사업장 선택, 실제 Windows 암호화 저장, 메타데이터 반환, 삭제, 비밀값 비움, 1040/1440 너비 검증 통과.
- 패키지 공통 UI 검증 통과. 테스트는 격리 프로필과 가짜 API 키, 사업장 응답 대역을 사용했다. 운영 계정 권한 조회 성공을 증명하는 테스트는 아니다.
- 0.51.0 Windows 설치 패키지 생성 및 설치 성공(exit 0). 설치된 app.asar와 검증 패키지의 SHA-256 일치 확인.

## 남은 범위

이 작업은 로컬 설정의 사업장 지정이다. 서버 자격증명 등록이나 플랫폼 연결 활성화가 아니다. 저장 당시 OWNER 확인은 이후 서버 작업의 권한 증명으로 재사용할 수 없다.

하린식품 기존 서버 키·실주문·DB는 변경하지 않았다. 새 사업장 키의 플랫폼 유효성 검증, Cafe24 OAuth, 서버 암호화 자격증명 저장 및 사업장별 런타임 연결은 다음 단계다. 캘린더 운영 배포·실제 금액 대조 등 기존 미완료 범위도 유지한다.
