# P4-184 두 Telegram 비서 연결

사용자 요청: 업무비서 @moaon_hub_bot과 개인비서 @moaon_solo_bot을 모아온에서 각각 연결 및 설정. 본인 개인 대화부터 시험.

구현: 두 카드의 토큰 확인/암호화 저장, 허용 사용자/대화 ID, 응답 지침, 연결 스위치, 시험 발송 및 적용 상태. 토큰 원문은 저장 후 반환하지 않으며 Telegram getMe로 슬롯 사용자명과 bot ID를 검사한다. 기존 관리 키 AES-GCM에 별도 AAD를 사용하고 RPC의 소유자/세션/조회키 검증을 유지한다.

Hermes: default를 유지하며 moaon-work/moaon-solo만 관리. 기존 개인 대화와 기억을 복사하지 않는다. 모델 설정만 공유하며 OAuth 파일을 복제하지 않는다. 개인비서는 본인 DM만 허용. 프로필 분리는 파일시스템 샌드박스는 아니다.

검증: 루트 3027개 통과 및 버전 문서 형식 1건 수정 후 재검사 통과. 데스크톱 457개, Python 자동화 4개 및 두 프로필 시험 통과. 소스/패키지 Electron 6개 테마/크기, 저장/토큰 초기화/시험 상태 검증. 0.147.22 패키지 128파일 일치 및 서명 업데이트 배포. 설치 앱에서 실제 두 봇 저장, 두 시험 발송 SENT 확인. Hermes 서버 설치 및 실제 AI 대화 확인 대기.

2026-09-16 후속 검증: 사용자 등록 전용 SSH 키로 직접 접속 성공. 기존 default 및 두 새 프로필이 실행 중이고 Telegram connected임을 확인. gateway.pid를 쓰지 않는 실제 실행 방식 때문에 상태가 잘못 표시되던 문제를 수정. 프로필 명령 인자와 /proc 시작 시각, 상태 파일의 Telegram writer identity를 비교하여 다른 프로필 및 재사용 PID는 거부한다. Python 회귀 및 8개 관련 Node 검사 통과. 서버 1.65.3 배포와 Hermes 직접 업데이트 완료. 운영 DB WORK/SOLO 모두 RUNNING, 설치 앱 두 카드 실행 중 확인. 사용자가 두 봇의 실제 응답 도착을 확인했다.
