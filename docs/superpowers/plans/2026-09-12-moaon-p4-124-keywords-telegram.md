# P4-124 · 키워드 작업 화면과 Telegram 연결 준비 (0.110.0)

사용자 요청: Telegram 앱 연결 자동화 가능성 확인, 키워드 탭 추가.

## 적용

- 왼쪽 메뉴의 독립 키워드 페이지. 기존 Daybook 제목·글자 크기·색상·뒤로가기 규칙 유지.
- 쇼핑광고 실제 검색어 / 등록 광고 키워드를 별도 선택. 최근 종료일의 가장 긴 저장 기간만 조회한다. 각 원천은 비용 상위 최대200개, 전체 해당 기간 수는 DB exact count로 표시한다.
- 이름 검색, 광고 유형, 전환/미확인 필터, 광고비·매출·ROAS·클릭 정렬, 상세 지표, 키보드 상세 닫기. 검색은 화면에 조회된 범위만 대상으로 한다.
- 실제 검색어 목록은 원천에서 확인되는 광고비·노출·클릭·CPC 중심. 전환 수 없는 자료를 0전환으로 취급하지 않는다. 실제 검색어와 등록 키워드를 합산하지 않는다.
- raw 필드가 없으면 normalized zero로 대체하지 않는다. 실제 검색어 raw samples는 원래 최대5개만 보관하므로 5개에 도달한 표본의 합계를 전체 비용으로 확정하지 않는다.
- 기존 읽기 전용 사업장 OWNER endpoint에 추가 투영. 보안 프로토콜 자산 허용 목록, 응답 화이트리스트, 권한 전후 확인과 로그아웃 제거 유지. 이전0.109.0 계약에는 optional 추가 필드다.
- 앱 설정에 Telegram 연결 준비 안내와 서버 설정 상태 조회 추가. 토큰/채팅 ID는 앱으로 반환하지 않으며 설정 여부·활성 여부만 표시한다.

## Telegram 범위

- 기존 서버에 Bot getMe/sendMessage, 중요 알림 전달·중복 방지·발송 스위치가 있다.
- 이번에는 봇 생성, 토큰 저장, 채팅 연결, 실제 메시지 발송, 발송 스위치 변경을 하지 않았다. 사용자에게 알림/조회 명령 선호와 기존 봇 유무를 물었지만 배포 준비 시점까지 답변이 없었다.
- 주간 보고서 Telegram 전송과 조회 명령은 봇/수신 대화를 정한 뒤 이어서 연결할 범위다. 기존 보고서 전송 함수가 이메일용이라는 점을 확인했고 Telegram 보고서가 이미 발송된다고 표시하지 않는다.
- 공식 근거: https://core.telegram.org/bots/features , https://core.telegram.org/bots/api . BotFather 생성→사용자가 봇 시작→서버 비밀 설정과 대상 대화 연결 순서로 안내.
