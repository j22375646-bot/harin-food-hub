# P4-114 · 총 재고와 소분 예상 수량 (0.100.0)

## 사용 방법

- 재고 등록의 **총 보유 수량/중량**에는 생산한 전체량을 입력한다. 신규 등록의 빈 수량은 저장할 수 없다. 재고 소진 기록을 위한 0 입력은 허용한다.
- **포장 표시**는 봉지/개 중 필수로 선택한다. 차는 봉지, 조청은 개처럼 사용자가 정한다.
- 티백 소분량은 없음 또는10/20/30/40/50티백. KG 소분량은 없음 또는100g부터1,000g(1kg)까지50g 간격이다.
- 등록/수정 화면에서 총량, `약 N봉지/개`, 남는 티백 또는 g를 즉시 계산한다. 150티백÷30티백은 약5봉지, 30kg÷100g은 약300개다. 155티백÷30티백은 약5봉지와 잔량5티백으로 표시한다.
- 소분량의 **없음** 버튼을 누르면 포장 수를 추정하지 않고 총 재고만 관리한다. 선택 가능한 소분량이 없는 개/박스 단위도 봉지/개 표시는 필수이며 소분량은 없음이다.
- 목록은 총 티백/KG와 약 봉지/개 수, 잔량을 함께 보여준다. 완성 가능한 정수 포장 수를 내림 계산하며, 실제 소분 손실을 측정한 확정 수량은 아니다.

## 저장·호환

기존 공유 DB 재고 JSON과 변경 이력에 `packLabel`과 `portionSize`를 저장한다. 새 테이블/DDL 변경 없이 기존 저장 RPC와 권한/수정 충돌 검사를 사용한다. 소분량의 기준은 티백 단위에서는 티백 수, KG 단위에서는 g다.

기존 버전 앱이 새 필드를 보내지 않고 수정해도 저장된 소분 설정을 보존한다. 총 재고 단위가 바뀌면 맞지 않는 이전 소분량을 제거한다. 입출고와 새 제조번호 등록에서 설정을 유지하고 변경된 총량에 맞춰 예상 수를 다시 계산한다.

주문 자동 차감의 재고 원단위와 기존 구성 수량은 이 표시 설정으로 자동 변경하지 않는다. 화면에 자동 차감·세트 구성에서 주문당 차감량을 확인할 수 있다고 안내한다.
