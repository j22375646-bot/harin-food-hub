# P4-163 로그아웃 접근성

사용자가 찾지 못하던 설정의 연결 해제를 로그아웃으로 통일하고, 왼쪽 메뉴의 앱 설정 아래에 로그아웃 버튼을 추가했다. 메뉴가 접혀도 문 나가기 아이콘과 접근성 이름·툴팁을 유지한다.

기존 disconnect IPC를 재사용한다. 진행 중 조회를 중단하고 앱 로컬 저장소·쿠키·캐시·인증캐시를 지운 뒤 로그인 화면으로 복귀한다. 다른 PC 세션의 서버 강제폐기는 이번 범위가 아니다. 정리 실패 시 기존 실패 처리를 유지한다.

검증: 데스크톱 전체451/451 통과. 실제 소스 격리 Electron에서 700/1040/1440 펼침·접힘, 중복 클릭, 합성 쿠키 삭제, 로그인 화면 및 재로그인 버튼 확인. 오른쪽 보조 모니터, focusable=false. 실제 사용자 세션을 로그아웃시키지 않았다.

버전: 데스크톱0.147.1. 웹1.64.0 변경없음. 설치 ASAR 112개 파일 소스 일치, 설치본 로그아웃 smoke PASS. 서명된 moaon-stable 0.147.1 배포 완료. 0.147.0 모의 버전에서 실제 다운로드·Ed25519 확인 PASS(설치 실행은 안 함). 바탕화면·시작메뉴·작업표시줄 및 current.json을 새 경로로 갱신.

최신버전 CURRENT 후속 검사는 두 번 ERROR. 공개 latest.yml 직접 조회에서 HTTP 504 Gateway Time-out 확인. 앞선 설치파일 다운로드·서명 검증 PASS와 구분하며 CURRENT 성공으로 보고하지 않는다. 배포파일 재게시나 검증 해제는 하지 않았다.
