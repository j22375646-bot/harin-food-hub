# P5-08 — 로그인 유지와 간결한 PC 로그인창

## 제공 버전

모아온 Windows Preview 0.8.0. 기존 PC 설치 경로에 업데이트했다. 웹 운영 배포나 서버 인증 설정 변경은 없다.

## 사용 방법

앱을 열고 **하린식품 연결**을 누른다. 유효한 로그인 세션이 있으면 비밀번호창 없이 저장 주문을 조회한다. 처음 연결하거나 서버 세션이 만료되면 짧은 로그인창이 열린다. 기존 서버 만료 시간은 12시간이며 앱에서 임의로 연장하지 않는다. 앱 실행만으로 운영 서버를 자동 조회하지 않는 기존 원칙은 유지한다.

비밀번호를 앱에 저장하지 않는다. 앱 전용 저장소에 인증 세션을 유지한다. **연결 해제** 또는 **샘플 화면으로**를 선택하면 세션을 지운다. 삭제 실패 시 이를 성공으로 표시하지 않으며, 다음 실행에서 미완료 삭제를 먼저 재시도한다. 다른 웹 브라우저의 로그인에는 영향을 주지 않는다. 이전 버전은 메모리 세션이므로 이번 업데이트 직후에는 한 번 로그인해야 할 수 있다.

## 변경 내용

- 초기 로그인 페이지 로딩이 정상적인 로그인 제출로 취소되는 경우, ERR_ABORTED를 일반 로딩 실패로 처리해 창을 닫던 경로를 수정했다. 허용된 정확한 로그인 제출 주소에서 발생한 취소만 예외로 처리한다. 실제 네트워크 오류와 금지된 주소는 계속 차단한다.
- 앱 로그인창에서 긴 웹 소개 영역을 숨겼다. 로고, 비밀번호 입력, 로그인 버튼, 12시간 유지 안내가 한 화면에 보인다. 서버 폼·비밀번호 검증·인증 경로는 그대로 사용한다.
- 앱 전용 영속 세션과 재연결 시 기존 세션 우선 조회를 추가했다.
- 세션 삭제 미완료 표식을 남겨, 재시작이 삭제 실패를 우회하지 않도록 보완했다.

## 검증 결과와 범위

- 데스크톱 단위 테스트 **44/44 통과**.
- 기존 허브 테스트 **2,541/2,541 통과**. 웹 코드 변경 없음.
- 실제 Electron을 세 번 실행하는 격리 시험에서 시험 쿠키의 재시작 후 유지, 유효 세션 로그인창 생략, 연결 해제 후 재시작 시 삭제를 확인했다. 실제 비밀번호/인증 쿠키 대신 시험 값을 사용했다.
- 설치된 0.8.0 EXE에서 공식 로그인창 표시·세로 스크롤 없음·빈 시험 POST 허용 경로를 확인했다. POST는 네트워크 전송 전에 취소했다. 실제 비밀번호 로그인 완료를 대신 검증한 것은 아니다.
- 설치 EXE의 주문 상태별 조회, 상세 표시, 라이트·다크와 3개 창 크기 검증 통과. 주문 HTTP 자료는 합성 시험 자료이며 실제 송장 발급은 하지 않았다.
- 패키지 내 실행 파일 8개와 소스 바이트 일치. 설치본 app.asar와 빌드본 SHA256 일치.
- 독립 코드 검토에서 세션 삭제 실패 위험을 찾아 수정했으며 재검토 통과.

과거 간헐 실패의 모든 경우가 같은 원인이었다고 단정하지 않는다. 재현한 초기 로딩 취소 경로를 수정했고 실제 Electron 로그인 경로 검사가 통과했다. 서버 지연이나 비밀번호 오류까지 제거한 것은 아니다.
