# P5-12 실제 설치·재실행 인수 보고

2026-09-08. 앱 버전은 **0.13.1 유지**. 이번 단계는 설치파일 생성에 그치지 않고 이 PC에 설치된 앱을 업데이트하고 실제 EXE를 검증했다. 앱 기능 코드 변경이나 새 버전 생성은 없다.

## 실제로 수행한 작업

1. Windows 사용자 설치 등록에서 기존 `Moaon Preview 0.9.0` 확인. 실행 중 MoaonPreview 프로세스가 없음을 확인했다.
2. 앞서 인도한 0.13.1 설치파일의 SHA256을 기존 보고서와 대조했다.
3. 사용자용 NSIS 설치를 실행했고 종료 코드 **0**을 확인했다. 관리자용 설치나 프린터 드라이버 설치는 하지 않았다.
4. 설치 직전 사용자 프로필 내 파일 **133개**를 해시로 검사하고 설치 직후 비교했다. 변경·누락 **0개**였다. 내용이나 인증 정보를 보고서에 기록하지 않았다.
5. Windows 설치 등록이 `Moaon Preview 0.13.1`로 갱신됐음을 확인했다.
6. 실제 설치 경로의 EXE를 기존 사용자 프로필로 두 번 실행했다. Electron 앱 버전도 두 번 모두 **0.13.1**이었다.

## 실행 시험 결과

| 항목 | 결과 |
|---|---|
| 설치 경로 | `C:\Users\a\AppData\Local\Programs\Moaon Preview\MoaonPreview.exe` |
| 기존 사용자 프로필 사용 | 일치 |
| 메인 화면 및 설정 이동 | 두 실행 모두 통과 |
| 기존 테마 | 두 실행 모두 dark, 저장값과 표시값 일치 |
| 설정 화면 확인 중 pageerror | 없음 |
| 실행부터 화면 준비·설정 이동까지 | 1차 1,043ms / 재실행 709ms |

측정은 이 PC에서 한 차례의 두 실행 결과다. 로그인·주문 API 로딩, 장시간 성능, 모든 메뉴 성능을 측정한 것이 아니다. pageerror 수집도 화면 준비 이후 설정 이동 구간에 한정된다.

## 추가한 재검증 도구

`desktop/test/installed-restart-smoke.cjs --installed`

- 설치된 EXE·실제 사용자 프로필을 사용하므로 `--installed`를 명시해야 실행된다.
- 미완료 세션 정리 표시가 있으면 중단한다.
- 사용자 테마를 변경하지 않고 현재 저장값과 표시값 및 재실행 일치를 확인한다.
- 연결, 주문 수집, 송장 발급, 출력 버튼을 누르지 않는다.
- 자신이 실행한 앱을 시험 종료 시 정상 종료한다. 임의 프로세스를 강제 종료하지 않는다.

## 아직 완료로 표시하지 않는 항목

- **로그인 세션 유효성:** 설치 중 프로필 파일 보존은 확인했지만 실제 서버에 로그인 확인 요청은 보내지 않았다. 세션이 만료됐는지는 별도다.
- **실물 출력:** 이 PC에서 직전 확인된 프린터는 가상 프린터뿐이다. 출고 PC 및 실물 프린터 확인이 필요하다.
- **전체 P5 인수:** 실제 용지·바코드 판독·프린터 실패/재출력 검증이 남았다.

시험 종료 후 앱은 닫혀 있다. 바탕화면 바로가기 또는 위 설치 경로로 실행하면 된다. 설치파일은 0.13.1 기존 인도 파일을 그대로 사용했다. 유료 서비스 추가 신청이나 운영 DB 변경은 없다.
