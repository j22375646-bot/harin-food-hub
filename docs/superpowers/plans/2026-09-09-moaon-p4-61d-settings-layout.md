# P4-61D 설정 화면 배치 수정

사용자 화면에서 API 제목의 과도한 공백, 2열 그리드의 서로 엇갈린 카드, 높이가 없는 출고 기록, 불필요한 프린터 점검을 확인했다.

## 변경

- 화면·프로그램 정보 → 계정·사업장 → API 설정 → 출고 기록 순으로 DOM과 화면 순서 일치.
- 설정 전체 폭을 1160px로 제한하고, 카드 쌍을 별도 행으로 묶어 뒤의 카드를 밀어내지 않도록 수정. 1100px 이하에서 한 열로 표시.
- 카드 내부 여백 20px, 제목의 기존 최소 높이 82px 제거. API 안내의 중복 배경 박스 제거.
- 출고 기록에 정상 카드 높이·패딩과 버튼 스타일 적용. 접기·펼치기 기능 유지.
- 설정 하단 프린터 점검·제한 블록 제거. 기존 출력 기능 자체는 변경하지 않음.

## 검증

- 새로운 설정 화면 시험이 기존 코드의 API 제목 높이에서 실패하는 것을 확인한 뒤 수정.
- 1040/1440/2200px 카드 순서·너비·잘림·제목 높이·출고 기록 펼치기 검증.
- 앱 단위 테스트 285/285, 기존 API 입력·Windows 암호화 저장·삭제 화면 시험 통과.
- 실제 화면 이미지를 확인. 이번 범위는 UI 수정이며 API 인증·사업장 실제 연결 완료를 의미하지 않음.
