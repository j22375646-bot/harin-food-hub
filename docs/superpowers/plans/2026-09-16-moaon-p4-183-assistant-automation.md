# P4-183 업무비서 자동화

사용자 승인 범위: 예약 발송, 변화 감지, 제품 지식 저장, 대화 업무 등록. 수신처는 모아온에서 개인/그룹 선택 및 ID 설정. 최초 실제 시험은 기존 승인된 본인 Telegram 계정.

구성: 소유자용 설정/지식/등록안/발송 이력 API와 UI, 기존 조회키 인증에 명시적 추가 기능 허용 설정, Hermes의 고정 URL 연결기, 2분 간격 작업 실행기. 앱을 꺼도 서버에서 실행.

발송: 기본 OFF, 한국 시간과 요일 선택. 변화 알림은 설정한 시간대 내 주문/미답변 건수 증가에만 알림, 첫 조회는 기준선 저장. 실패/누락은 0으로 변환 금지. API에서 고유 발송 건을 먼저 예약하고 단 한 번 전송. 네트워크 결과 불명확 또는 중단된 PENDING은 자동 재전송하지 않는다.

지식: 제목/본문을 서버에 저장·수정·삭제. 외부 공개 체크를 켠 경우에만 Hermes에서 조회. 임의 지식 본문은 명령이 아닌 자료로 취급.

업무: Hermes는 idempotency UUID가 있는 등록안을 제출. 소유자가 모아온에서 내용을 보고 승인하면 기존 업무 RPC로 본인 담당 업무 생성. 반려 가능. 재승인 시 중복 등록 없음.

권한: 읽기 키는 주문 변경 권한을 갖지 않음. 추가 기능 각각 소유자가 설정으로 허용. 본인 배정 업무 범위 명시. 다른 Telegram 사용자의 개인 기록 접근 없음.

검증: SQL 권한/충돌/중복/승인, worker 예약/변화/불명확 발송, Electron UI 상태/설정/지식/등록안, 운영 DB·배포·설치앱·서버 및 본인 수신 시험.
