# P4-128 · 로그인 화면 통합과 모아온 디자인 (0.113.0)

## 변경
기존 로컬 ‘로그인하고 시작하기’ 페이지 뒤에 서버 로그인 폼이 나타나 두 단계로 보였다. 로컬 진입은 모아온 로고와 준비 상태만 보여주고 연결 확인 후 기존 서버 비밀번호 폼을 바로 표시한다. 실패/로그아웃에는 다시 연결 및 복구 버튼이 남는다.

서버 폼의 제출·검증을 유지하고 앱 전용 CSS로 연보라 브랜드 소개와 오른쪽 입력 영역을 구성했다. 모아온 두 아치 로고, 58px 비밀번호 입력란, 54px 제출 버튼, 오류 안내를 적용했다. 800px 이하는 단일 입력 카드로 전환한다. 별도 로그인 창은 만들지 않는다. 스타일 적용 전 WebContentsView는 숨겨 디자인이 바뀌어 보이는 현상도 줄였다.
