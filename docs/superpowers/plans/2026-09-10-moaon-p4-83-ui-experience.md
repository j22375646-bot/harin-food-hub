# P4-83 — 페이지별 UI 설계와 오늘 화면 첫 적용 / 0.71.0

## 방향
- [페이지별 UI 계획](./2026-09-10-moaon-ui-direction.md)에 8페이지의 핵심 질문·시각화·행동·실제 연결 기능을 기록했다.
- 첫 적용은 오늘/공통 화면 전환이다. 나머지 페이지를 모두 완성했다고 표시하지 않는다.

## 변경
- 주문 진행 현황을 우선 배치하고 기존 상태 카드를 클릭 가능한 SVG 가로 막대로 전환했다. 각 막대는 기존 주문 상태 조회 동작으로 연결된다.
- 조회된 상태 중 최대 건수 대비 길이만 표현한다. 0/실패/부분 확인을 구분하며 전체 비율·새 시계열을 만들지 않는다.
- 자금/일정을 아래 두 열로 배치하고 좁은 화면에서는 한 열로 재배치한다.
- 공통240ms 페이지 전환,160ms 버튼 상태 변화와 reduced-motion 지원. 페이지별 스크롤을 복원한다.
- 조회 중에는 aria-busy와 대기 표시/맥동 틀을 제공한다. 기존 병렬 조회와 재방문 요청 억제를 유지한다.
- 서버 응답시간 개선은 측정/입증하지 않았다. 이번 개선은 시각적 대기 상태와 이동 경험이다.
