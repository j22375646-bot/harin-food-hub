# P4-175 업무 검색과 닫기 통일

검색할 업무를 드롭다운에서 6개 버튼으로 전환. 열 때 자동 포커스, 현재 업무 선택, 항목별 입력 예시, Enter 검색, Esc 닫기 유지. 원천 조회 범위는 기존과 동일하게 표시.

dialog 공통 X만 표시하고 기존 닫기 버튼은 숨긴 채 원래 핸들러를 위임. 취소/저장 동작, disabled 잠금, cancel 이벤트 거부 유지. 비-dialog 패널의 텍스트 닫기는 접근성 이름을 보존하고 X로 변환.

검증: 기본 dialog 12개 및 동적 재생성/닫기 거부, 700/1440 light/dark 스크롤 검사 통과. 검색 10개 경로 레이아웃, 로컬/서버 주문 검색, CtrlK/Esc 통과. 일반 AI 회귀 통과. 최종 패키지 117개 파일 일치, 설치 0.147.12에서 검색 X 1개/6개 업무 선택/닫기 확인.
