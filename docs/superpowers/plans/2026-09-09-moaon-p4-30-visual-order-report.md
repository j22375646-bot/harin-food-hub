# P4-30 — 시안 누락 보완: 상품 이미지·채널/배송/사은품 뱃지

2026-09-09 / 앱 0.19.0. 사용자가 색상만 비슷하고 시안의 상품 정보가 빠졌다고 지적하여, 서버 지연 조사보다 UI 보완을 우선했다.

## 원인과 수정

서버 주문 응답의 items.imageUrl, gifts/giftRequired가 앱 Main 프로세스와 화면 데이터 변환에서 빠지고 있었다. 배송 상태는 상세에만 있었고 목록에는 일반 주문 상태 텍스트만 표시됐다.

| 항목 | 이전 | 이번 변경 |
|---|---|---|
| 상품 이미지 | 전달/표시 없음 | 주문 응답의 신뢰 가능한 CDN 이미지 표시, 지연 로드 |
| 상품 옵션 | 상세에만 표시 | 목록 상품명 아래에도 표시 |
| 채널 | 영문 텍스트 | Cafe24/네이버/쿠팡 채널 뱃지 |
| 배송 | 일반 단계 텍스트 | 서버 배송 상태가 있으면 예약/배송중/배송완료 뱃지, 없으면 실제 주문 단계 |
| 사은품 | 앱 표시 없음 | 서버가 판정한 사은품 동봉 뱃지, 상세 이름/수량 |
| 상세 시작 | 출고 제한 설명부터 | 상품 이미지·이름·옵션·사은품을 먼저 표시 |

기존 프리텐다드·라이트/다크·검색·정렬·초기화·상태별 조회·페이지 이동·발급 확인·라벨 기능을 유지했다. 출고 안전 안내는 삭제하지 않았다.

## 데이터와 보안

- 금액만 보고 사은품을 새로 추측하지 않는다. 서버가 전달한 giftRequired와 유효한 사은품 이름·수량을 표시한다. 캘린더 변경 반영은 주문 재조회 시점 기준이다.
- HTTPS 상품 CDN만 이미지 용도로 허용한다. 임의 호스트·로컬 주소·파일·인증정보 포함 URL은 차단한다. 원격 스크립트/XHR/문서 탐색 허용이 아니다.
- 이미지 요청에 쿠키·인증 헤더·Referer를 보내지 않는다. 허브 로그인 세션과 이미지 요청 세션은 분리한다.
- 이미지 없음/실패는 각각 이미지 없음/이미지 확인으로 표시한다. 무관한 사진을 대신 붙이지 않는다. 허용되지 않은 신규 CDN은 추가 검토가 필요하다.

## 검증

- 누락 재현 테스트 RED 확인 후 수정, 단위 시험 127 통과.
- 소스/패키지 콘텐츠 주문 도구: PNG 디코딩 성공, 이미지 실패 대체 표시, 예약 뱃지, 사은품 이름·2개 표시, 기존 필터·정렬·단축키·초기화·작은 창·라이트/다크 확인.
- 소스/패키지 콘텐츠의 가명 출고/라벨 시험 통과. 소스 로그인 시험 통과.
- NSIS 설치 파일 빌드 종료 0. 실제 발급/실제 인쇄는 하지 않는다.
- 테스트 PNG는 가명 자료다. 전체 운영 주문 이미지 성공률을 의미하지 않는다.
- 이 PC 설치 종료 0. 실제 EXE 0.19.0 두 번 재시작에서 기존 로그인·라이트 테마·사업장 1개 조회 확인(진입 3.5/3.1초). 별도 실제 주문 인수는 workspaceRead가 READY/PARTIAL이 아닌 응답을 반환하여 실패했다. 운영 주문 이미지 인수 완료로 표시하지 않는다.
