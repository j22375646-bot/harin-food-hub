# P4-53 전체 검색·기간별 엑셀 — 개발·검증 보고

## 현재 상태

2026-09-09 / 앱 **0.38.0** 구현·검토·운영 서버 적용·이 PC 설치·실제 검색 검증 완료. 시작 기준 c2b0181 / 0.37.0, 기능 최종 커밋 59894ba. 실제 우체국 발급·플랫폼 송장 전송·물리 출력 인수 완료를 뜻하지 않는다.

## 이번에 연결하는 기능

- 현재 화면의 20건 안에서 찾는 검색과 별도로, 서버에서 조회 가능한 전체 주문에서 주문번호·상품·채널을 검색한다.
- 한국 날짜 기준 시작일/종료일로 기간을 좁힌다. 선택한 주문 단계·채널·배송 지연·사은품 조건과 함께 적용한다.
- 같은 조건의 주문을 Excel에서 여는 XLSX 파일로 저장한다. 주소·전화번호는 이번 내보내기 열에 포함하지 않는다.
- 주문 상단의 `전체 검색·기간` 도구를 필요할 때 펼친다. 기존 앱 Pretendard, 색상, 목록 정렬, 오른쪽 상세 패널 동작을 유지한다.

전체란 서버 조회 범위 안의 전체 주문을 뜻한다. 플랫폼이 제공하지 않거나 기존 수집 보존기간 밖에 있는 주문까지 새로 수집하는 기능은 아니다. 새 수집과 송장 발급/전송을 자동 재실행하지 않는다.

## 기존 웹 기능을 앱에 연결하는 방식

기존 DB·서버·인증된 사업장별 주문 API를 사용한다. 웹 화면 전체를 앱 안에 넣거나, 사업장 확인을 우회하는 웹 엑셀 주소를 열지 않는다. 동일 후보 필터를 목록과 XLSX에서 공유한다. 하린식품 OWNER와 판매자배송 제한은 유지한다. 네이버/카페24/쿠팡의 주문은 채널을 구분하여 검색하며 로켓그로스는 출고 대상에 섞지 않는다.

## 안전 조건과 개발 판단

파일당 최대 5,000건/10MB로 제한하고 초과하면 기간을 줄이도록 안내한다. 날짜 범위 자체에는 임의 기간 제한을 추가하지 않는다. 대규모 내보내기가 필요하면 추후 별도 배치 작업이 필요하다.

일부 채널 조회가 실패한 경우 불완전한 파일을 정상 엑셀로 만들지 않는다. 검색 결과가 없으면 파일 대신 안내한다. 금액 미확인은 0원으로 바꾸지 않는다. 파일 저장 취소, 기존 파일 충돌, 로그아웃, 검색 조건 변경, 응답 지연을 각각 검사한다.

- 최종 서버 전체 `pnpm test` **2,616/2,616**, 앱 전체 **227/227** 통과. Next.js production build와 Windows 설치 파일 빌드 종료0.
- 첫 구현의 앱 bridge 기대값 실패2건을 수정했다. 독립 검토에서 검색 응답 조건 일치, 다운로드 용량·시간·중단 경계, 저장창 이후 인증/주문 재검증, 이전 검색 상태 초기화, 회귀 시험 부족을 보완했다. 전체 변경 검토에서 상품명·수량 등 엑셀 값 변경도 snapshot에 포함하도록 추가 수정한 뒤 최종 재검토 승인.
- 엑셀용 8개 필드만 추출하는 공용 함수를 파일 내용과 변경 검사에서 함께 사용한다. 일반 주문 페이지에서 전체 주문의 배송/수취/사은품 상세를 추가 계산하지 않으며 ExcelJS도 XLSX 요청에서만 불러온다.
- 서버0건/5,001건/부분 채널 실패, 날짜 오류, 엑셀 열·알 수 없는 금액, 수식 문자열, 검색 기준 불일치, 10MB 초과/지연/중복 요청, 로그아웃/목록 변경, 저장창 취소/기존 파일/저장 전 인증 변경을 검증했다.
- 최종 패키지 UI **10종** 통과: 전체 검색, 기존 서버 필터, 변경 감지, 자동출고, 수동등록, 목록도구, 수집, 배송추적, A4 작업 문서, 선택 문서. `--isolated --packaged`로 최종 app.asar를 개발 Electron에서 실행하는 시험이며 실제 설치 EXE 검증과 구분한다. 실제 외부 송장 쓰기는 모의 응답이다.
- 가명 화면에서 라이트/다크, 최소1040×720, 입력/버튼 정렬, 포커스 이동/접힌 영역 제외, reduced-motion을 검증했다. 최초 화면에서 발견한 기본 회색 버튼은 앱 전용 테마와 36px 높이로 보완했다.
- 무거운 서버 테스트·설치 빌드를 동시에 실행한 회차에는 기존 issue-register 시간 제한 시험2건이 실패했다. 부하 작업이 끝난 뒤 앱 전체를 단독 재실행하여227/227 통과했다. 운영 timeout이나 해당 assertion은 완화하지 않았다. 이 관측을 숨기거나 첫 실패를 통과로 기록하지 않는다.

## 사용법

1. 앱의 주문·배송에서 원하는 단계와 채널을 선택한다.
2. `전체 검색·기간`을 펼쳐 검색어 또는 기간을 입력하고 `검색 적용`을 누른다. 입력 중에는 반복 조회하지 않는다.
3. `엑셀 저장`을 누르면 같은 적용 조건으로 파일을 준비하고 Windows 저장창을 연다. 기존 파일을 덮어쓰지 않으므로 다른 파일명을 사용한다.
4. `조건 초기화`로 검색·기간을 지운다. 별도 현재 페이지 검색은 현재 보이는 주문만 걸러내며 전체 엑셀 조건이 아니다.

작은 창에서 검색 도구를 펼치면 목록 공간이 줄어든다. 도구를 접으면 목록 공간을 다시 사용할 수 있고, 내부 스크롤 기능은 유지하되 스크롤바는 숨긴다.
