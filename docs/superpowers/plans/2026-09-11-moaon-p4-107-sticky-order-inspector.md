# P4-107 · 주문 상세 스크롤과 작업바 정리 (0.93.0)

## 변경

- 주문 선택 시 닫기 버튼 포커스에 preventScroll 적용, 목록 스크롤 위치 유지. 상세 이전/다음 이동도 목록 강제 스크롤을 하지 않는다.
- 오른쪽 상세 패널은 주 화면 스크롤에 sticky로 따라붙으며 화면 높이에 맞춰 내부에서 스크롤한다. 기존 포커스를 빼앗는 외부 UI 조작은 사용하지 않았다.
- 상세 배송정보/요약의 dt/dd를 80px 라벨열과 같은 기준선으로 맞춘다. 상품 밑 뱃지들을 한 flex 그룹으로 묶고 높이·여백·줄바꿈 간격을 통일했다.
- 주문 시각만 Asia/Seoul 분 단위로 표시한다. 별도 조회/운영 기록 시각의 정밀도는 유지한다.
- 하단 작업바 오른쪽에 출고 작업표 A4를 직접 배치. 발급 조건 설명은 추가 작업 안에서 계속 확인할 수 있다.
- 문서 준비/완료 안내를 작은 떠 있는 안내로 표시. 완료/저장/취소는5초 후 숨기고 닫기 버튼도 제공한다. 문서 안내에서 관련 없는 송장 등록 설명을 제거했다.
- 실제 송장 진행/미확인 결과는 이 자동 숨김에 포함하지 않는다. 인쇄는 기존 미리보기에서 사용자 실행, 직접 자동 인쇄하지 않는다.
