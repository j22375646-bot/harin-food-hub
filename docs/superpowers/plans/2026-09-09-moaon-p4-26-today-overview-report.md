# P4-26 — 앱 오늘 업무 요약 / 0.17.0

작성일: 2026-09-09

## 이번에 사용할 수 있는 기능

이 PC의 모아온을 **0.17.0으로 실제 업데이트**했다. 기존 소개/연결 중심의 오늘 화면에 저장 주문 업무 요약을 추가했다. 운영 웹·API·DB는 변경하지 않았다.

| 기능 | 사용 방법 |
|---|---|
| 상태 카드 4개 | 송장 발급 전 / 송장 등록 후 / 배송중 / 완료·취소 건수를 확인 |
| 전체 상태 조회 | 네 가지 상태를 함께 새로 조회. 주문 목록의 현재 페이지는 변경하지 않음 |
| 주문 바로가기 | 카드를 누르면 해당 상태를 조회한 뒤 주문·배송으로 이동 |
| 조회 근거 표시 | 카드마다 조회 시각, 부분 확인, 실패/미확인을 구분 |

로그인 직후에는 이미 불러온 주문 상태가 자동 반영된다. 나머지는 해당 주문 상태를 열거나 **전체 상태 조회**를 누르면 갱신된다. 로그인 과정에서 네 번의 추가 조회를 강제하거나 주기적 조회를 새로 추가하지 않았다.

이 수치는 **오늘 새로 들어온 주문 수나 매출이 아니라 허브에 저장된 상태별 주문 수**다. 실제 0건은 0건, 조회하지 않았거나 실패한 상태는 확인 필요로 표시한다. 부분 확인 건수는 전체 건수로 판단하면 안 된다. 네 상태는 각각 조회하므로 같은 순간의 단일 거래 스냅샷을 보장하지 않는다.

## 구현 및 안전장치

- 기존 허용된 사업장 주문 GET 경로만 사용한다. 화면이 사업장·주소를 임의 지정할 수 없다.
- 조회 중복을 합치고 시간 제한·취소를 적용했다. 로그아웃/인증 실패 후 늦게 도착한 결과를 버린다.
- 주문 상세/개인정보가 아닌 상태·건수·조회 시각만 요약 결과로 화면에 전달한다.
- 인증 실패는 전체 요약을 비우고, 개별 상태 실패는 0건으로 변환하지 않는다.
- Frontend Design 스킬에 따라 기존 앱 색상·글꼴·다크모드를 재사용했다. 좁은 화면에서는 카드가 두 열로 배치된다.

## 검증 결과

- 새 요약 함수 미구현 상태에서 테스트 실패를 확인한 뒤 구현했다.
- 데스크톱 테스트 **124 통과 / 실패 0 / 건너뜀 0**.
- 가명 Electron 소스 및 패키지 화면 시험: 0건/미확인 구분, 부분 확인, 라이트/다크, 가로 넘침 없음, 카드 이동, 로그아웃 비우기 통과.
- 연결 테스트: 요약 조회가 선택 상태를 바꾸지 않음, 중복 요청 합치기, 시간 초과, 해제 취소, 인증 실패 시 전체 폐기 통과.
- 설치 파일 SHA256 대조 후 설치 종료 코드 0. 기존 프로필을 삭제하지 않았다.
- 실제 설치 EXE 두 번 실행에서 버전 0.17.0, 다크모드, 로그인 유지 확인.
- 실제 저장 주문: 발급 전 1건 / 등록 후 0건 / 배송중 2건 / 완료·취소 87건. 완료 목록 다음·이전 20행과 새 전체 상태 요약 조회 통과.
- 실제 시험을 두 번 반복했고, 두 시험 모두 두 번째 재실행에서 사업장 목록 오류 안내가 나타났다. 첫 실행에서는 소속 1개와 업무 버튼이 정상이며 주문/전체 요약 조회도 성공했다. **재실행 직후 사업장 목록의 간헐적 실패는 미해결**이다. 시험의 PASS는 로그인/주문/요약에 대한 것으로, 사업장 목록 매회 성공을 뜻하지 않는다. 이 문제는 별도 원인 확인이 필요하다.
- 실제 시험에서 화면 스크립트 오류 없음. `git diff --check` 통과.

송장 발급·고객 알림·프린터 출력은 실행하지 않았다. 이번 검증으로 전체 플랫폼 수집이나 출고 PC 프린터까지 정상이라고 판정하지 않는다.
