# P4-41 — 페이지 이동 후 출고 확인 목록

2026-09-09 / 모아온 Windows 0.27.0

## 변경

페이지 변경 시 즉시 결과 영역이 초기화되어 대기 작업을 놓치기 쉬웠다. 자동 출고의 PENDING/FAILED/CHECK_REQUIRED 및 응답 확인 불가 주문을 별도 세션 메모리 목록에 보관한다. 자동 출고 REGISTERED 결과를 확인하면 그 주문을 목록에서 제거한다. 서버 기록/중복 방지 원장은 수정하지 않았다.

UI에는 ‘이번 실행의 출고 확인 목록’을 기본 접힘으로 표시한다. 각 항목은 ‘이전 결과’로 표시하며 실시간 상태로 주장하지 않는다. 현재 로드된 페이지의 주문은 ‘주문 확인’으로 상세를 연다. 텍스트 검색/검토 필터로 가려져 있으면 해당 필터를 초기화한 후 연다. 페이지 밖 주문은 버튼을 비활성화하고 채널·구간·페이지 확인을 안내한다.

주소·연락처·상품명은 이 보조 목록에 저장하지 않는다. 주문 식별자와 과거 상태만 메모리에 유지한다. 로그아웃·재연결·인증 실패 시 지운다. 앱 종료 시에도 사라진다.

취소한 확인창이나 BUSY 응답만으로 새 작업을 생성하지 않는다. 기존 세션 항목은 유지한다. 이 목록의 버튼은 상세 열기만 수행하며 자동 발급/재전송하지 않는다.

## UI 디테일

기존 모아온 surface/line/ink 색상과 폰트를 재사용했다. 별도 시안으로 교체하지 않았다. 접힘 제목의 키보드 포커스와 비활성 버튼의 명도를 명확히 하고 기존 패널 모션을 유지한다. 작은 창 시험 화면에서 가로 넘침이 없음을 확인했다.

## 검증

- 페이지 이동 후 보조 목록 부재를 먼저 재현한 뒤 수정.
- 자동 출고 UI: 페이지 변경 후 대기 항목 유지, 이전 결과 문구, 페이지 밖 버튼 비활성, 목록 복귀 후 해당 주문 열기, 로그아웃 데이터 제거 통과.
- 자동 출고 UI의 개발 런타임 및 패키지 app.asar 검사 통과.
- 배송정보 조회/발급 조건 재확인 UI 회귀 통과.
- 단위 시험 161/161 통과. 본 변경은 UI 상태 시험을 확장했으며 단위 시험 개수는 동일하다.
- NSIS 빌드 성공. 패키지 UI 시험은 개발 Electron에서 실행했고 운영 송장은 사용하지 않았다.
- 설치 종료 코드 0. 실제 설치 0.27.0 재실행 2회 로그인 유지 확인(진입 3.123초/2.487초, 측정 시점 값).
- 실제 서버 주문 네 구간 및 완료 목록 다음/이전 페이지 조회 통과. 운영 발급·등록 요청 없음.
- 설치 앱의 정렬 오차 0px, 패널 접힘/확장 22프레임 변화, 내용 유지·inert·스크롤바 숨김 검사 통과.

## 한계와 다음 단계

이번 목록은 자동 발급·등록 결과용이다. 수동 송장 등록 결과의 통합, 앱 재시작 후 영구 이력 복원, 페이지 밖 주문 자동 탐색은 포함하지 않는다. ‘주문 확인’은 상세를 여는 동작이며 최신 서버 상태 재조회와 실제 발급은 기존 별도 확인 흐름을 이용한다.

실제 우체국 발급·플랫폼 송장 등록·물리 출력은 이번 실행에서 수행하지 않았다. 다음은 기존 서버/로컬 작업 원장을 활용한 재시작 복원 범위와 조회 전용 작업 검색을 검토·구현한다. 운영 인수 완료 전까지 주문 페이지를 우선한다.
