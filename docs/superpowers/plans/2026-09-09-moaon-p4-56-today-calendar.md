# P4-56 / 0.40.0 — 오늘 일정 연결

## 구현 내용

- 로그인 후 오늘 페이지에서 한국 날짜 기준 일정을 자동 조회한다. 재진입은 마지막 시도 후 1분이 지나면 조회하며 상시 폴링하지 않는다.
- 기존 웹 일정 API와 DB를 그대로 사용한다. 웹 화면을 삽입하지 않고 앱 전용 일정 목록을 구현했다.
- 시간/종일, 제목, 예정/완료 상태를 앱의 기존 폰트·색상·간격으로 표시한다. 긴 제목은 줄바꿈하고 상태 글자는 가로로 유지한다.
- 수동 일정 조회, 로딩, 조회 실패, 정상 빈 목록을 구분한다. 오류를 일정 0건으로 표시하지 않는다.
- 새 조회 전 하린 사업장 주문 조회 경로로 권한을 확인한다. 고정 API의 당일 GET만 메인 프로세스에서 허용하며 임의 URL, 렌더러 직접 요청, 쓰기 요청은 허용하지 않는다.
- 응답에서 제목·날짜·시간·완료 상태만 추출한다. 원문 본문과 불필요한 필드는 화면으로 보내지 않는다. 로그아웃·요청 시간 초과·늦은 응답을 처리한다.

## 검증과 설치

- 신규 테스트의 실패를 확인한 후 구현. 앱 단위 테스트 236개 통과.
- 최종 패키지 일정 UI, 오늘 주문 요약, 자동 발급 UI, 화면 레이아웃 4종 통과. 자동 발급 검사는 가상 응답이며 실등록 성공 증거가 아니다.
- 0.40.0 설치 프로그램 실행 종료 코드 0, 설치된 app.asar와 빌드 산출물 SHA256 일치.
- 설치 앱의 기존 로그인으로 실제 일정 API 읽기 성공. 2026-09-09 한국 날짜 기준 서버 반환 일정 0건을 정상 빈 목록으로 표시했다. 일정 쓰기나 운영 주문 변경은 실행하지 않았다.

## 완료 범위와 남은 점

오늘의 일정 조회 연결만 완료했다. 일정 생성·수정·완료 처리·삭제, 월간 캘린더 페이지, 다른 사업장 일정 연결은 이번 범위가 아니다.

기존 서버 API는 지난 366일을 조회한 뒤 최대 500행에서 당일 겹침을 필터링한다. 기존 제한을 변경하지 않았으므로 장기·대량 일정의 완전성까지 보증하지 않는다. 캘린더 전체 이식 시 서버 페이지 처리와 사업장별 저장 분리를 함께 보완해야 한다.

우체국 실제 발급부터 플랫폼 등록까지의 실출고 인수는 기존과 같이 대상 부재로 대기 중이다. 과거 테스트용 발급 및 가상 플랫폼 응답 검증을 실제 등록 완료로 표시하지 않는다.
