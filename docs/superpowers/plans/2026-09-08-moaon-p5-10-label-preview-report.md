# P5-10 송장 미리보기·인쇄 연결 — 0.13.0 인도 보고

## 최신 결과: 2026-09-08 후속 개발

**0.13.0 설치파일 생성 및 패키징된 앱 코드 검증 완료.** 아래 중간 보고의 배포 보류 사유를 해결했다. 사용자 앱 자동 설치나 실제 프린터 출력은 하지 않았다.

### 원인과 수정

1. `javascript:false` 창에서 일반 `executeJavaScript`로 문서를 검사해 실행이 거부됐다. 원격 페이지의 스크립트 차단을 유지하고, 고정된 앱 검사 코드만 격리 영역 999에서 실행하도록 수정했다.
2. 한글 앱 이름이 User-Agent에 포함되어 Electron 합성 HTTPS 프로토콜의 헤더 변환에서 ByteString 오류 및 `ERR_UNEXPECTED (-9)`가 발생했다. 화면 제목은 그대로 유지하고 통신용 User-Agent만 ASCII로 정리했다. 이 재현은 합성 프로토콜 경로에서 확인한 것이며 모든 실제 인터넷 접속 오류의 원인이라고 단정하지 않는다.
3. 화면 버튼 시험의 수취인 표본을 주문 응답과 일치시키고, 연결 해제 버튼이 있는 오늘 화면에서 종료 동작을 확인했다.

### 이번에 직접 확인한 결과

- 데스크톱 자동 테스트 **99/99 통과**.
- 단독 실제 Electron 미리보기: `PREVIEW_OPEN`.
- 실제 Main/preload/IPC 연결 시험: 미리보기 열림, 원격 스크립트의 DOM 변경 차단, 연결 해제 시 창 종료 확인.
- Playwright 실제 화면 버튼 시험: 개발 코드와 패키징된 `app.asar` 모두 통과. 패키지 시험은 격리 프로필의 개발 Electron 런타임으로 실행했으며 설치 마법사 실행 시험과는 다르다.
- 독립 읽기 전용 검토: Critical/Important 결함 없음. 리뷰어 관련 테스트 50/50 통과.
- `npm run pack` 성공. Windows x64 NSIS 설치파일 생성.
- `git diff --check` 통과. 웹 서버 코드/운영 DB 변경 및 Vercel 재배포 없음.

### 설치파일과 사용 방법

파일: `output/moaon-preview-0.13.0/Moaon-Preview-0.13.0-Setup.exe`

SHA256: `D1FE37F6B7D1B8E0D4BD67708AD55A0CA921D092A9CAD4B93CABF12860FD0679`

서명: **NotSigned**. Windows에서 게시자 확인 경고가 나올 수 있다. 기존 앱은 자동 교체하지 않았다.

앱에서 하린식품 연결 → 주문·배송 → 등록된 카페24/쿠팡 판매자배송 주문 선택 → **기존 송장 미리보기·인쇄** → 미리보기 창의 **인쇄 설정 열기**를 선택한다. 인쇄 전 수취인·송장번호와 실제 용지를 확인한다. 플랫폼 등록 전 송장 및 네이버 송장은 이번 출력 범위에서 제외된다.

## 이번 작업

- 앱 주문 상세에서 이미 플랫폼에 등록된 카페24·쿠팡 판매자배송 송장의 미리보기·인쇄 진입 경로를 추가했다.
- 발급 요청을 다시 보내지 않고 기존 인쇄 조회 API만 사용한다. 신규 발급이나 실물 프린터 출력은 실행하지 않았다.
- 주문·송장번호·수취인·연락처·주소 대조, 인쇄 직전 주문 재조회, 취소 주문 차단을 구현했다. 수취인 원문은 Main 내부 WeakMap에서 관리하며 앱 UI IPC나 작업 기록으로 추가 전달하지 않는다.
- 미리보기 창의 외부 스크립트·새 창·다른 주소 이동을 차단하고 연결 해제 시 창을 닫는다. 자동 인쇄는 하지 않으며 명시적인 확인 후 시스템 인쇄 설정을 호출하는 코드다.
- 패키지 파일 목록에 새 모듈을 포함했다. 패키징 자체는 아직 실시하지 않았다.

## 검증 결과와 발견한 문제

| 검증 | 결과 |
|---|---|
| `node --test desktop/test/*.test.cjs` | 99개 통과, 0개 실패 |
| 독립 코드 검토 | 패키지 파일 누락·수취인 대조 누락·취소 상태 누락 발견 후 수정. 수정본 최종 재검토는 미완료 |
| 실제 Electron 단독 창 | 합성 HTTPS 문서의 HTTP 200 이동 확인. 이후 `executeJavaScript` 내용 검사에서 `Script failed to execute` 발생 |
| 전체 앱 Playwright 시험 | 미리보기 이동 `ERR_UNEXPECTED (-9)` 재현. 단독 창 실패와 동일 원인이라고 확정하지 않음 |
| 실제 주문 발급·프린터 출력·설치 앱 교체 | 실행하지 않음 |

99개 통과는 모의 OS 경계와 로직 시험 결과이며 실제 출력 기능 완료를 뜻하지 않는다. 보안을 낮춰 오류를 숨기지 않았고, 실패한 미리보기를 정상 기능으로 배포하지 않는다. 이번 변경은 개발 브랜치 `codex/moaon-print-preview`에 남긴다.
