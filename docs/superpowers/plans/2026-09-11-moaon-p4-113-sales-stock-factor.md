# P4-113 · 주문 자동 재고 차감과 세트 구성 (0.99.0)

## 사용 방법

- 재고 등록에서 카페24 상품을 연결하면, 확인된 카페24·네이버·쿠팡 판매자배송 연결에 주문 수량당 **1단위** 규칙을 기본 생성한다. 상품명에 적힌 2개/3개/5개 등을 임의로 추정하지 않는다.
- **재고 → 자동 차감 · 세트 구성**에서 상품·옵션별 차감할 재고와 구성 수량을 변경하고 저장한다. 3개입을 3으로 저장하면 주문 수량 2개는 6단위 차감한다. 기존 수정값은 재고 재등록/기본 연결 확인으로 초기화하지 않는다.
- KG는 소수 셋째 자리까지, 개/티백/박스는 정수로 설정한다. 단위 간 변환이나 서로 다른 상품으로 구성된 묶음의 BOM 계산은 자동 추정하지 않는다.
- 주문 목록 채널·주문시각·결제금액·상태의 헤더와 값은 같은 격자의 중앙에 정렬했다. 좁은 화면의 목록 재배치는 유지한다.

## 서버 처리

- 공유 DB에 설정·수집 이벤트·차감 원장·처리 오류 기록을 추가했다. 기존 주문 수집의 원본 테이블 INSERT/UPDATE 트리거에서 처리하므로 앱을 열어 두지 않아도 서버 수집 시 적용된다. 외부 플랫폼 재고 수량을 변경하는 기능은 아니다.
- 최초 연결 시점 이전 주문은 소급 차감하지 않는다. 이미 차감된 주문은 설정이 바뀌거나 재수집돼도 다시 차감하지 않는다. 설정 변경은 미차감 주문 처리에 적용되므로 재고 부족으로 보류된 주문을 재확인하기 전에 구성 수량을 확인한다.
- 같은 사업장 재고 수정과 동일한 트랜잭션 잠금을 사용한다. 유통기한이 빠른 제조번호부터 차감하고, 만료/단위 불일치 재고는 제외한다. 수량이 부족하면 일부만 빼지 않고 보류한다.
- 출고량·재고 수정 버전 이력을 남긴다. 취소/반품/주문 변경은 실물 확인 대상으로 표시하며 자동 복구하지 않는다. 기존 입고/출고 기능으로 확인 후 조정한다.
- 카페24에 유입된 다른 마켓 주문, 로켓그로스는 직접 재고 차감에서 제외한다. 네이버 원상품/채널상품 식별자는 같은 구성값으로 저장한다. 쿠팡은 원본 주문상품 ID가 있을 때 배송 묶음 ID 변경에도 같은 항목으로 처리한다.
- 채널 연결이 모호하면 임의의 카페24 재고에 매핑하지 않는다. 카페24/네이버 옵션 기본 규칙과 구체 옵션 규칙 중 구체 규칙을 우선한다.
- 네 테이블 RLS 활성화, anon/authenticated 접근 차단, 서버 service_role 경로만 허용. 앱의 저장 요청에는 기존 사업장 소유자·Origin·권한 재검사를 유지했다.
