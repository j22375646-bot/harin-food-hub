# P4-130 · 업무·일정 디자인과 프로필 사진

## 반영

- 업무·체크리스트를 겹친 카드 대신 구분선 중심 행으로 정리. 담당자, 기한, 완료 상태와 체크리스트 진행률을 구분했다.
- 업무 등록에 항목별 체크리스트 입력·추가·삭제·Enter 추가를 제공한다. 담당자/날짜를 나란히 배치하고 일정·프로필 폼의 간격과 타이포그래피를 통일했다.
- 기존 공통 선택창 CSS가 `.page` 내부에만 적용되어 dialog에서 누락되던 원인을 수정했다. 네이티브 키보드 접근성과 top-layer 선택 메뉴를 유지하며 dialog에도 공통 스타일을 적용한다.
- 최종 사용자 정정: 기본은 나의 업무, 전체 업무는 필터. 세 사람 모두 같은 사업장의 모든 업무를 조회·체크·완료 처리할 수 있다.
- 달력 날짜에 업무 제목·프로필을 표시하며 완료 업무를 구분한다. 날짜를 선택하면 옆 목록에서 상세 열기·체크 처리를 한다.
- 프로필 사진 등록/변경/삭제, 미리보기. JPG/PNG/WebP 8MB 이하를 앱에서 중앙 정사각형 128px JPEG로 변환하여 서버 프로필에 저장한다. 원본 파일/메타데이터는 업로드하지 않는다. 상단, 담당자 선택, 업무 담당자 및 달력에 재사용한다.
- 새 migration `20260912020136_moaon_profile_avatar`는 기존 세 계정과 사진 없는 구버전을 보존한다. 사진 생략한 구버전 프로필 저장은 기존 사진을 지우지 않는다. 동일한 세션/사업장 검증과 revision 충돌 처리를 유지한다.
