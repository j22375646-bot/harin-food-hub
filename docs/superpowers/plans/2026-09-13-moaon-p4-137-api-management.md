# P4-137 API 연결 관리 · 0.124.0

사용자 승인 범위: 쿠팡 키 교체, 저장 키 확인·수정, 만료일·실제 연결 재확인, Cafe24 PG 연결 검토. 세 계정은 동일한 OWNER 권한을 유지한다.

## 적용 결과

- 설정 > API 연결에 쿠팡, 네이버 커머스·광고, 카페24, 우체국 카드를 추가했다. 기본 가림, 명시적 원문 보기, 수정·저장, 만료일, 연결 재확인을 제공한다.
- 기존 사업장 식별자는 고정하며 암호화 저장·설정 버전 비교·활성 세션/멤버십 재검증으로 보호한다. 원문은 이동·닫기·저장·로그아웃 시 지운다.
- 서버와 고정 IP 수집기가 같은 암호화 설정을 읽는다. 쿠팡/커머스/우체국은 AWS, 네이버 광고/Cafe24는 웹 서버에서 점검한다. 네이버 두 점검은 같은 설정 버전일 때만 합친다.
- 알려진 쿠팡 만료일: 2027-03-12 01:54 KST. 다른 키의 만료일은 공급사 근거 없이 추정하지 않는다. Cafe24 상품 조회 성공은 OAuth 접근 성공이며 제한된 정산 권한까지 뜻하지 않는다.

## 실제 운영 검증

- Wing 원문에서 확인한 키로 Vercel과 AWS 환경을 교체했다. 이미지 OCR 후보의 401은 원문 재대조로 해결했다. 로컬 PC는 허용 IP가 아니므로 로컬 403을 인증 실패로 오판하지 않았다.
- AWS가 제공한 호스트 공개키 지문과 SSH 지문을 대조하고 접속했다. PENDING/RUNNING 요청이 없는 것을 확인한 후 수집 서비스를 짧게 중지·재시작했다.
- 쿠팡 상품 조회 HTTP 200 / SUCCESS, 실제 상품 1개 응답 확인.
- 2026-09-13 02:43 KST 기준 네이버 커머스 상품/광고 캠페인, Cafe24 상품, 우체국 접수국 조회 모두 CONNECTED. 최소 결과와 확인 시각만 DB에 저장했다.
- 최종 웹 배포: dpl_24Xn29FhhaHmGDeqYdDuSGDs4Ce8, READY 및 운영 alias 확인.
- worker 실행 위치: /opt/harin-food-hub/releases/managed-20260913. systemd override로 경로 변경. active/running, NRestarts=0, 환경 파일 0600 확인. 기존 current 디렉터리는 보존했다.
- 배포 시 명시적으로 MOAON_VERIFY_CONNECTIONS=1을 주면 웹 환경에서 조회 검증을 수행한다. 기본 배포에서는 외부 조회를 추가하지 않는다.

## 자격정보 이전 주의점

- Vercel sensitive 환경변수 다운로드는 실제 값 대신 마스킹 문자열을 돌려준다. 이를 유효 키로 이전하지 않는다. 초기 준비 중 잘못 생성된 마스킹 기반 후보 행은 기능 활성화 전에 수정/제거했다.
- 쿠팡·우체국은 실제 worker 설정을 암호화 이전했다. 네이버는 worker의 커머스 필드만 이전하고 광고 필드는 실제 웹 환경을 사용한다. Cafe24는 기존 웹 환경을 사용한다. 사용자가 저장하면 모든 필드를 완전한 암호화 스냅샷으로 전환한다.
- 암호화 root는 웹과 worker에 동일하게 설정하고 로컬 DPAPI 복구본을 보존한다. 코드/설치파일에는 넣지 않는다.
- 임시 키/환경 평문 파일은 작업 후 제거한다. 다른 사업장·Supabase 관리자 자격정보·서버 암호화 root를 앱에 노출하지 않는다.

## Cafe24 PG

첨부 화면의 이용 중 PG는 KCP, KG파이낸셜 휴대폰결제, PAYCO이다. PG 사용 등록과 모아온의 지급 원장 연결은 별개다.

- KCP: https://developer.kcp.co.kr/reference/search — site_cd, 서비스 인증서와 RSA 개인키 기반 거래 조회. 거래의 정산 상태를 실제 지급 정산 원장 전체로 간주하지 않는다. 인증서 발급은 계약 가맹점 기준으로 확인한다.
- KG파이낸셜: https://www.mobilians.co.kr/doc/download — 가맹점 서비스 ID와 계약별 정산 제공 방식 확인이 필요하다.
- PAYCO: https://partner.payco.com/ — 가맹점 ID, Cafe24 대행/직접 계약 여부, 정산 자료 제공 권한 확인이 필요하다. 공개 지급 원장 API는 이번 조사에서 확인하지 못했다.

PG 자격정보/계약 확인 없이 연결 성공을 표시하거나 결제 승인 API로 지급 원장을 대체하지 않았다. PG 연결과 배송유형 미분류 원장 재분류는 이번 키 교체만으로 해결 완료라고 표시하지 않는다.
