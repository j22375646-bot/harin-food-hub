# P4-54 / 0.38.7 자동 이력 조회 유지

## 로그인 검사 정정

설치본을 읽기 전용으로 실행하여 로그인 상태와 쿠키 메타데이터만 확인했다. 로그인 화면은 `로그인이 필요합니다. 아래 버튼으로 시작하세요.`를 표시했고 해당 서버의 저장 쿠키는0개였다. 이전30초 검사는 로그인 성공만 기다렸으므로, 그 시간 초과를 서버 응답 지연으로 해석할 근거는 없다. 쿠키가 없어진 원인이나 로그인 저장 기능의 정상 여부까지 입증한 것은 아니다. 비밀번호 입력·저장 자료 삭제·인증 우회는 하지 않았다.

## 수정

자동 이력 조회는 주문 페이지 이동과 무관한 세션 단위 조회인데, 기존 코드에서는 주문 페이지 요청 번호가 바뀌면 그 응답을 버렸다. 별도 세션 세대 번호로 분리했다.

- 같은 로그인 세션에서 주문 목록을 이동해도 등록 이력·미완료 출고 복원 응답을 유지한다.
- 이력의 주문 찾기 버튼도 페이지 이동만으로 무효화하지 않는다.
- 로그인 변경·로그아웃·샘플 복귀 시 이전 세대의 응답을 버린다.
- 서버 쓰기와 송장 등록 요청의 중복 방지는 변경하지 않았다.

## 검증

수정 전 페이지 이동 후 이력 표시 테스트가 실패했고 수정 후 통과했다. 로그아웃 후 늦은 응답 숨김도 확인했다. 앱 단위231개와 단건/일괄 송장 등록 UI 검사 통과. 합성 응답 시험이며 실제 플랫폼 등록 성공을 의미하지 않는다.

## 남은 작업

0.38.7 패키징 성공. 최종 app.asar로 자동 이력·자동 발급 UI·단건/일괄 등록 UI3종 통과. 이 PC 설치 종료0, 패키지와 설치본 app.asar 해시 일치. 기존 로그인 프로필은 삭제하지 않았다. 운영 서버 변경은 없다.

실제 플랫폼 등록·결과 복구 인수는 미완료다. 실제 주문을 임의로 변경하거나 가짜 송장을 등록하지 않았다. 로그인 세션이 없는 상태에서 실주문 인수를 완료로 표시하지 않는다. 주문 인수를 마친 뒤 오늘 페이지로 진행한다. 서버 변경과 신규 과금은 없다.
