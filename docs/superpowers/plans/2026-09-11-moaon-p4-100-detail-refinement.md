## 쿠팡 제한 설명
- 판매자배송은 기존 자동 발급·등록 대상 경로다. 로켓그로스는 별도 처리다. 배송정보/송장 이력/취소 상태/서버 허용/배송묶음 번호가 충족돼야 버튼이 켜진다.
- 기존 서버 shippingBlockedReason을 앱 투영에서 버리던 문제를 수정했다. 서버 조건 제한 시500자 이내 일반 텍스트로 보존해 선택 영역과 상세에 표시한다.
- 배송묶음 번호가 없을 때 SHIPMENT_ID 사유를 노출한다. 기존 발급 허용 조건을 무조건 우회하지 않는다. 가상 쿠팡 주문의 비활성 사유/긴 상품명 레이아웃을 확인했다.
- 사용자가 첨부한 실제 주문의 최신 제한 사유와 실송장 등록 성공은 아직 확인하지 않았다. 운영 발급·등록을 테스트 목적으로 실행하지 않았다.

## 캘린더 등록
- 캘린더에 일정 등록 폼을 추가했다. 제목/날짜/선택 시간/일정 또는 메모/내용을 입력한다.
- 하린식품의 기존 /api/calendar/entries CREATE_ENTRY에 연결했다. 새 서버 배포는 하지 않았다. 기간/행사/편집/삭제 기능은 이번 등록 범위에 포함하지 않는다.
- 고정 IPC,정확한 필드 검증,인증된 월 조회,네이티브 저장 확인1회,Main의 제한된 POST,로그아웃 세대 검사,15초 요청 제한,중복 제출 차단을 적용했다. 운영 비밀번호를 자동 입력하지 않는다.
- 성공은 서버 반환 ID/제목/날짜까지 확인하고 월 목록을 재조회한다. 오늘 일정 캐시도 무효화한다.
- POST 결과가 불명확하면 자동 재전송하지 않고 동일 내용 재등록을 현재 연결 인스턴스에서 잠근다. 이 잠금은 서버의 영구 idempotency 기능이 아니다. 일정 새로 조회로 저장 여부를 확인해야 한다.
