# P4-138 · 트레이 상주와 백그라운드 알림 · 0.125.1

## 사용 방법

- 창의 닫기(×)는 창을 숨기며 모아온은 Windows 오른쪽 아래 트레이에 남는다. 일반 작업표시줄에서는 숨긴다.
- 트레이 로고 클릭 또는 메뉴의 **모아온 열기**로 복원한다. **모아온 종료**를 선택하면 완전히 종료한다.
- 업데이트 설치와 Windows 종료는 숨김 대상으로 취급하지 않는다. 트레이 생성에 실패하면 기존 정상 종료 동작을 유지한다.
- 내 프로필의 Windows 알림 설정을 주문·문의·업무·일정 알림에 적용한다. 세 사용자 권한은 변경하지 않는다.

## 백그라운드 동작

- Electron Main의 독립 타이머로 업무 상태를 약 15초마다 확인한다. 창을 숨긴 상태에서 renderer의 타이머 제한에 의존하지 않는다.
- 주문·문의·오늘 일정 저장 자료를 약 1분마다 조회한다. 주문 수집 약 2분, 문의 수집 약 5분으로 기존 서버/고정 IP 수집 경로를 호출한다. 서버 처리/네트워크 시간에 따라 지연될 수 있으며 초 단위 실시간 push는 아니다.
- 주문 수집과 문의 수집은 별도 비동기 단일 실행으로 진행하여 오래 걸리는 수집이 업무 확인 루프를 막지 않게 한다. 수동 주문 수집의 작업 번호와 결과 상태는 분리 보존한다. 불확실한 자동 수집은 기존 번호 조회 후 10분 경과 시 새 읽기 수집으로 재시도한다.
- 첫 성공 조회는 기존 자료의 기준선으로 기록한다. 새 주문·문의는 종류별 묶음 알림으로 보낸다. 수신 ID는 사용자별 해시로 저장하며 Windows 표시 성공 후만 완료 처리한다. 알 수 없는 주문 날짜를 새 주문으로 추정하지 않는다.
- 나에게 배정된 새 업무(본인 배정 포함), 오늘 마감인 미완료 업무, 시작 10분 전 일정/오전 9시 종일 일정을 알린다. 알림 클릭은 작업표시줄 복원 후 해당 페이지를 연다.
- 프로필 변경·로그아웃 후 이전 사용자 알림 클릭/지연 응답을 적용하지 않는다. 주문 조회는 현재 화면의 검색·필터·페이지·선택을 바꾸지 않는다.
- 문의 수집 실패가 이후 주문 성공에 덮이지 않도록 상태를 유지한다. 연결/로그인/자료 잘림은 트레이에서 확인 필요로 표시한다.

- 숨긴 창에서 합성 배정 업무의 실제 Windows Notification `show` 이벤트 PASS. 실제 사용자 계정 업무/실주문 알림 시험, 사용자 PC 스피커 소리와 사장님 PC 수신은 별도 확인 범위다.
- 패키지 원본 파일 88개 대조 PASS. 설정 안내 카드 표시 및 renderer 오류 없음 확인.

## 범위와 한계

- PC가 켜져 있고 인터넷과 유효한 로그인 세션이 있어야 한다. 기존 12시간 로그인 정책을 우회하거나 비밀번호를 저장하지 않는다. Windows 방해 금지/앱 알림 설정에 따라 소리·배너 표시가 달라진다.
- Windows 부팅 시 자동 시작은 추가하지 않았다. 모아온을 한 번 실행한 뒤 트레이에서 종료하기 전까지 유지한다.
- 주문 알림은 활성 주문 최대 100개, 문의는 기존 CS 읽기 범위에 한정한다. 잘림은 확인 필요로 표시하며 무제한 실시간 이벤트 수신으로 보장하지 않는다. 오랜 종료 뒤 예전 알림이 몰리지 않도록 재실행 시 최대 최근 24시간 범위로 제한한다.
- 각 PC가 주기적으로 수집을 요청한다. 기존 네이버/쿠팡 큐의 분 단위 중복 방지는 유지한다. 세 PC 전체를 하나의 수집 주체로 만드는 중앙 스케줄러/전역 lease와 장시간 부하 계측은 이번 범위에 추가하지 않았다.
- DB·서버 배포나 채널 키 변경은 없다. 기존 수집 API와 로그인 검증을 재사용한다. 판매 입찰/발급/출고 요청을 자동 실행하지 않는다.
