# P4-54 주문 도구 키보드 동작 — 0.38.4

## 수정 내용

검색·추가 필터 안에서 Escape를 눌렀을 때 해당 도구 대신 주문 상세가 닫히는 문제를 재현하고 수정했다.

- 전체 검색·기간 입력 중 Escape: 검색 도구만 닫고 실행 버튼으로 포커스 복귀.
- 추가 필터 내부 Escape: 필터만 닫고 요약 버튼으로 포커스 복귀.
- 입력한 검색어와 체크한 주문, 열려 있는 주문 상세를 유지한다. 검색 적용이나 API 요청을 새로 실행하지 않는다.
- 상세에서 Escape를 누르면 기존처럼 상세를 닫고 해당 주문 행으로 돌아간다.
- 선택 주문 추가 작업 메뉴의 기존 닫힘 우선순위는 유지한다.

화면 색상·레이아웃·API 계약·출고 안전 확인 절차는 변경하지 않았다. 이번 UI 작업은 시각적 재디자인이 아니라 키보드 접근성과 작업 흐름 보완이다.

## 검증

- 수정 전 검색 패널이 열린 채 남는 실패 재현 후 수정.
- 실제 키 입력으로 검색/필터 닫힘, hidden·inert, 포커스 복귀, 검색 초안·주문 선택 유지, 상세 닫힘 확인.
- 앱 단위230개 통과.
- 패키지 UI6종 통과: 키보드, 전체 검색, 배송정보, 목록 밀도·패널, 자동 발급·등록, 플랫폼 송장 등록.
- 1440/1040px 및 라이트·다크의 목록 밀도 기준 유지.
- NSIS 0.38.4 빌드 성공.
- 이 PC 설치 완료. 설치본/빌드 app.asar SHA256 `24E8E981078EF8AE71ECF4ACD6804A5D8199974439BA5F78D4C25EA7F9B11597` 일치.
- 실제 설치 EXE 읽기 전용 확인: 버전0.38.4, 로그인 재입력 없이 주문 진입, 정렬0px·패널22프레임·스크롤바 숨김 통과.

격리 프로필과 시험 응답 검증이며 실제 송장 발급·플랫폼 전송·물리 인쇄는 실행하지 않았다. 서버·DB 변경과 유료 인프라 추가도 없다.

## 다음 단계와 미완료 범위

실제 출고 PC·프린터·지정 실주문의 우체국 발급→플랫폼 등록→출력·바코드 인수는 미완료다. 주문 페이지 전체 완료로 표시하지 않는다. 주문 화면의 기능 결함을 재현하면 계속 보완하되, 실제 인수 결과와 코드/UI 시험 결과를 구분한다.
