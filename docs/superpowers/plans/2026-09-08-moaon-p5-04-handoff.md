# P5-04 — 모아온 0.4.0 상태별 주문 조회

## 사용자가 확인한 선행 조건

0.3.1 로그인 수정 이후 사용자가 연동 확인을 보고했다. 이는 사용자 확인이며 개발자가 비밀번호를 입력하거나 모든 주문을 원본 대조했다는 뜻은 아니다.

## 인도 범위

주문·배송에 송장 발급 전, 송장 등록 후, 배송중, 완료·취소 조회 범위를 제공한다. 서버에 저장된 주문 분류를 사용하며 상태별로 최대20건씩 이전·다음 조회한다. 상태 변경은 첫 페이지로 이동하고 이전 검색·선택·상세를 지운다. 검색은 현재 페이지에만 적용된다.

목록과 상세의 알려진 주문 상태를 한글로 표시한다. 알 수 없는 상태는 확인 필요로 남긴다. 완료·취소에는 취소 주문도 포함되고 현재 수집된 자료만 표시한다. 모든 과거 주문이나 최근30일 조회를 보장하지 않는다.

## 유지되는 제한

저장 주문 조회이며 실시간 택배 추적이나 새 주문 수집 기능이 아니다. 송장 발급·인쇄·상태 변경·플랫폼 키 입력·다사업장 가입은 이번 범위에 없다. 운영 웹사이트·DB·인증을 수정하지 않는다. 수취인 이름·전화·주소를 새로 노출하지 않는다. 로그인 세션은 앱 종료 시 사라진다.

## 검증 결과

- 구현 커밋 `0a70ae9`.
- 데스크톱 단위 34/34 PASS. 상태별 고정 URL, 범위 전환, 늦은 응답, 연결 해제 중 선택 차단, 로그인 회귀를 포함한다.
- 기존 허브 회귀 2,541/2,541 PASS. 운영 웹 코드는 변경하지 않았다.
- 별도 임시 프로필의 실제 Electron에서 네 가지 범위와 페이지 초기화·검색·상세 초기화·한글 상태·샘플 복귀 PASS. HTTP 응답은 합성이며 실제 신규 범위의 데이터 완전성 검증과 구분한다.
- 패키지 app.asar 기준 상태 조회·로그인 제출·기본 UI smoke PASS. 런타임 소스 8개 바이트 일치 확인, 테스트 파일/운영 비밀키는 패키지에 포함하지 않는다.
- 코드 검토 및 최종 설치 상태는 인도 직전에 추가 기록한다.

## 다음 단계

상태별 실사용 조회를 확인한 후 업무에 필요한 주문 상세를 확대한다. 송장 발급과 인쇄는 중복 방지·대상 재확인·실제 프린터 검증을 별도 단계로 유지한다.
