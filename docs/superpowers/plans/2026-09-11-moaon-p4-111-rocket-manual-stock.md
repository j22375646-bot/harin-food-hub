# P4-111 · 직접 관리 재고와 로켓그로스 (0.97.1)

## 변경

- 상품 목록의 큰 수량은 재고 페이지에 직접 등록하고 Cafe24 상품과 연결한 제조번호별 수량이다. 다른 단위는 합치지 않는다. 미등록/조회 실패는 0으로 표시하지 않는다. Cafe24·네이버 수량은 작은 참고값이며 플랫폼 판매/품절/확인 필요 상태를 구분한다.
- 중복 연결은 상세 화면에서 선택·저장한다. 원래 채널 연결을 삭제하지 않고 사업장별 선택을 DB에 저장한다. 다른 상품 소속이나 네이버 광고 자료를 판매 상품으로 선택할 수 없다.
- 재고 페이지에 직접 관리/로켓그로스 탭을 분리했다. 로켓그로스는 수동 등록하지 않는다. API 수량이 양수이고 판매 상태가 확인된 옵션만 DB 관리 목록에 자동 등록한다. 이후 0개가 되어도 품절로 남는다. 재고가 처음부터 0인 옵션은 등록하지 않는다.
- 관리 목록은 PC가 아닌 DB에 저장된다. 현재 수량 누락은 확인 필요, 6시간 넘은 자료는 갱신 필요로 구분한다. 재고 탭이 보이는 동안 30초마다 저장 결과를 조회하고, 5분 간격으로 API 수집을 요청한다. 여러 PC의 수집 요청은 DB 잠금으로 합친다. 앱을 닫은 동안의 새 주기 스케줄을 추가한 것은 아니다.
- 재고 저장 후 상품 목록 캐시를 무효화하여 다음 상품 탭 방문 때 새 수량을 읽는다.

- 운영 Vercel dpl_DXs3w4Q2KGDhLSip7vEbVACxChHa READY. 인증된 stock GET200, rocketStatus READY, 관리 옵션2개 확인.

- 최종 원본 파일56개 일치, SHA256 0801183833e36ae3df06b69ce8bdcc3bc38ef7c44cb616decbeb2e42d6dc5e2d.
- D:\GPT\Apps\Moaon\releases\0.97.1 설치, D:\OneDrive\바탕 화면\모아온.lnk 갱신. 가시 검증은 오른쪽 보조 모니터, 포커스 가져오기 없음. 기존 실행 창은 강제 종료하지 않는다. 새 버전은 바로가기로 다시 열면 적용된다.
- DB 보안 진단: 새 테이블은 RLS/서비스 전용 권한으로 일반 클라이언트 접근을 차단했다. 정책 없음 INFO는 의도한 서버 전용 구조다. 기존 Auth 유출 비밀번호 보호 WARN은 이번 변경 밖이며 [설정 안내](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)를 참고한다.

## 범위와 복구

실제 주문 발급/출고, 채널 재고 수량 변경은 수행하지 않았다. 직접 재고는 공유 DB를 계속 사용한다. 로켓그로스 수집은 기존 작업 서버에 의존하며 수집 실패를 품절로 대체하지 않는다. 앱은 이전 버전으로 복구할 수 있고 새 DB 테이블은 기존 API 자료를 삭제하지 않는다.
