# P4-59 분석(인사이트) 앱 이식 — 0.45.0

## 이번 개발 범위

기존 웹 화면을 앱 안에 넣지 않고, 기존 네이버 주간 분석 모델을 읽기 전용 API와 앱 전용 화면에 연결했다. 기존 모델은 네이버 주간 광고 보고서 기반이다. 카페24·쿠팡 분석이나 주문 전체 매출을 이 화면에서 지원한다고 표시하지 않는다.

- 분석 메뉴, 광고 전환매출·이전 보고서 대비·공헌이익 카드.
- 원인 검토와 검토할 행동, 판단 제한 안내.
- 최근 보고서 최대 20개 제목·기간 목록. 전체 보고서 상세는 아직 미이식.
- 최초 진입 자동 조회, 5분 이내 재진입 중복 요청 억제, 수동 새로 조회.
- 실패/로그아웃 시 이전 금액 비움. 미확인은 0이 아닌 판단 보류, 실제 0원은 유지.
- 앱 색상·기존 폰트 재사용, 1040/1440 폭·라이트/다크, 가로 넘침 방지, 숨긴 스크롤바와 휠 스크롤, 줄바꿈·짧은 메뉴명.

## 기능·안전 경계

분석 전용 로더는 reports를 한 번 조회하며 NAVER/WEEKLY/is_latest 조건과 최신 20개 한도를 사용한다. 이 횟수는 권한 확인용 DB 요청을 포함하지 않는다. 전체 대시보드 로더나 AI 생성을 호출하지 않는다.

고정 사업장 OWNER 권한을 조회 전후 재확인한다. 다른 사업장·권한 변경·쿼리 변조를 차단하고 응답은 private, no-store다. 앱은 허용된 고정 GET만 사용하며 로그아웃 시 진행 중 요청을 취소한다.

원천 수집 상태를 이번 조회에서 따로 검사하지 않으므로 최신 자료라고 단정하지 않는다. 보고서 생성 시각과 자료 기간을 표시한다. 재무 근거 READY가 아니면 공헌이익을 숨기고, 동일·겹치는 기간 또는 비교 제한 보고서는 증감률 판단을 보류한다.

광고 변경, 보고서 신규 생성, 송장 발급·등록, 유료 자원 생성, DB 복사·변경은 이번 작업에 없다.

- 서버 전체 자동 테스트: 2,662/2,662 통과.
- 앱 자동 테스트: 263/263 통과.
- 서버 프로덕션 빌드 통과.
- 격리 패키지 화면 시험: 분석, 정산, 재무, 주문 레이아웃 4종 통과.
- 분석은 0원/미확인·HTML 문자 안전 출력·중복 요청 억제·실패/로그아웃 비움·화면 폭/테마를 확인했다.
- 패키지 시험은 실제 app.asar를 개발 Electron으로 임시 프로필에서 실행한다. 운영 API 성공의 증거로 사용하지 않는다.
- 첫 패키지 시험은 빌드 완료 전 시작해 app.asar 부재로 실패했다. 패키지 완료 후 재실행하여 통과했다.
- 실제 인증된 운영 분석 금액·보고서와 웹 화면 대조는 미완료다.
