# P4-115 · 생산분별 입고 내역과 기간 인쇄 (0.101.0)

## 사용 흐름

- 신규 등록은 **총 입고 수량**, KG는 **총 입고 중량**으로 표시한다. 기존 재고 수정은 현재 보유량이라는 의미를 유지한다.
- 재고 목록의 **＋ 입고**는 상품 연결·단위·소분량을 이어받는 새 생산분 등록 창을 연다. 입고일·제조번호·제조일자·유통기한·입고 수량을 입력한다. 제조 정보는 이전 생산분에서 복사하지 않는다.
- 생산분별 별도 UUID로 저장하여 기존 제조번호와 유통기한을 덮어쓰지 않는다. 원래 생산분의 보유량과 최초 입고 수량을 구분한다.
- 상품을 누르면 같은 카페24 연결 상품의 입고 내역을 함께 표시한다. 미연결 상품은 동일 이름끼리 표시한다. 현재 재고 목록 자체는 기존 생산분별 표시를 유지한다.
- 내역은 **전체 / 최근 30일 / 기간 선택**으로 조회한다. 최근 30일은 한국 날짜 기준 오늘 포함30일, 직접 기간은 시작일·종료일 포함이다. 날짜 역전과 빈 결과에서는 인쇄를 비활성화한다.
- 내역 열은 입고일·제조번호·제조일자·유통기한·입고 수량·관리다. 요청에 따라 잔량은 표시하지 않는다. 입고일 없는 기존 기록은 전체에서 `기록 없음`, 날짜 범위에서는 제외한다.
- **입고 내역 인쇄**는 선택 상품·조회 기간의 A4 미리보기를 연다. 상품명·기간·건수와 입고 내역을 인쇄하며 수량을 강조한다. 여러 행을 한 장에 배치하고 표 머리글을 다음 장에도 반복한다. 실제 출력은 미리보기의 인쇄 설정 메뉴에서 진행한다.

## 자료와 연결

공유 DB의 기존 재고 JSON에 `receivedDate`, `receivedQuantity`, `receivedUnit`을 저장한다. 최초 입고 수량은 서버가 확정하고 이후 수정·출고에서 보존한다. 기존 자료에 없던 최초 수량을 현재 잔량으로 추정하지 않는다. 기존 수정 충돌·원장·유통기한 우선 차감 방식을 유지한다.

인쇄 요청에는 재고 ID와 날짜만 전달한다. 메인 프로세스가 인증된 서버에서 자료를 읽고 조회·인쇄 직전에 재확인한다. 세션 변경 시 미리보기를 닫고 변경된 자료는 다시 조회하도록 한다. 문서 내용은 HTML 이스케이프하며 외부 요청·스크립트·팝업을 허용하지 않는다.
