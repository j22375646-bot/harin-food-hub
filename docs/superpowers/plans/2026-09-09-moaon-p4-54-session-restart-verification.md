# P4-54 로그인 유지·API 회귀 검증

## 이번 결과

- 서버 로그인 토큰과 쿠키의 기본 유효기간은12시간이다. 무기한 로그인 유지 기능은 아니다. 임의로 보안 유효기간을 늘리지 않았다.
- 0.38.7 최종 app.asar를 사용하는 격리 프로필에서 합성 쿠키를 저장하고 앱을 종료·재실행했다. 쿠키가 유지됨을 확인했다. 명시적 로그아웃 이후 다시 재실행하면 쿠키가 없는 상태를 유지했다.
- 실제 운영 로그인 쿠키를 만들거나 읽어 출력하지 않았다. session-test.invalid의 비인증 쿠키만 사용했다. 실제 로그인 쿠키가 사라진 시점과 원인은 이 시험으로 확정할 수 없다.
- 설치본 UI 검사에서 로그인 필요 상태를 즉시 BLOCKED/LOGIN_REQUIRED로 구분하도록 수정했다. 실실행에서 해당 결과를 확인했다. 더 이상 이를 단순 서버 시간 초과로 보고하지 않는다.
- 우체국 발급·발급 보호·출고 상태·작업 화면 관련 서버 회귀25개 통과. 외부 플랫폼에 실제 송장을 전송한 시험은 아니다.

## 완료와 미완료

이번 변경은 검사 도구와 검증 기록이며 제품 UI·설치 파일 변경은 없다. 설치 버전0.38.7 유지. 로그인 프로필 삭제·DB 변경·유료 자원 추가·고객 주문 전송은 하지 않았다.

실제 인증된 주문 발급→플랫폼 등록 종단간 검증은 로그인 세션이 없어 진행하지 못했다. 비밀번호 자동 입력이나 인증 우회는 하지 않는다. 주문 페이지 전체 완료가 아니며, 다음 인수에서는 이 상태를 먼저 확인하고 중복 전송 없이 기존 등록 결과를 대조해야 한다.
