# 모아온 데스크 — Windows 앱 전용 디자인 시안

2026-09-09 · 시안 검토용. 운영 UI 교체 아님. 앱 기능은 0.17.0 유지.

[다크·라이트 비교 이미지](../designs/moaon-desktop-dark-light-v1.png)

내장 이미지 생성 도구로 만든 정적 시안이다. 실제 움직임·API 연결을 시연하지 않는다. 이미지의 로고·버전·문구·상태/목록 조합은 생성 예시이며 확정 사양이 아니다. 구현 시 기존 모아온 로고, 정확한 상태 필터, 실제 버전, 전체 균형 테두리 규칙을 유지하고 과한 버튼 광택은 줄인다. 표시 메뉴 중 미구현 기능은 운영에서 활성화하지 않는다.

## 목표

사장님과 출고 담당자가 모아온을 켜고 주문을 찾아 확인하고 처리 결과까지 놓치지 않게 한다. 큰 웹 소개 문구와 긴 스크롤 대신, 한 창 안에서 목록·상세·작업 결과를 함께 다룬다. 기존 기능·인증·금액 계산·채널 구분·발급 안전장치는 보존한다.

## 추천안: 모아온 데스크

같은 작업 구조를 다크와 라이트 두 가지로 비교한다. 서로 다른 앱을 만드는 것이 아니라 같은 기능·위치에 테마만 달리한다.

- 다크: 슬레이트 배경 #172332, 패널 #223246, 동작 블루 #5C8FFF, 성공 #65BFA7, 주의 #D9A45E.
- 라이트: 배경 #EEF3F8, 패널 #FFFFFF, 본문 #203047, 동작 블루 #3E69D2. 오류와 미확인은 색상뿐 아니라 글자로도 표시한다.
- 본문은 기존 한국어 글꼴 자산 우선, 제목은 Semibold, 금액·시각은 tabular 숫자. 본문 14–16px, 보조 12–13px, 페이지 제목 22–26px. 실제 표시 크기는 Windows 125/150% 배율에서 확인한다.
- 얇은 앱 제목줄 → 업무 탭 → 고정 도구줄 → 목록/우측 상세 → 접히는 작업 결과창 순서.
- 사이드바는 아이콘+이름을 기본으로 하고 선택 시 전체 배경과 전체 테두리를 사용한다. 좁은 한쪽 색 띠에 의존하지 않는다.
- 대표 요소는 **하단 작업 결과창**이다. 목록을 바꾸지 않고도 처리 중·완료·확인 필요를 확인한다. 로그 원장 자체는 기존 저장된 실제 상태만 사용하고 샘플 성공 메시지를 운영에 섞지 않는다.

## 화면 배치

| 영역 | 역할 | 보존/적용 조건 |
|---|---|---|
| 오늘 | 저장 주문 상태와 다음 업무로 바로 이동 | P4-26의 미확인/부분 확인/조회 시각 유지 |
| 주문·배송 | 검색·채널·정렬·선택·상태·페이지 이동을 한 도구줄로 정돈 | 현재 페이지 필터임을 계속 명시 |
| 우측 상세 | 제품·받는 분·사은품·확인 항목·발급 동작 | 이전/다음, 키보드 이동, 닫기, 포커스 복원 유지 |
| 하단 작업 결과 | 진행 상태와 결과 재확인, 미리보기로 이동 | 신규 UI 개발 대상. 자동 재발급은 금지 |
| 설정/사업장 | 연결 상태·소속·역할·프린터 설정 | 미지원 사업장을 연결된 것처럼 표시하지 않음 |
| 나머지 업무 메뉴 | 웹 기능을 기능 단위로 앱에 이전 | 시안에 있어도 아직 앱에 구현됐다는 뜻이 아님 |

## 동적 효과 설계

| 동작 | 제안 | 업무 보호 |
|---|---|---|
| 행/버튼 hover | 배경 100ms, 툴팁 지연 없이 표시 | native title의 긴 대기 대신 접근 가능한 툴팁 |
| 상세 열기 | 180ms 불투명도+짧은 이동 | 입력·조회는 애니메이션 완료를 기다리지 않음 |
| 작업 결과 펼치기 | 180–220ms | 선택 주문과 스크롤 위치 유지 |
| 작업 상태 변경 | 실제 상태가 바뀔 때 한 번만 160ms 강조 | 숫자 카운트업, 거짓 진행률 금지 |
| 페이지 진입 | 짧은 120ms 전환 | 로그인/데이터 대기에 추가 지연 없음 |
| 접근성 | reduced-motion이면 전환 제거 | 키보드 포커스와 상태 안내는 그대로 |

콘텐츠 표면은 불투명하게 유지한다. 유리 효과는 제목줄 정도로 제한하고, 표 위 배경 영상·상시 반짝임·무거운 3D·과한 블러는 사용하지 않는다. 기능을 보이게 하는 시각 효과에 집중한다.

## 기능을 잃지 않는 적용 순서

1. 시안 방향 선택. 이번에는 제품 코드를 교체하지 않는다.
2. 현재 앱 기능 목록과 버튼/키보드 동작을 기준표로 고정한다.
3. 주문·배송 한 화면부터 기존 조회·발급 함수를 그대로 연결하고 UI만 교체한다.
4. 0건·부분 조회·서버 오류·인증 만료·주문 변경·결과 미확인·중복 클릭·재시작을 검사한다.
5. 오늘/설정/다른 업무로 확대한다. 메뉴만 먼저 노출하지 않는다.
6. 1040×720 및 1366×768, Windows 100/125/150% 배율, 라이트/다크, 키보드·스크린리더 상태 안내, 프린터 실기 인수를 거친다.

## 기존 개발 병행 기록

출고/라벨 흐름의 패키지 검증을 진행했다. 라벨 미리보기·스크립트 차단·로그아웃 시 창 닫기는 통과했다. 오래된 출고 화면 테스트가 로그인 우선 화면에서 숨겨진 연결 버튼을 기다리며 실패하는 문제를 재현하고, 격리 시험 시작 시 초기 인증을 정리한 뒤 가명 주문을 조회하도록 테스트를 수정했다. 발급 완료 후 버튼 잠금과 상태 재확인이 추가 발급을 보내지 않는지도 검사했다. 실제 고객 송장 발급이나 프린터 출력은 하지 않았다.

검증: 출고 가명 소스/패키지 시험 통과, 라벨 가명 패키지 시험 통과, 단위 테스트 124개 통과, diff 검사 통과. 수정 대상은 테스트 절차이며 송장 발급 기능 자체를 새로 구현한 것은 아니다. 새 EXE 설치나 운영 배포는 하지 않았다.

사업장 목록 재실행 실패는 원인 미확정이며 해결 완료로 표시하지 않는다. 시안 작업 때문에 다사업장 권한이나 운영 원장을 변경하지 않는다.
