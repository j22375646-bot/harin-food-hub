## P4-27: 실제 출고 개발

발급 완료 후 상세 안에 **발급 결과 주문 다시 조회** 버튼을 추가했다. 기존의 저장 주문 재확인 경로를 호출하며 추가 발급 POST를 보내지 않는다. 조회 결과에서 송장이 등록된 것으로 확인되면 기존 미리보기·인쇄 버튼이 나타난다.

현재 페이지에서 주문이 다른 상태/페이지로 이동해 사라지면 기존의 주문을 찾지 못했다는 안내를 유지한다. 전체 주문을 자동 탐색하거나 송장 등록을 임의 추정하지 않는다. 결과가 미확인/실패인 경우 완료 버튼을 표시하지 않는다.
