# P4-173 주문 클릭 선택

실주문 행 클릭 시 기존 선택을 유지하며 해당 주문 자동 선택. 체크박스 및 선택 해제로 취소. 발급/출고 실행은 기존 버튼과 확인 절차 유지. 주문 제목의 inherited line-clamp/overflow clipping 제거, 충분한 line-height와 padding 제공. 상세 주문 변경 시 내부 스크롤 초기화.

로컬/패키지 Electron 주문 UI 검사 통과. 기존 시험의 오래된 예약 상태 기대값을 현재 결제완료 표시로 수정. 자동 선택/하단 작업 메뉴, 채널/정렬/상세 이동 및 다크/라이트 확인. 패키지 117개 파일 일치. 0.147.10 실제 설치 검증 및 배포.
