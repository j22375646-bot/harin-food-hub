# P4-54 / 0.38.8 발급·등록 결과 확인 동선

## 변경

자동 발급·등록의 실패/결과 불명 행과 수동 송장 등록의 미완료 행에 `주문·발급 상태 확인` 버튼을 추가했다. 기존 앱의 findOrder 읽기 경로로 해당 주문을 찾아 목록·상세 확인으로 연결한다. 신규 발급 또는 플랫폼 등록을 다시 보내는 버튼이 아니다.

플랫폼 등록 실패 문구를 앱 내 상태 확인 안내로 바꿨다. 기존 Pretendard·secondary-action 버튼 스타일을 재사용하여 결과 행에 넣었으며 카드·구분선을 늘리지 않았다. 전체 오류 안내의 모든 웹 허브 참조가 제거된 것은 아니다.

기존 성공/대기/실패 구분, 대기 작업의 진행 다시 확인, 중복 작업 잠금, 로그아웃 보호를 유지한다. 오래된 결과 버튼은 주문 화면 요청 번호가 달라지면 실행되지 않는다.

## 검증

새 테스트에서 버튼이 없는 기존 상태의 실패를 먼저 확인했다. 수정 후 자동/수동 결과에서 클릭 시 해당 주문번호의 조회만 발생하고 발급·등록 횟수가 증가하지 않음을 검증했다. 이전 화면 버튼 재실행도 조회 횟수를 늘리지 않는다. 모의 API 응답을 이용한 격리 앱 검사이며 실제 플랫폼 등록 성공 증거는 아니다.

앱 단위231개, 신규 결과 확인·기존 자동 발급/등록·기존 수동 등록 UI 검사 통과. 제품 버전0.38.8. 서버·DB 변경 없음.

최종 패키지 기준 결과 확인·자동 발급·수동 등록·레이아웃 UI4종 통과. 1040/1440px 밝음/어두움 배치 검사 통과. 이 PC 설치 종료0, 빌드 app.asar와 설치본 해시 일치. 로그인 프로필은 삭제하지 않았다.

## 남은 범위

현재 실제 로그인 세션이 없는 상태이므로 실주문 발급→플랫폼 등록 인수는 미완료다. 이번 버튼은 확인 동선이며 실패 자동 복구나 재발급 기능이 아니다. 주문 인수 완료 전 다른 페이지를 완료 처리하지 않는다. 다음 우선순위는 실제 인증 상태에서 플랫폼별 등록 결과 대조와 주문 페이지 마감이다.
