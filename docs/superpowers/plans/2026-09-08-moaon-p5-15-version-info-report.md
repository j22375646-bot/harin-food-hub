# P5-15 / 0.15.1 실제 실행 버전 표시

## 무엇을 고쳤나요?

설정 화면에 버전이 `0.9.0`으로 고정되어 있었다. 설치된 프로그램이 업데이트되어도 화면에는 옛 숫자가 남아 혼동할 수 있었다. 이제 로그인 화면과 앱 설정이 Electron 호스트의 `app.getVersion()` 값을 동일하게 표시한다. 읽기에 실패하면 임의의 버전을 보여주지 않고 `버전 확인 필요`로 표시한다.

버전 조회는 앱의 신뢰된 메인 화면에서만 가능하고 추가 인수는 거부한다. 파일 경로·비밀번호·인증정보는 반환하지 않는다. 기존 주문 수집·송장 발급·로그인 인증 방식은 변경하지 않았다. 이전 0.15.0의 로그인 우선 화면과 디자인도 포함된다.

## 검증 결과

- 데스크톱 자동 테스트 **112/112 통과**. 버전 IPC의 정상 조회·다른 화면 차단·추가 인수 차단·잘못된 값 처리를 검사했다.
- 개발 코드 및 패키징 코드의 Electron 로그인 화면 시험 통과: 로그인 우선, 취소 후 잠금 유지, 유효 세션 진입, 만료 후 로그인 복귀, 접근 거부 복구.
- 화면 시험은 격리 프로필과 합성 인증 응답을 사용했다. 실제 사용자 비밀번호 입력이나 운영 로그인 성공을 검증한 것은 아니다.
- 화면 시험의 호스트는 개발용 Electron이므로 표시값은 그 호스트 버전과 비교했다. 별도로 패키징된 `app.asar`의 package.json이 **0.15.1**인지 확인했다. 설치된 EXE의 화면 검증을 대체하지 않는다.
- 독립 코드 검토에서 중요한 결함 없음. 현재 숫자 세 부분 버전 형식만 허용하며 향후 prerelease 버전 도입 시 형식 확장이 필요하다.
- Windows x64 설치파일 생성, SHA256 확인. 추가 유료 서비스 신청 없음.

## 설치파일과 실제 적용 상태

설치파일: `output/moaon-preview-0.15.1/Moaon-Preview-0.15.1-Setup.exe`

SHA256: `7E0817D84C03875A2EB710E07A4CFA8E452641912F38E3A9E645EF7DE6065CDE`

서명 상태: **NotSigned**. Windows 게시자 확인 경고가 나타날 수 있다.

시작 점검 당시 이 PC의 설치 등록은 **0.13.1**이었고 앱이 실행 중이었다. 정상 종료를 요청했으며 이번 작업에서 앱 강제 종료나 설치 교체는 수행하지 않았다. 출고 PC에도 아직 설치하지 않았다. 개발 완료와 실제 설치 완료를 구분한다.

## 다음 개발·인수 순서

1. 최신 설치파일로 업데이트하고 실제 설치 EXE에서 로그인 화면과 버전 표시를 확인한다.
2. 사용자가 직접 로그인하여 세션 유지·재실행·만료 복귀를 운영 서버와 확인한다.
3. 출고 PC에서 프린터 목록, 용지 크기와 바코드 출력 품질을 확인한다. 실제 발급·출력은 대상 주문과 사용자의 확인 하에 진행한다.
4. 현장 인수와 별개로 다사업장 계정·자료 격리·플랫폼 연결센터를 기존 계획 순서로 진행한다. 다른 사업장 운영을 임의로 개방하지 않는다.
