# P4-120 · 오늘 작업대와 주문·배송 정렬 (0.106.0)

## 반영 범위

승인한 Daybook 시안을 실제 앱의 조회·작업 경로에 연결했다. P4-119의 도넛과 큰 상태 카드를 제거하고 주문 작업대, 오늘 일정과 월력, 재고 관리 바로가기, 기존 월별 자금 판단을 배치했다. 시안에 있던 정적인 주문·매출 값과 7일 그래프는 운영 데이터로 옮기지 않았다. 로컬 시안의 업무 스냅샷은 Git 제외 상태를 유지한다.

- 왼쪽 메뉴는 창 전체 높이를 채우고 본문만 스크롤한다. 설정은 아래에 배치하며 낮은 창에서는 메뉴 자체를 스크롤할 수 있다.
- 오늘 작업대는 상태별 최대 6건의 실제 조회 투영을 사용한다. 상품·수량·금액·채널을 보여주고 클릭하면 해당 상태의 주문을 새로 읽어 상세로 연결한다. 요약 조회는 기존 주문 목록의 선택·페이지를 변경하지 않는다.
- 요약 DTO는 상품 표시용 필드만 전달한다. 받는 사람·주소·전화·송장 상세를 추가하지 않는다. 조회 실패 시 이전 미리보기 행을 보여주지 않고, 부분 확인·확인 필요·실제 0건을 구분한다.
- 오늘의 왼쪽 작업대/자금과 오른쪽 일정/재고를 독립적으로 쌓아 불필요한 행 높이를 공유하지 않는다. 일정의 시간·상태와 제목도 줄을 나눠 정렬한다.
- 주문·배송은 상태 탭을 밑줄 방식으로 정리하고 검색·필터·목록을 하나의 표면에 배치한다. 옵션/수량, 64px 이미지, 중앙 열 정렬, 선택 툴바, 상세 스크롤 및 출고 기능을 유지한다.
- 공통 최종 스타일은 `daybook.css`로 대체했다. 제목은 배포에 포함된 Pretendard를 사용해 PC별 설치 폰트 차이를 줄인다. 다른 페이지의 기능과 기존 의미별 색상을 유지한다.

## 사용자 추가 지적과 수정

검증 중 기존 CSS의 높은 우선순위 때문에 ‘확인 필요’ 글자가 24px로 커지고, 특정 상태만 건수가 다음 줄로 내려가는 문제가 드러났다. 배포를 진행하기 전에 오류 문구/건수 크기를 13px로 통일하고, 좁은 창에서는 모든 탭을 같은 이름·건수 2행 구조로 맞췄다. 좌우 첫 영역의 시작 위치, 일정 제목 줄, 이미지가 없는 상품의 대체 아이콘도 정리했다.
