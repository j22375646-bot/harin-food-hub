# P4-33 — 6개 영역 이식 착수 및 주문 1차

## 이번에 달라진 점
- 채널 선택이 현재 20건에 있는 채널만 표시하던 방식에서, Cafe24/네이버/쿠팡 판매자배송 서버 조회로 바뀌었다.
- 체크박스·전체 선택·선택 해제·내용 확인을 연결했다. 선택은 상세 패널을 닫아도 유지된다. 페이지/채널 변경 때는 초기화한다.
- 이미 우체국 송장이 발급된 적격 주문을 최대20건 선택해 쇼핑몰에 등록할 수 있다. 단건 상세에서도 같은 기능으로 진입한다.
- 실제 전송 전 확인창과 최신 주문 재검사, 같은 앱 연결에서 중복 시도 차단을 유지한다. 완료/대기/실패/확인 필요를 각각 표시한다.
- 등록 성공 후 ACTIVE에서 REGISTER로 이동하는 실제 서버 흐름을 반영했다. 제한된5페이지/100건 및 시간 안에 같은 송장을 확인하지 못하면 성공이라고 표시하지 않는다.
- READY_TO_SHIP 적격 주문도 포함했다. 네이버/로켓그로스는 임의로 Cafe24·쿠팡 판매자배송 처리 경로에 섞지 않는다.
- 패널 X의 오른쪽 이동/페이드와 목록 확장, 열 정렬, 공통 스크롤바 숨김을 반영했다. 스크롤 자체는 유지한다.

## 범위와 미완료
이번은 주문 1차 이식이다. 일괄 신규 송장 발급 전체 흐름, 쿠팡 큐의 자동 완료 추적, 불명 결과의 앱 재시작 후 복구, 신규 주문 수집 버튼, 내보내기/일괄 인쇄는 아직 전체 이식 완료로 세지 않는다. 등록 버튼은 신규 번호 발급 버튼과 다르다.

오늘은 기존 주문 요약, 설정은 기존 앱 설정만 있다. 정산·인사이트·캘린더 신규 앱 화면은 아직 구현 전이다. 장기 로그인 유지 변경은 이번 범위가 아니다. 서버·DB·요금제 변경 없음.

1. 주문 남은 처리 흐름과 실제 수집·작업 상태·부분 실패 복구.
2. 오늘·운영(정산)의 서버 공통 조회 모델: 웹과 앱이 같은 계산 결과를 표시.

5. 설정의 연결·수집 상태를 추가하고 기존 테마·프린터 기능 통합.
