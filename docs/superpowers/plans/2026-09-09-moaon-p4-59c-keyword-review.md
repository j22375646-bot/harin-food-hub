# P4-59C 키워드 후보와 7일 확인 기준

## 이번 변경

기존 0.46.0 앱의 보고서 상세가 새 응답을 그대로 표시하므로 앱 재설치 없이 서버 조회 결과를 보완했다.

- 키워드 제목에 낭비 후보/성장 후보를 구분한다.
- 두 그룹에 각각 450바이트를 배정해 긴 낭비 후보가 성장 후보를 밀어내지 않게 했다. 그룹당 최대 4개이며 분량에 따라 더 적게 표시될 수 있다.
- 후보 자료가 없으면 자료 없음 안내를 표시한다. 확인되지 않은 성과를 0으로 바꾸지 않는다.
- 기존 보고서의 sevenDays 모델에서 확인 시점·검증 기준·확인 질문·위험을 연결했다.
- 7일 뒤 자동 실행/예약을 생성한 것이 아니다. 광고 설정·입찰·DB 데이터를 변경하지 않는다.
- 기존 패널 애니메이션·스크롤·닫기·권한 제한은 그대로 사용한다.

## 검증

새 실패 테스트 2개를 먼저 작성하고 수정 후 통과했다. 관련 17개 통과. 기존 최대 20건 응답 크기·Unicode·권한·재무 제한 테스트를 유지한다.

실제 서버 변환 함수가 만든 시험 응답을 0.46.0 패키지의 통신 검증과 네이티브 화면에 통과시켰다. 두 후보, 실제 0, 확인 시점·지표·질문 표시 및 클릭 추가 요청 없음이 통과했다. 격리 임시 프로필과 개발 Electron으로 기존 app.asar를 실행했으며, 실제 운영 계정의 보고서와 대조한 것은 아니다.

## 남은 범위와 다음 단계

표시량 제한이 있는 요약이다. 전체 보고서·후보 전량, 실제 운영 숫자 대조, 자동 광고 변경은 완료 범위가 아니다. 기존 주문 실등록 검증·정산 실금액 대조도 미완료로 유지한다.

다음 P4-60은 캘린더 페이지의 월간 일정 조회·날짜 선택·상세 보기 이식이다. 기존 오늘 일정 조회 기능을 기준으로 앱 전용 화면을 연결하고, 일정 쓰기 기능은 별도 검증 단계로 구분한다.
