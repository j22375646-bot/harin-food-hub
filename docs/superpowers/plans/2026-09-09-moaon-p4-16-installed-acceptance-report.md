# P4-16 Windows 0.15.2 실제 설치·재시작 인수

## 실제 수행

기존 설치 0.15.1 및 실행 중 모아온 프로세스 없음을 확인했다. P4-15 설치파일 SHA256 96202BF7C1DF3A7C77A8F685B659FB97E8A8C6DA62CF3EB4202741D6120D9E91 일치 확인 후 사용자 단위 설치를 실행했다. 설치 종료 코드 0. 기존 프로필 삭제 없음.

설치된 C:/Users/a/AppData/Local/Programs/Moaon Preview/MoaonPreview.exe를 실제로 두 번 실행하고 닫는 인수 시험 PASS. 개발용 Electron이 아닌 설치 EXE 검증이다.

|항목|1회|2회|
|---|---|---|
|앱 버전|0.15.2|0.15.2|
|테마|dark|dark|
|로컬 UI 준비|705ms|531ms|
|로그인 상태 확인 포함|1316ms|1008ms|
|결과|로그인 필요|로그인 필요|

유효 세션이 없는 상태에서 로그인 화면을 먼저 표시하고 업무 화면은 숨김/inert 상태임을 확인했다. 기존 테마와 사용자 프로필 경로 유지 확인. 시험 창은 정상 종료했다.

## 남은 조건

운영 계정으로 앱 내 로그인이 필요하다. 브라우저 Supabase 로그인과 Electron 앱 로그인은 별개다. 로그인 후 실제 사업장 목록 표시 및 주문 화면 진입은 아직 미검증이다. 설치된 EXE에 비밀번호 자동 입력, 외부 주문 수집·발급·인쇄·데이터 이전은 하지 않았다.

다음 단계는 사용자가 앱에서 로그인한 뒤 실인수를 마치고, 서버의 사업장별 업무 접근 분리를 이어가는 것이다. 현재 다른 사업장 업무 전환은 열지 않았다.
