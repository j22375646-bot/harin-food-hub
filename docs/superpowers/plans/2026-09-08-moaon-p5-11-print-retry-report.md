# P5-11 / 0.13.1 인쇄 상태·재출력 보호

## 이번 변경

- 인쇄 검증과 시스템 인쇄 요청이 처리되는 동안 인쇄 메뉴를 비활성화한다. 반복 클릭이 들어와도 같은 창에서 작업을 동시에 요청하지 않는다.
- 확인창 취소, 프린터 취소, 프린터 실패, 요청 전달 상태를 창 제목으로 구분한다.
- 동일 미리보기 창에서 다시 인쇄하면 중복 가능성을 알리고 실제 출력물과 대기열을 먼저 확인하도록 안내한다. 경고 이력은 해당 창에서만 유지되며 창을 닫거나 앱을 재실행한 뒤의 중복 인쇄를 영구 차단하는 기능은 아니다.
- 정상 콜백도 ‘실제 출력 확인 필요’로 표시한다. 자동 재시도나 실제 출력 완료 추정은 하지 않는다.

## 검증

- 최초 새 테스트 3개 실패 확인 후 구현. 최종 데스크톱 테스트 **104/104 통과**.
- 패키징된 app.asar를 격리 프로필/개발 Electron으로 실행한 화면 시험 통과: 조회, 미리보기, 스크립트 차단, 연결 해제 창 종료.
- 독립 검토에서 중요 결함 없음. 리뷰의 비차단 제안인 정상/실패 콜백 상태 테스트도 추가했다.
- `npm run pack` 성공. Windows x64 NSIS 0.13.1 생성. 실제 인쇄창·물리 프린터 출력은 시험하지 않았다.

## 이 컴퓨터 점검 결과

Windows 사용자 설치 등록 정보는 **Moaon Preview 0.9.0**으로 확인됐다. 실행 중인 MoaonPreview 프로세스는 조회되지 않았다. 등록 정보만으로 설치 파일의 실제 버전·다른 경로의 실행 여부까지 확정하지 않는다.

등록된 프린터는 Fax, Hancom PDF, Microsoft Print to PDF, Microsoft XPS Document Writer, OneNote (Desktop)이다. 실물 라벨 프린터는 목록에 없다. 다른 출고 PC인지 사용자에게 문의했다. 드라이버 설치·기본 프린터 변경·실제 출력·사용자 앱 업데이트는 수행하지 않았다.

사용자는 기존 앱을 종료한 뒤 새 설치파일을 실행해 업데이트한다. 기존 사용자 데이터 폴더를 삭제할 필요는 없다. 업데이트 후 앱 버전과 하린식품 재연결을 확인한다. 이번에 설치 마법사로 업데이트·로그인 유지 인수는 수행하지 않았다.

## 다음 단계

1. 실제 사용할 PC·프린터를 확정하고 해당 PC에서 설치·재실행 및 로그인 유지 확인.
2. 실제 용지 크기·여백·바코드 판독 확인. 100×150mm는 현재 기본값이며 사용자 장비 확인 완료값이 아니다.
3. 프린터 취소/실패/재출력을 실제 장비에서 인수한다. 이후 P5 전체 인수 상태를 갱신한다.
