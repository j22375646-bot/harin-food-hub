# P4-25 — 앱 주문 작업 도구 묶음 / 0.16.0

작성일: 2026-09-09

## 이번 인도

사용자의 앱 개발 우선 요청에 따라 사업장 저장소 후속을 잠시 뒤로 두고, 주문·배송 화면의 실제 작업 편의를 한 묶음으로 구현·검증·설치했다. 이 PC는 **0.16.0으로 업데이트 완료**다. 운영 웹/API/DB는 변경하지 않았다.

| 기능 | 사용 방법 |
|---|---|
| 채널별 보기 | 주문 목록의 채널에서 현재 페이지에 존재하는 채널 선택 |
| 금액순 정렬 | 높은 순/낮은 순/불러온 순서 선택. 미확인 금액은 양쪽 모두 마지막 |
| 초기화 | 검색어·채널·정렬·사전 확인 필터를 한 번에 원상 복구 |
| 상세 단축키 | 주문 선택 후 Alt+↓ 다음 상세, Alt+↑ 이전 상세 |

상세 이전·다음 버튼 자체는 이전 버전에 이미 있었다. 이번에는 단축키를 추가하고 필터/정렬 후에도 현재 표시 순서대로 이동하는지 검증했다. 검색 입력·select 조작·한글 조합 중에는 새 단축키가 입력을 가로채지 않도록 했다.

필터에 가려진 선택 주문은 상세에서도 닫는다. 연결 해제/새 페이지 로딩 시 검색·채널·정렬을 초기화한다. 선택 상태를 디스크에 저장하지 않아 다른 사업장이나 로그인으로 넘겨 쓰지 않는다.

**모든 새 작업 도구는 현재 불러온 페이지에만 적용된다.** 전체 주문 검색이나 서버 전체 정렬을 제공하는 것은 아니다. 클릭할 때 추가 수집/API 호출 없이 화면에서 처리한다. 금액을 합계로 재계산하거나 정산 수치를 바꾸지 않는다.

## UI 적용

Frontend Design 스킬에 따라 기존 모아온의 글꼴·색상·다크모드 토큰을 유지했다. 채널/정렬/초기화를 목록 작업 도구로 묶고 좁은 창에서 줄바꿈한다. 1040×720에서는 기존 목록 작업 영역을 스크롤해 주문을 볼 수 있다. 새 도구 때문에 본문 글꼴을 축소하지 않았다.
