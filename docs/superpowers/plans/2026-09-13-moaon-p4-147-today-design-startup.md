# P4-147 · 오늘 화면과 시작 대기 정리 · 0.134.0

- 요청: 기존 오늘 구조 유지, 부드럽고 변화 있는 문구, 자금 박스 축소/시각화, 절제된 동적 효과, 기능/UI 회귀 없이 시작 지연 조사.
- 한국 시간대별 새벽/아침/오후/저녁 인사와 날짜 배지, 업무 설명을 표시한다. 갱신 시에도 시간대를 반영하며 화면에서 계속 문구를 돌리거나 추가 타이머를 만들지 않는다.
- 자금은 3개 소형 카드와 공통 기준 막대로 표시한다. API에는 월 집계만 있으므로 일별 추세를 만들지 않았다. 막대는 알려진 금액의 절댓값 비교이며 수익률/완료율이 아니다. 음수는 원래 숫자와 위험색, PARTIAL은 부분 확인, 미확인은 빗금/확인 필요로 구분한다. 예상 잔액은 실제 입금액이 아니라는 기준을 유지했다.
- 좁은 창은 카드가 한 열로 바뀐다. 숫자 자릿수/한글 줄바꿈을 허용하고 기본 가독성 크기를 유지한다. 주문 차트 등장과 자금 막대 애니메이션은 짧게 적용하며 reduced-motion에서 비활성이다.

## 시작 과정 조사

- 변경 전 격리 프로필 3회 로컬 창 load까지 1167/806/1149ms. 인증된 서버 데이터와 사용자 PC의 체감 시작 전체를 측정한 값이 아니다.
- main.cjs는 창을 로드하기 전에 Windows 바로가기 복구를 await했고, 이미 일치하는 링크에도 매번 Explorer 쓰기를 수행했다. 창 아이콘/AppID는 계속 먼저 지정하고 바로가기 복구만 ready-to-show 뒤로 이동했다. 기존 링크 속성이 모두 일치하면 쓰지 않는다. 오래된 링크 복구/사용자 인자/작업표시줄 고정 링크 보호는 유지한다.
- 안전한 세션 정리, 로그인, IPC 권한, 트레이/알림, 자동 업데이트 검증은 그대로 둔다. 로그인/서버 응답 지연까지 해결되었다거나 사용자 환경의 지연 원인이 하나로 확정됐다고 주장하지 않는다.
- 재현용 desktop/test/startup-timing-smoke.cjs 추가. 격리 Electron의 로컬 셸 준비 시간만 측정한다. 최초 재측정은 UI 감사와 병렬이라 속도 개선 비교에 사용하지 않는다.
