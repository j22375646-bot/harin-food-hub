## 완료한 작업

이전 P4-22에서 만든 0.15.4를 이 PC에 실제 설치했다. 앱 프로세스가 없는 것을 확인하고 설치파일 SHA256을 대조한 후 실행했으며 설치 종료 코드는 0이다. 프로필이나 로그인 정보를 삭제하지 않았다.

실제 설치 EXE의 재시작 테스트에 ‘주문 업무 열기’ 버튼 클릭 검증을 추가했다. 단순히 버튼이 존재하는지만 검사하지 않고, 클릭 후 주문 화면과 ACTIVE 조회 성공까지 확인한다. 앱 기능 코드는 이번에 바꾸지 않았으며 기존 설치파일을 적용한 단계다.

## 실제 검증 결과

- 첫 시험은 `Target page, context or browser has been closed`로 중단됐다. 종료 주체는 확인되지 않았으며 사용자 조작이나 앱 결함으로 단정하지 않는다.
- 같은 조건 재시험은 통과했다. 이어 버튼 클릭 검증을 추가한 최종 시험도 통과했다.
- 최종 시험의 두 번 재실행 모두 버전 0.15.4, 로그인 화면 생략, 기존 dark 테마, 소속 사업장 1개 유지.
- ‘주문 업무 열기’ 클릭: 주문 화면 진입, ACTIVE / READY.
- 송장 발급 전: 1건 / 1행 / READY, 1,986ms.
- 송장 등록 후: 0건 / 0행 / READY, 1,939ms.
- 배송중: 2건 / 2행 / READY, 1,905ms.
- 완료·취소: 87건 중 20행 / READY, 1,939ms.
- 완료 목록 다음 페이지 offset 20 및 이전 페이지 offset 0 모두 20행 조회 성공.
- JavaScript pageerror 없음. `git diff --check` 통과.

화면 준비는 두 실행 모두 약 405ms였다. 두 번째 실행에서 세션 확인과 사업장 목록 확인까지 약 2.94초였다. 첫 실행 총 19.20초는 버튼 클릭·여러 상태 조회·페이지 이동을 포함한 **시험 전체 시간**이며 로그인 소요 시간이 아니다. 단일 PC·회차 측정으로 항상 같은 속도를 보장하지 않는다.

검증은 이미 저장된 주문의 조회만 수행했다. 새 주문 수집, 우체국 송장 발급, 실제 프린터 출력, 고객 알림 전송은 실행하지 않았다.
