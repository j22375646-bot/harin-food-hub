# P4-149 · 업데이트 반복 안내와 실행 경로 · 0.135.0

## 관찰과 원인 범위
- 조사 시 실제 MoaonPreview.exe는 D:/GPT/Apps/Moaon/releases/0.129.0에서 실행 중(4개 프로세스), 관리 current.json/바탕화면은0.134.0이었다. 오래된 앱이 트레이에 남아 새 실행의 단일 인스턴스 요청을 받아 구버전 창을 여는 상태다.
- Windows 제거 등록은0.52.1 및 C:/Users/a/AppData/Local/Programs/Moaon Preview에 남아 있었다. 기존 NSIS 업데이트는 installDirectory를 지정하지 않았다. 설치 경로와 실행 경로가 분리될 수 있는 코드 결함을 확인했다. 사용자의 직전 설치가 어느 지점에서 종료됐는지는 설치 로그를 확보하지 못했으므로 단정하지 않는다.
- 기존 버전 비교는 동일/이전 버전을 CURRENT로 처리하고 시험도 통과한다. 안내를 숨겨 문제를 감추는 변경은 하지 않는다.

## 수정
- 서명 업데이트 NSIS 대상 디렉터리를 실제 process.execPath의 부모 폴더로 지정한다. 과거 레지스트리 경로에 다른 사본을 업데이트하는 것을 방지한다.
- publish-local은 바탕화면뿐 아니라 기존 시작 메뉴/작업표시줄의 알려진 모아온 링크도 같은 실행 파일로 갱신한다. 실행 인자는 보존하고 다른 앱 링크는 변경하지 않는다.
- 고정 Ed25519 공개키/설치 직전 해시 검증/업데이트 작업 잠금/명시적 재시작/트레이 안전 종료는 유지한다.
- 기존 구버전 종료는 사용자에게 트레이 종료를 요청했다. 실행 중 작업을 강제 종료하지 않았다. 사용자 실제 세션의 최신 버전 전환 확인은 아직 별도다.
