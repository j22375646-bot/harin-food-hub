## 시안 체험

[시안 HTML](../designs/studio-v3/index.html) · [화면 이미지](../designs/studio-v3/preview.png)

이 PC의 미리보기 서버가 실행 중이면 http://127.0.0.1:8879/ 에서 열 수 있다. 서버는 로컬에만 바인딩하며 시안 디렉터리만 제공한다. 서버가 꺼지면 HTML 파일을 브라우저로 직접 열어도 된다. 외부 라이브러리·API·계정 연결·운영 자료가 없는 독립 시안이다.

V2의 생성 이미지에서 V3는 직접 클릭 가능한 HTML/CSS 화면으로 전환했다. 이번에는 이미지 생성 도구가 아니라 Frontend Design 스킬을 활용한 코드 시안이다. 새 폰트·이미지·라이브러리 다운로드 없이 동작한다. 상품 그림은 가명 상품을 구분하는 도형이며 실제 상품 이미지 수집 결과가 아니다.

### 실제 작동하는 시안 동작

- 상태 필터, 검색, 채널 선택과 초기화. 표시 건수는 가명 목록에서 계산한다.
- 주문 선택과 상세, 이전/다음, 상세 닫기/다시 열기, 선택 해제.
- 하단 선택 도구막대와 접히는 작업 결과. 결과는 고정 예시임을 표시한다.
- 라이트/다크 전환, Ctrl+K 검색 포커스, Escape 닫기.
- 확인 버튼은 시안 안내 대화상자만 연다. 실제 발급/출력 없음.
- 다른 메뉴는 구성 제안임을 알린다. 실제 기능이 연결된 것처럼 이동시키지 않는다.

### 동적 효과

| 효과 | 구현 |
|---|---|
| 상세 선택 전환 | 180ms 불투명도·8px 이동 |
| 선택 도구막대 | 140ms 등장 |
| 작업 결과 내용 | 180ms 등장 |
| 상세 공간 접기 | 220ms 레이아웃 전환 |
| 버튼 상태 | 140ms 색상·누름 반응 |
| 설명 툴팁 | 지연 없이 hover/키보드 포커스 표시 |
| 움직임 줄이기 | 수동 버튼 및 OS reduced-motion 지원 |

동작이나 자료 변경은 효과 종료를 기다리지 않는다. 실제 API 진행률처럼 보이는 거짓 애니메이션은 넣지 않았다. 운영 앱의 UI는 교체하지 않았다.

검증: Edge 기반 Playwright에서 선택·필터·상세·대화상자·테마·reduced-motion·1040/760px 가로 넘침 없음, 화면 스크립트 오류 없음 확인. Python Playwright가 없어 기존 Node Playwright로 실행했다. 실제 Windows 배율 125/150% 및 스크린리더 전체 인수는 아직 하지 않았다.

## P4-28 실제 앱 기능

P4-27의 발급 완료 후 재조회에서 주문이 현재 페이지에 없으면 **송장 등록 후 목록 열기**를 표시한다. 누르면 기존 등록 후 목록 조회를 실행한다. 자동 재발급이나 전체 주문 무제한 탐색은 하지 않는다. 목록에서 주문을 선택해 상세·기존 송장 미리보기로 이어간다.

실패/일반 재조회에 무조건 버튼을 붙이지 않는다. 화면 새 조회/해제 시 안내 버튼을 비운다. 현재 페이지에 주문이 남는 기존 경로도 유지한다.

검증: 새 안내 버튼 없음으로 실패를 재현한 후 구현. 가명 출고 완료 후 같은 목록에 남는 경우와 REGISTER로 이동하는 경우 모두 통과, 발급 POST 1회 유지. 단위 시험 124개 통과. 실제 고객 송장 발급/출력은 실행하지 않았다.

0.17.2 패키징 종료 0, 최종 패키지의 이동 시나리오 통과. SHA256 대조 후 이 PC 설치 종료 0. 실제 서버 연결 인수 시험은 전체 상태 요약 카드가 READY/PARTIAL인지 확인하는 단계에서 실패했다. 설치 완료와 운영 연결 전체 정상은 구분한다. 신규 동선 자체는 가명 검증이며 실제 주문 발급으로 인수한 것은 아니다.
