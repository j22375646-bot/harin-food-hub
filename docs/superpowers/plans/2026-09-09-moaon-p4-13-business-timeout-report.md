# P4-13 사업장 목록 시간 초과 복구

## 실제 원인과 변경

미국 iad1 API에서 싱가포르 제어 DB로 반복 왕복하며 요청의 10초 제한을 초과했다. 개인정보 없는 단계별 시간 로그를 추가하여 운영에서 재현했다. SQL·자격 증명·사용자 정보·원본 오류는 로그에 남기지 않는다.

기존 기록: DB 조회 3,178ms / 인증 2,069ms / DB 조회 1,874ms / DB 조회 1,871ms. 마지막 DB 시간 확인까지 끝나기 전에 REQUEST_TIMEOUT 발생.

vercel.json의 해당 함수만 sin1에 배치했다. 다른 함수 지역, 인증/권한/세션 검증, DB 데이터와 UI는 변경하지 않았다. 새 유료 자원은 생성하지 않았다. 지역별 사용량 단가 차이는 별도일 수 있다.

## 검증

- 관련 시험 14개 통과, 전체 pnpm test 2,588개 통과, 실패/스킵 0.
- 로컬 빌드와 운영 빌드 성공.
- 코드 ccadc63, 운영 dpl_8tL8ZuRoGRY8k5ZmJ6h5Au3JajGv READY.
- 실제 로그인 브라우저 /api/moaon/businesses: ok:true, 하린식품 OWNER 1건, membershipVersion 1 확인.
- 수정 후 단계 기록: DB 107ms / 인증 388ms / DB 29ms / DB 30ms / DB 27ms. 합계 581ms. 이는 서버 내부 측정 구간 합계이며 전체 브라우저 로딩시간이나 p95가 아니다.
