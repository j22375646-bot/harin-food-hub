# P4-110 · 재고 단위·카페24 상품 연결·공통 선택창 (0.96.0)

## 변경

- 단위를 개/KG/티백/박스로 제한. 개/티백/박스는 정수, KG는 소수 셋째 자리까지 허용한다. 보유 중량/수량 라벨, 입력 간격, 1g 안내, 입출고 변경 수량에도 적용한다. 서버에서도 같은 규칙을 검사하고 kg는 KG로 정규화한다. 기존 비표준 단위를 자동 변환하지 않는다.
- 카페24 판매·진열 중이고 품절/웹허브 상품 제외 대상이 아닌 저장 상품을 가나다순으로 연결한다. 상품 검색·선택 시 재고 상품명을 채우고 연결 해제/새 제조번호 복사를 지원한다.
- 연결 상품의 번호·이름은 서버가 검증한다. 신규 연결은 판매 상태를 재확인한다. 판매 중단된 기존 연결은 재고 편집을 막지 않으며, 구버전 앱이 수정해도 연결 정보/특이사항을 지우지 않는다.
- 전역 Cafe24 카탈로그는 기존 하린 사업장 문맥에서만 제공한다. 다른 사업장에는 노출하지 않는다. 재고는 기존 사업장별 JSONB DB·revision·변경 이력을 사용하며 스키마 변경은 없다.
- 특이사항을 메모·입출고 기록과 분리하여 저장하고 목록에서 요약 표시한다. 보관방법은 상온/냉장/냉동 및 직접 입력을 지원한다.
- 모든 페이지의 select에 공통 base-select picker 스타일을 적용했다. 16px 선택창, 44px 이상 옵션, 앱 색상·테두리·선택 표시·키보드 동작·동작 줄이기를 유지한다. 재고 입력/상품 선택은 17px 중심으로 확대하고 수량/단위 입력칸을 정렬했다.
