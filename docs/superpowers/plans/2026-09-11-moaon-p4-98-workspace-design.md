# P4-98 — 전체 페이지 공통 디자인 개편 (0.85.0)

## 사용자 요청과 확인
- 전체 페이지를 판매용 앱 관점에서 통일하고 변화가 눈에 보이도록 개선한다.
- 최초 청록색 방향은 사용자가 거절했다. 최종 방향은 흰색/쿨그레이/잉크색 메뉴와 블루 강조다. 상태 의미의 정상 색은 유지한다.
- 현재 실행 중인 프로세스는 C:/Users/a/AppData/Local/Programs/Moaon Preview/MoaonPreview.exe였으며, 해당 app.asar/package.json에서 0.52.1을 확인했다. D 바로가기는 0.84.0을 가리키고 있었다. 실행 중인 구버전이 최신 UI를 표시하지 않는 원인을 확인했다.

## 구현
- 오늘, 주문·배송, 운영·정산, 분석, 캘린더, 재고·상품, 고객·CS, 앱 설정의 제목에 workspace-heading 공통 클래스를 적용했다.
- 제목32px/750, 설명14~15px, 주요 조회 버튼44px, 카드18px, 헤더 구분선과 공통 여백을 적용했다. 기존 ID별 제목 스타일 충돌을 제거했다.
- 1280px 이상 창에서는 196px 메뉴에 제품명·아이콘·메뉴명을 표시한다. 좁은 창에서는 84px 메뉴를 유지한다. 8개 메뉴 아이콘을 동일 선형 SVG로 교체했다.
- 공통 배경/면/선/선택/입력 초점/라이트·다크 토큰을 변경했다. 로그인 진입 화면에도 브랜드 색과 카드 규칙을 반영했다.
- 페이지 진입300ms, 제목380ms, 실제 주문 막대 등장480ms와 버튼 눌림 반응을 적용했다. 동작 줄이기에서는 진입/차트 효과를 끈다. 가짜 수치나 추세를 추가하지 않았다.
- 주문 수집 영역을 제목 옆으로 정렬하고 버튼 크기를 맞췄다. 다른 페이지의 조회 버튼도 헤더 상단에 정렬했다.
