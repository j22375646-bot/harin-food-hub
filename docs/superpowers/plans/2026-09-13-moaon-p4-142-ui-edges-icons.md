## 수정

- 오늘 주문 행: 양옆 여백과 12px 모서리, 내부 패딩을 적용해 hover 배경이 잘린 사각형처럼 보이는 문제 수정.
- 업무 완료: 서로 겹치던 두 CSS 체크 표시 중 하나를 제거. 24px 민트색 둥근 사각형과 단일 체크로 통일.
- 캘린더 업무 목록: 스크롤 영역 안에 6px 여백을 확보해 왼쪽 체크박스의 포커스 외곽선이 잘리지 않도록 수정.
- Windows: 실제 실행 창의 WM_GETICON과 실행 파일 추출 아이콘은 모아온 로고였으나 같은 AppUserModelID를 가진 옛 시작 메뉴 바로가기가 삭제된 0.123.0 실행 파일을 가리켰다. 바탕화면 바로가기에는 AppUserModelID가 없었다. 이 불일치를 아이콘 재발 원인 후보로 확인했다.
- 패키지 앱 시작 시 모아온 소유의 바탕화면·시작 메뉴·기존 작업표시줄 고정 바로가기를 현재 실행 파일과 고정 userData ICO로 복구한다. 기존 실행 인수와 앱 ID를 유지하고 다른 앱 바로가기는 건드리지 않는다. 고정 바로가기를 새로 생성하지 않는다.
- 창의 별도 relaunch icon 속성은 설정하지 않는다. NSIS 설치 ID와 업데이트 서명 키도 유지한다.
