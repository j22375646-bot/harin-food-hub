# P4-119 · 파스텔 업무 공간 (0.105.0)

## 디자인 방향

실제 판매하는 업무 앱을 목표로 밝고 부드러운 파스텔, 선명한 본문과 숫자, 읽기 쉬운 차트, 절제된 동작을 적용한다. 공통 메뉴·폼·버튼·대화상자·상세·표의 표현을 통일하며 상태와 숫자의 의미를 보존한다.

- 라벤더 `#eeeafd`, 민트 `#e6f5ef`, 살구 `#fff0e6`, 하늘 `#eaf2fc`. 본문 `#28283d`, 주요 행동 `#6957cb`.
- 본문은 배포에 포함된 Pretendard. 제목은 설치된 G마켓 산스 Medium을 local 폰트로 시도하고 없으면 Pretendard로 표시한다. 새 폰트 파일을 복사하거나 재배포하지 않는다.
- 밝은 사이드바와 전체 면을 쓰는 선택 표시, 부드러운 외곽선과 그림자. 목록에서는 상품·수량·상태의 읽기 순서를 유지한다.
- 오늘 화면의 주문 구성 도넛과 상태별 카드가 대표 요소다. 송장 발급 전·배송대기·배송중의 합계만 진행 중 주문으로 집계한다. 완료·취소는 별도 카드이며 도넛 분모에 넣지 않는다.
- 대화상자 등장과 기존 화면 전환 모션은 짧게 유지한다. reduced-motion에서는 제거한다. 호버·포커스와 키보드 경로를 유지한다.

## 구현 범위

`pastel.css`는 최종 공통 디자인 토큰과 화면별 표현을 소유한다. 보안 프로토콜에는 이 로컬 CSS 파일만 추가 허용한다. 기존 공통 카드 규칙의 `:is()`가 내부 ID 때문에 모든 카드에 높은 우선순위를 부여하던 부분은 `:where()`로 정리한다.

오늘·주문·정산·분석·캘린더·상품·재고·고객·설정의 공통 외관을 다듬고, 오늘의 자금 카드 내부 박스는 구분선으로 단순화한다. 정산의 예상/확인 금액 막대는 라벤더/민트로 구분한다. 재고의 목표 충족 막대는 소진 위험에 따라 민트/살구/로즈를 사용하며 기존 위험 문구도 유지한다.

도넛은 세 진행 상태가 모두 READY이고 안전한 정수일 때만 그린다. 부분·누락·실패 자료는 대시와 확인 필요 문구로 남긴다. 실제 0건은 0과 비어 있는 링으로 표현한다. 접근 가능한 SVG 설명과 기존 상태별 목록 이동 버튼을 제공한다. 새 데이터 수집·재무 계산·재고 차감·주문 발급 동작은 변경하지 않는다.
