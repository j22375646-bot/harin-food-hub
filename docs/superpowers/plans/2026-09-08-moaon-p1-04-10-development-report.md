# 모아온 P1-04-10 개발 보고서

## 이번 단계

복구 이력을 검토할 때 로그인만으로 진행하지 않고, 최근에 추가 인증을 마친 증거를 확인하는 문지기와 여러 서버가 함께 쓰는 요청 제한 기반을 만든다. 기존 로그인·화면·주문·정산 기능을 바꾸는 작업은 아니다.

구현·자동 검증·독립 최종 검토를 마쳤고 운영 코드 배포를 진행한다. 실제 MFA 등록 화면이나 공급자의 인증 증거 발급기는 이번 단계에 연결하지 않는다. 필요한 증거가 없으면 허용하지 않는 방식이다.

## 쉽게 설명하면

| 만든 부분 | 하는 일 | 필요한 이유 |
|---|---|---|
| 추가 인증 확인 | 최근 5분 이내의 인증 증거가 현재 사용자·현재 로그인 세션의 것인지 확인 | 로그인 쿠키만 가진 사람이 중요한 복구 이력을 처리하지 못하도록 함 |
| 공통 요청 제한 | 운영자별 한도와 전체 서비스 한도를 DB에서 함께 검사 | 서버가 여러 개여도 각자 따로 세어 제한을 넘기는 일을 방지 |
| 처리 직전 재확인 | 대기 중 만료·로그아웃·취소 여부를 다시 확인 | 처음에는 유효했어도 기다리는 동안 자격을 잃은 요청을 차단 |
| 운영 적용 점검표 | 실제 인증 연결, DB 권한, 공개 조건을 구분 | 코드가 만들어졌다는 이유만으로 미완성 인증을 운영에 공개하지 않도록 함 |

이번에는 보이지 않는 서버 내부 기반을 보강했다. 화면에 새 버튼이 생기거나 로그인 방식이 바뀌는 단계가 아니다. 다른 사업자가 자신의 계정을 연결하는 모아온을 만들기 위한 순서이며, 기존 하린식품 업무 기능을 대체하지 않는다.

- 수정 커밋 `d461196`: 미래 시각 재검사와 서버 내부 거부 사유 보존을 추가했다. 잘못된 외부 오류를 신뢰하지 않는다. 먼저 admission/resolver 두 경로에서 200→예상403 실패를 재현했고, 수정 후 집중 **53/53**, 주 검증자 전체 **2,310/2,310** 통과(54.49초, 실패·취소·건너뛰기 0).

- 실제 DB 테스트가 생성한 임시 DB는 모두 정리됐으며 `postgres`와 기존 `moaon_test_supervisor`만 남은 것을 확인했다. 로컬 PostgreSQL 서버 정상 종료(exit 0). 운영 데이터는 사용하거나 삭제하지 않았다.

## 주요 재현 검사

- 추가 인증 검증기가 없는 factory: 수정 전 TypeError가 없어 실패(15/16), 필수 조건 추가 후16/16.
- 증거가 없는 요청: 수정 전200/예상403 실패, 이후 DB 처리0회와403 확인.
- 잘못된 증거 형식·다른 세션·만료: 먼저 실패를 확인한 뒤 정확한 snapshot 검증 추가.
- 요청 제한/재확인 순서: 수정 전 예상429 대신503 및 순서 누락을 재현, 연결 후 통과.
- 시각 후퇴: admission/resolve 양쪽에서 수정 전200/예상403 실패, 수정 후 실제 후속 RPC0회와403 통과.
- 구현 중 DB/연결부 집중 **8/8** 통과 보고. 조회30/31·종결10/11 경계, 서비스 전체 공유, 한쪽 제한 시 부분 차감 방지, 창 초기화·미래 시각, rollback, 권한·세션 거부 및 인증 상태 보존을 포함한다. 최종 통합 검증과는 구분한다.

## 개발 중 판단

1. 실제 MFA 증거 발급을 별도 활성화 조건으로 분리하고 필수 서버 검증기에 기본 성공값을 두지 않는다. 기존 쿠키는 MFA 증거가 없기 때문이다. 이 선택의 비용은 실제 증거 발급기를 연결하기 전 기능을 사용할 수 없다는 점이다.
2. 후보 제한은 60초 동안 운영자별 조회30회/종결10회, 서비스 전체 조회300회/종결100회로 정했다. 요청자가 한도를 바꿀 수 없으며 승인 후 실패·취소 시 환불하지 않는다. 실제 업무량보다 낮으면 정상 업무도 제한될 수 있어 활성화 전 조정이 필요하다.
3. 요청 승인과 이력 처리는 별도 DB 트랜잭션이다. 세션/증거를 다시 확인하고 실제 전송 직전 취소를 검사하지만, 이미 전송된 작업을 로그아웃이 원자적으로 취소한다고 약속하지 않는다. 접수된 작업이 로그아웃 뒤 완료될 수 있으므로 활성화 전에 정책을 확인한다.

## 적용하지 않는 것

새 공개 주소·운영 SQL·MFA/메일·운영자 계정·환경 설정을 활성화하지 않는다. 운영 자료 복사나 새 유료 테스트 자원은 만들지 않는다. 기존 서비스 사용량까지 무료라고 보장하는 의미는 아니다. Windows EXE와 다사업장 공개도 완료 단계가 아니다.
