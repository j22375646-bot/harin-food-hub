# P4-49 — 선택 주문 작업표·송장 묶음

2026-09-09 / 모아온 0.34.0 / 구현·패키지 검증·이 PC 설치 완료

## 목적과 범위

기존 웹 허브의 주문 내보내기 및 100×150mm 송장 출력을 앱 전용 선택 작업에 연결한다. 웹 페이지를 삽입하지 않고 현재 선택 주문과 서버 재확인 결과로 문서를 만든다. 새로운 API·DB·유료 서비스를 추가하지 않는다.

웹 엑셀 API는 검색 조건 전체를 내보내므로 선택 주문 기능에 그대로 호출하지 않는다. 이번 작업표는 Excel에서 열 수 있는 UTF-8 CSV이며, 서식 있는 XLSX와는 다르다. 현재 페이지 최대20건의 선택만 포함하고 수취인 주소·연락처는 제외한다.

송장 묶음 미리보기는 Cafe24·쿠팡 판매자배송의 등록된 송장을 대상으로 한다. 네이버 직접 송장 출력 지원을 확장한 것이 아니다. 같은 송장번호 중복, 취소, 미등록, 배송정보 누락은 출력 대상으로 묵인하지 않는다.

## 사용자 흐름

1. 주문을 선택하고 추가 작업에서 CSV 저장 또는 송장 묶음 미리보기를 선택한다.
2. 앱이 선택 주문을 서버에서 다시 확인한다. 선택 당시와 달라졌으면 재조회하도록 안내한다.
3. CSV는 Windows 저장창에서 위치를 선택한다. 선택한 작업표만 저장하며, 확인할 수 없는 수량·금액은0으로 바꾸지 않는다.
4. 송장은 주문별 한 장씩 메모리 안에서 미리보기를 연다. 문서를 여는 것만으로 인쇄하거나 재발급하지 않는다.
5. 사용자가 인쇄 메뉴를 선택하면 주문·송장·수취정보를 다시 확인하고 인쇄 설정을 연다. 인쇄 요청 전달과 실제 출력 완료를 구분한다.

## 검증 기록

- 단위 테스트 **193/193 통과**. CSV 수식 방지, 취소·주문 변경·로그아웃 후 저장 차단, 중복 송장과 두 번째 라벨 신원 변경 차단을 포함한다.
- 실제 Electron Main/preload/IPC/UI를 통한 두 장 미리보기·문서 크기·선택 유지·작업 중 잠금·1040×720 버튼 접근 시험 통과. CSV 저장창·파일 쓰기와 외부 통신은 시험용 대체 객체로 검증했다.
- 패키지에서 신규 문서, 단일 라벨, 수집, 배송추적, 자동 발급·등록, 수동 등록 UI 회귀 시험 모두 통과.
- 독립 검토에서 발견한 초기 서버 조회 무한 대기/잠금 문제 수정. CSV·단일/묶음 송장의 시간 초과 및 로그아웃 6조합으로 잠금 해제·늦은 응답 차단을 검증했고 재검토 통과.
- `npm run pack` 성공, 0.34.0 설치 종료 코드0. 운영 서버 배포·DB 변경·새 유료 서비스 추가 없음.
- 설치 EXE 두 번 실행에서 저장 로그인 유지, 네 주문 구간 및 페이지 이동 조회 통과. 열 제목/뱃지 정렬 오차0px, 패널 닫힘 동안22개 너비 변화 프레임, 숨긴 스크롤 검증 통과.
- 실제 등록된 쿠팡 주문2건의 메모리 전용 송장 묶음 미리보기 **통과**. 최초에는 긴 상품명·주소의 누적 여백으로 용지 높이를 초과해 차단됐다. 글자 크기(상품14px·주소18px·수취인24px)를 유지하고 여백/간격을 축소한 뒤 재패키징·재설치하여 실주문2건을 다시 확인했다. 합성 상품명69자·주소54자와 두 번째 라벨1500자 거부 시험도 통과. 실제 파일 저장·인쇄·출고 쓰기는 없었다.
- 실제 발급·플랫폼 전송·물리 인쇄는 실행하지 않았다. 모의 시험 통과를 실제 출고 완료로 취급하지 않는다.

## UI 디테일

선택 도구막대의 ‘추가 작업’ 안에 기능을 배치해 주 화면의 버튼을 늘어놓지 않았다. 출력 가능/제외 건수와 중복 송장 안내를 표시하며 미지원 주문이 섞이면 묶음 미리보기를 잠근다. 선택 주문은 유지하고 결과를 ‘미리보기 열림’, ‘CSV 저장’, ‘저장 결과 확인 필요’로 구분한다. 기존 Pretendard·앱 색상·숨긴 스크롤 및 상세 패널 전환을 유지한다.

## 다음 개발 — P4-50

주문 페이지를 계속 우선한다. 기존 웹의 A4 포장명세서·출고 작업표를 앱의 선택 주문 흐름에 이식하고, 선택 수량·페이지 나눔·인쇄 전 정보 재확인을 검증한다. 출고용 PC에서 프린터 모델/용지를 확인한 뒤 시험 라벨 치수와 바코드 스캔을 별도 인수한다. 실제 우체국 발급→플랫폼 등록→출력은 대상 주문을 명확히 정한 운영 인수로 남긴다.

## 남는 범위

실제 출고용 PC의 프린터·용지·스캔 인수, 포장명세서/A4 작업표와 서식 XLSX 확대는 별도다. PDF 프린터 출력은 운영체제 인쇄 설정의 선택이며 자동 PDF 저장 기능과 같지 않다. 송장 재출력 경고는 실제 인쇄 성공을 추정하지 않는다.
