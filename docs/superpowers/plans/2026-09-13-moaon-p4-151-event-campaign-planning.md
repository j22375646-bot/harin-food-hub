## 적용 범위

이벤트 기획에 할인 없음/정률(1~100%)/정액(최대 1억원 정수), 할인 조건·상품, 메시지 계획 없음/예정/완료, 채널·대상, 예정일·실제 발송일을 추가한다. 완료 선택 시 오늘을 기본 입력하며 수정 가능하다. 상세 패널에 같은 기록을 표시한다. 이 항목은 기획 기록이며 실제 상품 가격 변경·고객 메시지 발송은 실행하지 않는다.

기존 이벤트 body의 선택적 campaign 필드로 보존한다. 엄격한 기존 plan 구조를 변경하지 않아 구버전 앱의 해석을 유지하고, 구버전이 campaign을 생략한 수정도 서버 POST에서 기존 값을 보존한다. 새 앱은 서버 응답의 campaign을 대조해 이전 서버가 기록을 무시했을 때 성공으로 표시하지 않는다. 스키마 변경 없음. 사은품·플랫폼 범위·금액/날짜 판정은 유지한다.

## 헤르메스·텔레그램 제안 — 미도입

추천 순서: 기존 서버의 Telegram Bot 알림 → 필요한 경우 Hermes 읽기 요약 시험. Cafe24 Hermes는 쇼핑몰 기본 기능이 아니라 별도 VPS의 AI 에이전트이며, 공식 가이드에서 텔레그램 대화·영구 기억·스케줄 작업을 지원한다. 모아온의 데이터 API와 권한을 연결하는 작업은 별도다.

1. 텔레그램 1차: 가족의 허용된 chat ID만 연결. 주문/미답변 문의/오늘 일정/발송 예정 미처리 요약과 해당 모아온 화면 링크. 집계 숫자와 제목 중심, 고객 주소·전화번호·키 제외. 사업장별 구분과 중복 알림 방지, 마지막 수집 시각 표시, 오류·연결 만료 알림 및 끄기 제공.
2. PC가 꺼져도 받으려면 앱 트레이가 아니라 기존 서버에서 수집/알림을 실행한다. 휴대폰 텔레그램 알림 허용 및 서버 작동 필요. Telegram API 전달 성공은 사람이 읽었다는 의미가 아니다.
3. Hermes는 기존 전체계획 B3대로 아침 요약/주간 제안만 14일 비교. 읽기 전용 집계 API, 일일 사용량·비용 상한과 중지 버튼. 유료 VPS/LLM 신청·봇 생성·외부 전송은 이번 작업에서 하지 않는다. 실제 주문 수정·가격 변경·마케팅 발송은 별도 명시적 실행 흐름으로 유지한다.

공식 근거: https://help.cafe24.com/docs/server-hosting/hermes-agent-hosting/hermes-agent-quick-start-guide/

## 썸트렌드 활용안 — 현재 연결 확인 필요

현재 저장소에서 Sometrend 호출 구현은 확인되지 않았고, 핵심 연결 화면 시험에서는 명시적으로 제외돼 있다. 로컬 환경 이름과 Vercel production 환경 목록에서 SOME/VAIV/TREND 계열의 사용 가능한 Sometrend 키 항목을 확인하지 못했다. 다른 명칭·이전 프로젝트·외부 관리 저장본까지 부재를 증명한 것은 아니다. 사용자에게 기존 연결 방식/위치를 질문했다. 키값을 채팅에 요청하지 않았다.

공식 Data+ 소셜 API는 날짜별 키워드 빈도, 연관어, 감성·속성 연관어와 추이를 제공한다. 웹사이트 이용권과 API 이용 권한을 같은 것으로 간주하지 않는다. 실제 계약의 매체 범위·조회 기간·호출량·인증 방식·재사용 조건을 확인한 후 제한된 읽기 호출로 연결을 검증한다.

활용 흐름: 관심 키워드(차/선물세트/무카페인 등 사용자 상품에 맞춰 선정) → 최근 7일/30일 언급 변화와 연관어 → 상승 이유를 설명한 행사 아이디어 → 대상 상품/할인/메시지 초안 → 이벤트에 붙여넣기 → 기간 종료 후 채널별 실제 주문·매출과 함께 회고.

- 키워드 페이지: 별도 '소비자 관심' 카드에 언급량·감성 연관어·수집 시각·매체·기간·근거를 표시한다. 네이버 검색량·광고 입찰가는 기존 원천을 유지한다.
- 이벤트: 근거가 있는 행사 아이디어 3개와 대상/혜택/메시지 초안을 제공하고 사용자가 선택해 기획으로 만든다. 식품 효능을 사실처럼 단정하는 문구는 제외하고 상품 근거를 대조한다.
- 분석: 언급 추이와 자사 실주문 추이를 나란히 본다. 소셜 언급은 판매 예측이나 광고 ROAS가 아니며 성과 인과로 단정하지 않는다. 자료 누락/권한 만료는 확인 필요로 표시한다.
- 수집: 일 단위 캐시, 키워드 수·기간·호출량 제한, 최근 성공/실패·쿼터·중지 버튼을 API 카드에 제공한다. 실데이터 없이 예시 차트를 실제처럼 제공하지 않는다.

공식 근거: https://data.some.co.kr/social/api / https://data.some.co.kr/social/intro
