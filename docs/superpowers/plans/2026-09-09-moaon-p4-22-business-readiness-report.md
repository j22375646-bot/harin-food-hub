# P4-22 사업장 준비 상태와 안전한 업무 진입

작성일: 2026-09-09 · 모아온 Windows Preview 0.15.4

## 이번에 달라진 점

앱 설정의 ‘내 사업장’에서 이름과 역할만 보이던 목록을 업무를 시작할 수 있는 카드로 바꿨다.

- 하린식품 소유자: ‘현재 연결’과 ‘주문 업무 열기’ 버튼 표시.
- 하린식품의 소유자가 아닌 역할: 권한 확인 필요 안내와 비활성 버튼.
- 다른 사업장: 연결 준비 중 안내와 비활성 버튼. 기존 하린식품 주문을 다른 사업장 자료처럼 표시하지 않는다.
- 버튼을 누르면 기존 서버의 사업장별 주문 API로 다시 확인한 다음 주문 화면으로 이동한다. 목록에 보인 권한만 믿고 업무를 개방하지 않는다.
- 중복 클릭을 잠그고, 연결 해제 후 늦게 끝난 작업으로 화면이 다시 바뀌지 않도록 기존 세대 검사를 유지한다.

Frontend Design 스킬에 따라 기존 앱의 글꼴·색상·다크모드·전체 테두리 스타일을 재사용했다. 버튼 높이를 42px로 맞추고 긴 사업장 설명은 줄바꿈한다. 전면 UI 재설계가 아니다.

## 설치 상태: 파일 준비 완료, 현재 PC 적용 대기

실행 중인 기존 앱이 오늘 화면에 있고 진행 중 출고 대화상자가 없는 점은 확인했다. 그러나 정상 종료를 위한 Windows 창 활성화가 `failed to activate captured window`로 실패했고, 창을 다시 선택한 뒤 재시도해도 같은 결과였다. 강제 종료하거나 실행 중 파일을 덮어쓰지 않았다.

따라서 **설치파일은 0.15.4지만 이 PC에 실행 중인 앱은 기존 0.15.3이다.** 0.15.4 실제 설치·로그인 유지·실계정 버튼 인수는 완료로 계산하지 않는다. 사용자 프로필은 삭제하지 않았다.

## 다음 개발

1. 현재 앱 정상 종료가 가능한 상태에서 0.15.4를 설치하고, 기존 로그인·테마 보존 및 실계정 ‘주문 업무 열기’를 인수한다.
2. 다사업장 주문 저장 구조와 플랫폼 연결 자격 증명의 사업장별 분리를 구현한다. 다른 사업장을 열 수 있게 만드는 핵심 선행 작업이다.
3. 두 개의 가명 사업장으로 목록·상세·페이지 조회·로그아웃·권한 회수·늦은 응답의 데이터 혼입을 검증한 뒤 사업장 전환을 개방한다.
4. 실제 다른 사업장 연결과 출고 PC 프린터 출력은 해당 환경에서 별도 인수한다.

다른 사업장 계정이 목록에 나타나는 것과 해당 사업장의 주문을 안전하게 운영할 수 있는 것은 별개다. 이번 단계는 준비 상태를 명확히 보여주고 기존 하린식품 업무를 안전하게 여는 범위다.
