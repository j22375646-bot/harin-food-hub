# P4-131 · 오늘의 나의 일정

- 오늘 오른쪽의 작은 월간 표를 이번 주 날짜 선택과 오늘 일정 목록으로 교체했다. 큰 전체 달력은 기존 캘린더에서 유지한다.
- 날짜·제목·새로 조회 버튼을 정렬하고 시간/일정 제목/상태를 행으로 구분했다. 완료는 취소선과 세이지 상태, 예정은 연보라 상태로 표시한다.
- 날짜를 누르면 캘린더의 해당 날짜로 이동한다. 업무가 있는 날짜에는 표시점을 제공한다. 일정 제목도 캘린더로 연결한다.
- 오늘 페이지에서 일정 등록 폼을 직접 열며 오늘 날짜를 채운다. 조회 실패/날짜 불일치/빈 결과는 구분하고 자료 없는 상태를 0건으로 오인하지 않도록 유지한다.
- 조회 시작 시 날짜 표시를 갱신하고 기존 날짜 전환·중복 조회·로그아웃 보호를 유지했다. 캘린더 날짜 이동은 진행 중 조회를 기다린 뒤 적용한다.
