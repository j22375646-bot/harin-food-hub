# 모아온 개발 배포 · 고정 바로가기

- 검증을 마친 `win-unpacked`를 `desktop/scripts/publish-local.ps1 -PackageRoot <절대 경로>`로 배포한다. D:\GPT\enter-moaon.ps1을 먼저 실행한다.
- 배포 스크립트는 전체 패키지 대조 → D:\GPT\Apps\Moaon\releases\<version> 복사 → 재검증 → 바탕화면 모아온.lnk 갱신 순서로 실행한다. 사용자는 설치 파일을 다시 실행할 필요가 없다.
- 버전 역행·같은 버전 덮어쓰기·패키지 링크를 거부한다. 최신/직전/실행 중인 버전을 제외한 자체 관리 표시가 있는 릴리스만 정리한다. 사용자 데이터는 정리하지 않는다.
- 실행 중인 버전은 강제 종료하지 않는다. 종료 후 같은 바로가기로 새 버전을 연다. 오른쪽 모니터 지정은 유지된다.
- 개발 빌드 경로를 사용자 실행 바로가기에 연결하지 않는다. 개발 폴더를 사용자가 직접 찾아 실행하게 하지 않는다.

## 외부 사용자 자동 업데이트

- 앱 시작10초 후와6시간마다 확인하고 새 버전을 자동 다운로드한다. 적용은 업무가 끝난 뒤 재시작 버튼으로 진행한다. 진행 중 요청/자식 창은 재시작을 막는다.
- 현재 `update-channel.json`은 disabled다. 실제 HTTPS 배포 주소와 Windows 코드 서명 발급자, 일치하는 빌드 메타데이터가 필요하다. 이를 생략해 배포 준비 완료로 표시하지 않는다.
- 서명된 NSIS 설치 파일과 latest.yml/blockmap을 같은 신뢰된 배포 위치에 제공한 뒤 구버전→신버전 실제 인수를 해야 한다.
- 로컬 개발 배포 스크립트와 외부 네트워크 자동 업데이트는 별개다. 이 문서만으로 외부 배포가 활성화되지 않는다.
