# P4-15 내 사업장 화면 / Windows 0.15.2

## 완료

앱 설정에 내 사업장 카드를 추가했다. 기존 하린식품 주문 연결 성공 후 목록을 자동 조회하고, 소속 이름과 역할을 표시한다. 재조회 버튼, 빈 목록, 권한 부족, 로그인 만료, 시간 초과 안내를 구분한다. 로그아웃 시 표시를 지우며 이전 응답이 다시 나타나지 않게 한다. 기존 라이트/다크 테마를 재사용했다.

이 목록은 소속 확인용이다. 업무 전환 버튼은 제공하지 않으며 기존 하린식품 주문 연결에 다른 사업장을 끼워 넣지 않는다. 다른 사업장 선택/업무 접근은 미완료다.

## 검증

- UI가 없는 상태의 Electron 시험 실패를 확인한 뒤 구현했다.
- 데스크톱 단위 시험 119개 통과.
- 소스 및 app.asar 패키지 콘텐츠를 개발용 Electron으로 실행하는 격리 프로필 시험 통과. 외부 HTTP만 시험 응답으로 대체했다.
- 자동 목록, 시간 초과, 해제 시 목록 삭제, 이름의 HTML 문자 비실행, 라이트/다크 및 가로 넘침 검사.
- 다크모드 캡처 육안 확인.
- npm run pack 성공, Moaon-Preview-0.15.2-Setup.exe 생성(111,380,396 bytes).

## 미검증/미변경

새 설치파일의 설치 마법사 실행, 실제 운영 계정으로 Electron 안에서 목록 조회, 출고 PC 인수는 미실시다. 패키지 콘텐츠 시험은 설치 마법사/설치된 EXE 인수를 대체하지 않는다. 기존 사용자 앱 자동 교체 없음. DB/서버/외부 주문 변경 및 웹 배포 없음.

## 다음

0.15.2 설치 및 운영 로그인 인수, 사업장 전환 권한을 서버 업무 경로까지 검증하는 설계를 진행한다. 다사업장 주문/출고 격리 전까지 기존 업무 연결은 하린식품 전용으로 유지한다.
