# P4-164 묶음 주문 상품별 표시

주문 목록에서 대표 상품명 외 N개 대신 묶음 주문 제목과 상품별 카드로 표시한다. 각 카드에는 순번·상품명·옵션·수량을 구분한다. 동일 구성은 오른쪽 선택 주문 패널 상단에도 표시하여 추가 정보 펼치기 없이 확인할 수 있다. 서버 상품 데이터·수량·주문 처리 로직은 변경하지 않는다. 목록 API의 최대8개 제공 제한은 기존 상세 안내에 유지한다.

좁은 창(900px 이하)은 상세 패널과 목록을 수직 배치해 패널이 눌려 가려지지 않게 한다. 상품명/옵션은14px 이상, 선택 배경 위 카드 대비를 유지한다.

실제 격리 Electron에서4상품 이름·옵션·개별수량과 선택패널,700/1040/1440 라이트·다크 넘침 확인. 오른쪽 모니터·가상자료만 사용. 운영 주문/송장 실행 없음.

앱 버전0.147.2, 웹1.64.0 변경없음. 앱 전체451/451 통과. 설치 ASAR112개 파일 일치 및 설치본 묶음 UI smoke PASS. 최종 distribution-20260914-234719-347을 moaon-stable에 서명 배포. 바탕화면/시작메뉴/작업표시줄/current.json을0.147.2 경로로 갱신.

공개 latest.yml은200·0.147.2 일치. release.json 직접 요청은HTTP504이며 실제 업데이트AVAILABLE/CURRENT 검사는ERROR로 끝났다. 공개 다운로드/서명검증 성공을 주장하지 않는다. 로컬 서명 배포 및 설치본 UI 검증과 구분한다.
