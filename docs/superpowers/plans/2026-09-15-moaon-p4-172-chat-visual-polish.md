# P4-172 Gemini 대화창 디자인

모아온 연보라색, 기존 한국어 글꼴을 유지하며 대화 패널을 다듬음. 제목 옆 작은 별, 원형 닫기, 둥근 도구 버튼, 추천 질문 카드, 사용자 말풍선과 여백 있는 AI 본문을 적용. 첨부/모델/전송을 하나의 입력 카드로 묶음. 호버와 포커스 반응 및 답변 표시 중 커서 효과를 추가하고 reduced-motion을 준수. 패널 DOM 유지/깜빡임 회귀 방지. 신규 대화에서는 인사말부터 스크롤 시작.

데스크톱 UI만 변경. API/키/한도/저장/삭제 기능 유지. desktop 0.147.9. Electron UI 검증에서 파일/모델/기록/삭제, 밝은/어두운 테마, 700/1040/1440 폭 확인.

최종 패키지 117개 파일 일치, 패키지 Electron 회귀 PASS. 실제 설치본의 인사 화면, 추천 질문 3개, 입력 카드 및 상단 스크롤 확인.
