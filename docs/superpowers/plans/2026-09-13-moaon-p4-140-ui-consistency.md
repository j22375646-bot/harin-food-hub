# P4-140 · 전체 페이지 UI 일관성 · 0.127.0

## 범위와 확인한 문제

- 오늘, 주문·배송, 운영·정산, 분석, 키워드, 캘린더, 재고, 상품, 고객·CS, 설정 10개 페이지.
- 밝은/다크 × 1040/1440px의 40개 화면과 설정 추가 6개 탭 × 4조건, 총 64개 상태를 격리 Electron으로 캡처했다.
- 재고 탭의 고정 파란색과 다크모드 비선택 탭의 낮은 대비, API 카드의 별도 색상, 11~12px 운영 안내와 주문 필터, CS 요약값의 음절 단위 줄바꿈, 상품 빈 상태의 중복 테두리, 페이지별 조회 버튼 차이를 확인했다.

## 적용

- `ui-polish.css`: 기존 보라/민트/중립색 토큰을 사용하고 선택/주요 동작/조회 버튼을 구분. 주요 버튼 전경색은 밝은·다크 테마에 맞게 지정한다.
- 제목 자간 -0.035em, 섹션 제목 -0.025em, 입력/버튼 -0.01em. 작은 운영 안내와 필터는 14px. 숫자 데이터는 tabular-nums.
- 조회 컨트롤 최소 44px, 닫기 버튼 44px. CS·상품 요약은 라벨/값을 세로 정렬하고 긴 한국어를 단어 단위로 표시한다.
- 상품·키워드 필터 패널의 여백과 하단 정렬, 재고 버튼 줄바꿈, API 카드 색상을 공통 테마에 맞췄다.
- 버튼/입력 반응 160ms, 설정 탭·입력창 등장 180ms. 모션 감소 설정에서는 효과를 끈다. 계산·API·재고/주문 쓰기·알림·로그인 권한은 변경하지 않았다.
