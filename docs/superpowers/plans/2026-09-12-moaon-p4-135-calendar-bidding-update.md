# P4-135 · 일정 삭제, 쇼핑 입찰, 공통 UI · 0.122.0

## 반영 범위

- 아빠 로그인 표시와 운영 프로필 직책을 사장으로 변경했다. 사용자 식별자, 비밀번호, 동등 권한은 유지했다.
- 일정 상세에 삭제 버튼과 확인 화면을 추가했다. 기존 ARCHIVE_ENTRY 서버 동작을 사용하며 삭제 후 월간 자료를 다시 조회한다. 이벤트 삭제는 사은품 조건에도 영향을 준다고 안내한다.
- 업무 상세에 삭제와 취소/확인을 추가했다. DB에는 삭제 시각·수행자와 DELETE 이벤트를 보존하며 공동 목록과 배정 알림 조회에서 제외한다. revision 충돌과 중복 요청을 처리한다. 확인 도중 정기 새로고침이 확인 화면을 닫지 않는다.
- 사이드바 접기 버튼을 표시하고 접힌 상태를 저장한다. 본문 폭이 늘어나며 아이콘 설명을 유지한다.
- 캠페인 표 제목/행의 열 비율·박스 계산·숫자 정렬을 통일하고 좁은 폭에서는 가로 스크롤을 사용한다. 프로필의 알림 테스트 버튼에 공통 디자인을 적용했다.
- 키워드 화면에 운영 중인 쇼핑광고 그룹 선택과 기본 입찰가 조회 → 변경 미리보기 → 확인 → 반영 결과 재조회 흐름을 추가했다. 개별 입찰가가 지정된 상품에는 적용되지 않는다. 기존 등록 키워드 감액 기능은 유지한다.

## 입찰 검증과 제한

공식 Naver Search Ads 스펙의 adgroups PUT fields=bidAmt를 사용한다. 그룹/캠페인 활성 상태와 연결 관계, 자동입찰 여부, 현재 금액, 70~100000원 및 10원 단위를 확인한다. 5분 미리보기 만료, 사용자별 요청 소유권, 그룹별 중복 실행 잠금, 서버 변경 허용 스위치를 적용한다. 통신 결과가 불명확하면 UNKNOWN으로 보존하고 무작정 재전송하지 않는다.

실제 광고 입찰가는 테스트 중 변경하지 않았다. 서버 NAVER_SEARCH_AD_WRITE_ENABLED 설정을 그대로 따르며 현재 값은 비밀 환경변수라 이번 점검에서 확인하지 못했다. 실제 사용 시 조회 응답에 따라 변경 가능 여부를 표시한다. 쇼핑 개별 상품 입찰 및 실제 검색어별 입찰은 이번 구현 범위가 아니다.
