# P5-16 / 0.15.1 실제 설치·로그인 진입 인수

## 완료한 작업

현재 개발 PC에서 실행 중인 모아온이 없음을 확인하고, 기존 검증된 설치파일의 SHA256을 대조한 뒤 0.13.1에서 0.15.1로 업데이트했다. 새 기능/새 버전을 추가한 단계가 아니라 준비된 EXE를 실제 사용 환경에 적용·검증한 단계다. 레지스트리 설치 버전과 실제 실행 중인 Electron 호스트 버전 모두 0.15.1이다.

설치 전후 기존 사용자 프로필 파일 133개의 정렬된 상대 경로와 파일 해시를 비교한 집계 해시가 동일했다. 설정·로그인 자료를 삭제하거나 새 프로필로 바꾸지 않았다. 비밀번호·쿠키 내용은 출력하지 않았다.

## 실제 설치 EXE 검증

개발용 Electron 대체 실행이 아니라 설치 경로의 `MoaonPreview.exe`를 기존 사용자 프로필로 실행했다. 검증 스크립트는 이전 0.13.1 메인 우선 가정에서 최신 로그인 우선 흐름으로 갱신했다. 새로운 앱 동작을 추가하지 않았다.

| 항목 | 첫 실행 | 두 번째 실행 |
|---|---:|---:|
| 실행 버전 | 0.15.1 | 0.15.1 |
| 기존 테마 | dark | dark |
| 로컬 화면 준비 | 325ms | 296ms |
| 시작부터 로그인 상태 안내까지 | 892ms | 569ms |
| 결과 | 로그인 필요 | 로그인 필요 |

로그인 필요 상태에서 업무 화면은 숨겨졌고 키보드 접근도 차단되었다. 측정값은 이번 PC의 두 차례 실행 표본이지 모든 PC·네트워크의 보장 속도는 아니다. 첫 화면만 확인한 사전 시험도 두 차례 통과했다.

현재 저장된 세션으로는 재로그인이 필요하다는 응답을 받았다. 이 결과만으로 만료 원인을 단정하지 않는다. 설치 전후 파일 보존은 확인했지만 실제 비밀번호 로그인 성공과 로그인 유지는 아직 검증하지 않았다. 비밀번호를 입력하거나 인증을 우회하지 않았다. 시작 시 저장 주문 읽기 경로는 호출될 수 있으며 수집·송장 발급·인쇄 작업은 실행하지 않았다.

## 남은 인수와 다음 순서

1. 사용자가 설치된 모아온에서 직접 로그인한다.
2. 로그인 성공 후 종료·재실행해 서버가 유효한 세션을 인정하고 업무 화면으로 복귀하는지 확인한다.
3. 다른 출고 PC에 같은 설치본을 설치하고 프린터 목록·용지·바코드를 확인한다. 이번 결과는 출고 PC 설치·물리 출력 결과가 아니다.
4. 다사업장 계정·자료 격리·플랫폼 연결센터의 기존 개발 순서는 유지한다.

설치파일은 P5-15와 동일하며 미서명이다. 추가 유료 서비스·리소스 생성 없음.
