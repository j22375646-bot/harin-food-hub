# P4-34 — 정렬·상세 패널 동작 재수정

## 원인
이전 검증은 열 시작 좌표와 닫힌 상태만 확인했다. 실제 뱃지 중심과 제목 중심은 달랐다(가상자료 기준 약8px/14px). X 처리에서 내용이 즉시 교체되어 슬라이드 도중 다른 내용이 나타났고 패널 폭도 줄어들며 내용이 재배치됐다.

## 수정
- 채널/상태 제목과 뱃지를 가운데 정렬. 금액은 우측 정렬. 헤더와 행 테두리·모바일 패딩 일치.
- 440ms 슬라이드 및 목록 확장, 고정 내부 폭으로 내용 재배치 방지.
- X/Escape는 내용 유지 후 화면 밖으로 이동. 즉시 inert/aria-hidden 적용.
- 로그아웃·채널/자료 변경 시 숨긴 내용도 즉시 제거하는 보안 동작 유지.
- 공통 스크롤바 숨김, reduced-motion, 체크 선택, 채널 조회, 송장 등록 유지.
- frontend-design 원칙을 사용해 기존 앱의 색·폰트·레이아웃을 바꾸지 않고 정렬 기준과 전환 동작만 수정했다.

## 검증
- 새 중심선 검사 RED 확인 후 GREEN.
- 애니메이션 중간 프레임에서 목록 폭 변화, 패널 내용/폭 유지 검사 통과.
- 패널·1040/1440 라이트/다크 배치·다중 선택·등록 격리 시험 통과.
- 단위 시험136/136 및 패키지 패널/배치 시험 통과. 코드 재검토 승인.
- 0.22.1 설치 완료(종료0). 실제 설치 EXE의 실제 주문 화면에서 채널/상태 중심 오차0px/0px, 목록 폭 변화22개 중간 프레임, 상세 내용 유지/화면 밖 이동/inert/스크롤바 없음 확인.
- 실제 로그인 유지로 진입했으며 운영 송장 발급·전송 없음.
