# P4-61F 서버 자격증명 암호화 기반

## 구현 범위

서버 전용 AES-256-GCM 암호화 모듈을 추가했다. 매 저장마다 12바이트 난수를 생성하고 사업장 UUID·플랫폼·설정 revision·암호화 key ID·형식 version을 인증된 부가 데이터에 묶는다. 암호문을 다른 사업장이나 플랫폼으로 옮겨 사용할 수 없다.

- 입력 필드·자료 크기·키 길이·base64 형식을 검증한다. 실패는 비밀값을 포함하지 않는 고정 오류로 반환한다.
- 활성 키로 새 자료를 암호화하고, 제한된 이전 키 목록으로 기존 자료를 복호화한다.
- 암호화 키나 API 키를 환경에서 가져오거나 실제로 생성·저장하지 않았다. 서버 배포 구성에서 별도 공급해야 한다.

## 검증

정식 npm test 전체 2,679/2,679 통과.

4개 테스트를 먼저 실패시킨 뒤 구현했다. 같은 입력의 비결정적 암호화, 정확한 범위에서 복호화, 사업장·플랫폼·revision 교체 차단, 암호문·nonce·tag 변조 차단, 이전 키 읽기와 새 키 쓰기, 잘못된 키·입력 크기 차단을 검증한다. 실제 API 키 대신 시험값 사용.

## 반드시 남아 있는 경계

이 모듈은 암호화 도구이지 권한 검사나 DB 저장소가 아니다. 호출 전에 서버 소유자 권한을 확인하고, 저장 트랜잭션에서 다시 확인해야 한다. revision은 DB의 신뢰된 최신 버전에서 가져와야 하며 이 모듈 단독으로 이전 자료 재사용을 막지는 않는다.

DB 테이블·저장 API·앱 연결·고정 IP 플랫폼 인증·운영 배포는 아직 미구현/미검증이다. 이번 변경으로 앱에서 새 사업장을 실제 연결할 수 있게 된 것은 아니다. 앱 설치 버전 0.51.2 및 하린식품 운영 키는 그대로 유지한다.
