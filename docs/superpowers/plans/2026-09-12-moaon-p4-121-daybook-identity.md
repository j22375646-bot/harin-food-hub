# P4-121 · 시안 원본 로고·픽토그램·공통 화면 (0.107.0)

## 원본에 맞춘 요소

P4-120은 시안의 화면 구조 일부만 반영하고 기존 브랜드·메뉴 요소를 남겼다. 사용자 지적에 따라 로컬 승인 시안 Daybook v1의 원본 SVG 경로와 시각 요소를 실제 앱에 옮겼다. 원본의 운영 스냅샷은 복사하거나 공개 저장소에 추가하지 않았다.

- 두 아치로 구성된 M 로고와 ‘모아온 / 사업의 하루를 모으다’ 워드마크. 왼쪽 메뉴·로그인 브랜드·로그인 심볼을 같은 로고로 통일했다.
- 워크스페이스/상품 관리 메뉴 그룹, 사업장 아바타와 카드, 아이콘·선택 점·주문 건수, 하단 설정/연결 상태.
- 원본의 집·상자·정산·차트·달력·잎·상담·설정 픽토그램. 오늘 상품에는 잎/병/상자 삽화를 사용하고 주문·배송 본문의 실제 상품 사진은 유지한다.
- 상단 경로/검색/아바타, 오늘 날짜와 제목 마침표, 자료 기준 버튼, 배송 확인 수치·화살표, 월력 아이콘, 재고 상자 일러스트와 자료 기준 노트.
- 오늘 주문 기본4건/펼치기6건, 실제 목록·상세 이동, 네 가지 운영 상태 탭. 실제 앱은 전체 채널을 다루므로 시안의 네이버 전용 고정 숫자/3개 단계 대신 실제 채널과 4개 단계를 표시한다.
- 오늘 목록에서 이동할 때 이전 주문 페이지의 채널/검색 필터를 초기화해 클릭한 상품이 숨겨지지 않도록 했다.

## 조회 흐름 그래프의 의미

시안의 고정 7일 접수 수치를 운영 통계로 복제하지 않았다. 기존 네 단계 조회 응답의 현재 페이지에서 주문 ID를 중복 제거하고 한국 날짜별로 집계한다. 추가 서버 조회나 DB 쓰기는 없다. 전체 저장 주문이 아니라 **이번에 조회한 작업실 주문의 최근 7일 분포**이며, 페이지가 더 있거나 부분 응답이면 ‘일부 조회분 · 전체 주문 통계가 아닙니다’로 표시한다. 날짜나 단계 응답이 없으면 0건 차트를 만들지 않는다. 상품 수량·네이버 결제 주문번호 개수·전 기간 접수 통계와 구분한다. 기존 자금 판단은 그래프 아래에 유지했다.

## Windows 로고

`desktop/ui/brand/`에 원본 경로의 SVG와 PNG, 16/24/32/48/64/128/256px ICO를 생성했다. 실행파일·설치/제거 아이콘·창 아이콘에 연결했다. Windows 실행파일에서 아이콘을 직접 추출해 M 마크를 확인했다.

기존 Ed25519 검증은 유지한다. electron-builder의 리소스 편집은 켜고 `signExecutable: false`로 유료 Authenticode 서명만 건너뛴다. 설치파일과 업데이트 manifest의 기존 Ed25519 서명은 계속 검증한다.
