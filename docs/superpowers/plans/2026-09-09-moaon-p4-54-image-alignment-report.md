# P4-54 / 0.38.6 상품 이미지·결제금액 정렬

## 수정과 확인

- 목록 44×52/38×48, 상세 64×78이던 이미지 칸을 각각 44×44/38×38/64×64로 수정했다. 원본 상품은 contain으로 비율을 보존한다.
- 결제금액과 제목을 모두 중앙 정렬했다. 기존 검사는 칸의 위치만 확인했으나 이번에는 실제 텍스트 Range 중앙선을 측정한다. 수정 전 9.91px 어긋남을 재현했고 수정 후 1px 미만을 검증했다.
- Cafe24 상품 86의 이미지가 DB에는 harinfood.com/web/product/small 경로로 존재하지만 앱 허용 목록에 없어 누락됨을 확인했다. 해당 호스트의 상품 이미지 파일 경로만 허용하고 CSP도 일치시켰다. 임의 호스트·관리자 경로·스크립트 요청은 허용하지 않는다.
- 앱 단위 테스트 231개 통과. 실제 공식몰 상품 이미지가 목록·상세에서 디코딩됨을 확인했다. 1040/1440px, 밝음/어두움에서 정사각형·텍스트 중앙선 검사 통과. UI의 주문 데이터는 합성이고 이미지 파일만 실제 공식몰에서 읽었다.

## 배포 상태

최초 패키징은 ENOSPC로 실패했으나 이후 여유 공간 약9.3GB를 확인하고 재빌드했다. 0.38.6 최종 설치 종료코드0, 패키지와 설치된 app.asar의 SHA256 일치를 확인했다. 파일을 삭제하지 않았고 로그인 프로필을 유지했다. 자동 이력 조회·배송 상태 수정 및 검증 한계는 [통합 보고](./2026-09-09-moaon-p4-54-orders-automation-report.md)를 따른다.
