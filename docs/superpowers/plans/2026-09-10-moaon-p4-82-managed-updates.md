# P4-82 — 고정 바로가기·관리형 배포·업데이트 UI / 0.70.0

## 사용자 요청과 확인
- 바탕화면 Moaon Preview.lnk는 C드라이브의0.52.1을 가리켰고 실행 중인 앱은 D 개발빌드0.69.0이었다.
- 사용자 요청: 같은 바로가기에서 버전 업그레이드, 구버전 정리, 반복 설치 제거, UI 개선.
- 사용자는 외부 배포 주소와 Windows 코드 서명이 아직 없다고 확인했다. 외부 자동 업데이트 활성화를 완료했다고 주장하지 않는다.

## 구현·실제 적용
- publish-local.ps1: 소스 대조 → 관리형 버전 폴더 복사 → 재대조 → 고정 바로가기 갱신. 역행/같은 버전 덮어쓰기/링크 패키지 거부. 최신+직전+실행 중 버전을 보존하고 소유 표식이 있는 과거 관리형 릴리스만 정리한다.
- 바탕화면 모아온.lnk를 D:/GPT/Apps/Moaon/releases/0.70.0/MoaonPreview.exe --display-right로 연결했다. 이전 Moaon Preview.lnk는 제거했으며 개발 폴더 바로가기는 보존했다.
- 실행 중0.69.0은 강제 종료하지 않았다. 종료 후 같은 모아온 바로가기로 신버전을 연다. C의0.52.1 설치 폴더/사용자 데이터는 미삭제다.
- 앱 시작10초 후+6시간마다 확인/다운로드를 예약한다. 일반 종료 시 설치하지 않으며 업무/자식 창 재시작 차단을 유지한다.
- 업데이트 UI에 상태 배지,3단계 순서,명확한 배포 연결 대기,자동 확인 정책,44px 버튼/14px 안내와 좁은 화면 재배치를 추가했다.
