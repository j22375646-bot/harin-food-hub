# P4-155 · 주문 패널·선택 상태·캘린더 세부 수정

## 원인과 변경

- 주문 패널의 바깥 padding 때문에 스크롤된 본문이 sticky 제목 위 여백으로 노출됐다. 패널 바깥 여백을 없애고 제목/본문 각각 내부 여백을 적용하여 제목을 패널 상단에 밀착했다. 기존 메뉴·본문·출고 동작 유지.
- 선택 행의 하단 border가 공통 주문 행 스타일에 덮어써졌다. 전체 테두리와 안쪽 보강선, 내부 포커스 테두리로 잘림을 방지한다.
- 선택 행과 출고 예정 뱃지가 같은 보라 배경을 사용했다. 선택 시 뱃지에 surface 배경과 보라 테두리를 적용한다.
- 상태 데이터로 결제/준비·대기/배송/완료/취소·확인필요의 색을 구분한다. 배송 대기는 REGISTERED 상태로 표기 색을 결정한다. 밝음·다크 공통 토큰 사용.
- 이벤트 주간 띠지 CSS가 날짜 배경을 transparent로 덮어썼다. 업무 캘린더와 같은 일요일/공휴일 연한 장미색, 토요일 연한 보라색을 다시 적용한다. 선택 테두리와 휴일 이름 유지.
- 왼쪽 주문·배송 수는 ACTIVE + REGISTER만 합산한다. IN_TRANSIT/COMPLETED는 제외. 필요한 두 범위 중 미확인 값이 있으면 — 유지하며 배송 중 조회 실패는 이 합계에 영향을 주지 않는다.
