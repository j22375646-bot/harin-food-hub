# P4-132 · 담당자 선택값과 Windows 알림 확인

## 원인과 수정

- Chromium 기본 선택값은 option 안의 아바타 첫 글자와 이름 텍스트를 함께 복사하여 이름이 중복됐다. `selectedcontent`를 사용하고 선택된 값의 문자 아바타만 숨긴다. 메뉴 안의 아바타와 사진 아바타는 유지한다.
- 사용자 확인: 알림이 없던 테스트는 자신에게 직접 배정한 업무였다. 기존 서버는 본인 배정을 알림 이벤트 조회에서 제외한다. 다른 사람이 나에게 배정하면 받는 사람으로 로그인한 앱에 알리는 원래 동작을 유지했다.
- 프로필에 Windows 알림 테스트 버튼과 대상 설명을 추가했다. 신뢰된 로컬 렌더러, 로그인한 프로필, 15초 호출 제한을 확인하며 임의 알림 본문을 IPC로 받지 않는다.
- 알림 표시 전에 수신 완료를 기록하던 문제를 수정했다. Windows `show` 이벤트 후 기록하며 실패는 세션 내 무한 반복 없이 다음 실행에서 다시 시도할 수 있다. 묶음의 마지막 업무가 이미 완료되어도 다른 유효한 배정이 누락되지 않는다.

## 검증

- 운영 배정 이력을 읽기 전용으로 확인. 테스트 배정은 사용자가 직접 수행했으며 자동으로 추가 업무를 생성하지 않았다.
- 이 PC의 시작 메뉴 AppUserModelID는 `com.moaon.preview`로 일치했다. 독립 native 시험 및 실제 프로필 테스트 버튼에서 `Notification`의 `show` 성공 응답 확인. 다른 PC에서 실제 소리/배너를 보았다는 의미는 아니다.
- 기존 코드 374개 PASS와 추가 실패 후 재시도/묶음 누락 회귀 PASS. 원본 및 패키지 업무 UI 흐름에서 선택값 문자 아바타 숨김, 프로필 native 테스트, 사진 등록/삭제, 체크리스트 회귀 확인.
- 0.117.0 설치 패키지, 공개키 서명 릴리스, 로컬 바로가기 갱신. 서버/DB 동작 변경 없음.
- 로그: `D:\GPT\tmp\p4132-*`. 알림에는 본인이 자신에게 배정한 업무가 포함되지 않고 앱이 실행 중이어야 한다.
