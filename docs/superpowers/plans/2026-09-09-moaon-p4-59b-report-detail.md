# P4-59B 보고서 판단 근거 — 0.46.0

## 개발 내용

분석 페이지의 최근 보고서가 버튼으로 바뀌었다. 선택하면 앱 안에서 결정·위험·캠페인·키워드·행동·근거를 볼 수 있다. 웹 페이지를 삽입하지 않으며 기존 네이버 보고서 판정식을 재사용한다.

- 현재 조회한 최대 20개 보고서에 제한된 상세 텍스트를 포함한다. 클릭마다 추가 API/DB 요청을 보내지 않는다.
- 저장된 owner_brief를 그대로 신뢰하지 않고 현재 판정식으로 다시 읽는다. 저장 보고서를 변경하지 않는다.
- 섹션별 900바이트, 항목별 500 UTF-16 길이, 섹션 6개/항목 최대 8개 제한. 긴 내용은 일부임을 화면에 알린다.
- 정보가 없으면 확인 필요로 표시하며 숫자 0을 누락과 구분한다. 광고 자동 변경은 하지 않는다.
- 우측 상세 닫기/Escape, 원래 보고서로 초점 복귀, 좌측 목록의 부드러운 확장.
- 패널 닫힘 후 큰 수직 공백이 남는 오류 수정. 내부 스크롤은 유지하고 스크롤바는 숨겼다.
- 새로 조회 실패·로그아웃 시 이전 상세 삭제. 구버전 서버에 상세가 없으면 새로 조회 안내.

## 검증

- 서버 전체 2,667개 통과, 앱 265개 통과.
- 실제 코드 기반 서버 상세 테스트 15개: 비공개 필드 제외, 글자·바이트 제한, 이모지, 20개 응답 크기, 기존 권한·재무·비교 제한.
- 격리 앱 UI: 키보드 선택/닫기/초점, 여러 프레임의 목록 확장, 닫힌 패널 공백 제거, HTML 문자 안전 출력, 1040/1440 폭, 라이트·다크, 조회 실패·로그아웃 비움.
- 검증용 응답을 사용한 패키지 시험과 실제 운영 계정 조회는 별개다. 실제 보고서와 웹 숫자 대조는 미완료다.
- 서브 에이전트가 서버 구현과 별도 리뷰를 수행했다. 리뷰에서 발견한 이모지 길이 불일치 및 닫힌 패널 높이 문제를 회귀 테스트로 재현하고 수정했다.

## 범위와 남은 일

이번 화면은 제한된 판단 근거 요약이다. 전체 캠페인·키워드 목록, 별도 7일 확인 행동표, 보고서 생성·광고 변경을 이식 완료로 표시하지 않는다. 자료가 잘리면 일부 항목만 표시된다. 우체국·플랫폼 신규 등록 실검증과 정산 실금액 대조도 별도 미완료 상태다.
