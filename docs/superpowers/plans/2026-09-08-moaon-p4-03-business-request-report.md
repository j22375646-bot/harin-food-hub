# P4-03 사업장 목록 HTTP 요청 경로

## 구현

`GET /api/moaon/businesses`와 서버 전용 요청 처리기를 추가했다. 쿠키에서만 기존 세션 형식의 자격값을 읽으며 URL의 사용자 ID 등 쿼리 입력은 거부한다. 중복·누락·과대 쿠키, 교차 사이트 요청을 차단한다. 반환 목록은 최소 필드로 다시 검사하고 비밀정보와 추가 필드를 제거한다. 성공·오류 모두 no-store이며 CORS 공개 헤더를 넣지 않는다.

정상 빈 목록은 200, 인증 필요는 401, 설정 미완료는 503 SETUP_REQUIRED로 구분한다. 조회 제한시간은 기본 10초이고 시간 초과는 504다. 내부 오류 메시지는 노출하지 않는다. 제한시간은 HTTP 응답 대기만 종료하며, 취소를 지원하지 않는 하위 DB 작업이 실제로 중단되었다는 보장은 하지 않는다. 자동 재시도는 없다.

## 중요한 적용 한계

현재 route는 의도적으로 저장소를 주입하지 않은 상태다. 따라서 쿠키가 없으면 401, 형식에 맞는 쿠키가 있어도 503 SETUP_REQUIRED이며 사업장 정보를 반환하지 않는다. 운영 인증 adapter와 제한 DB 연결을 조합한 서버 구성이 아직 필요하다. 이 경로의 추가는 인증 연결 완료나 선택 화면 완료를 의미하지 않는다. 기존 하린식품 OWNER를 다른 사업장 권한으로 사용하지 않는다.

## 검증

- 신규 요청 시험의 미구현 실패 확인 후 구현.
- 요청 처리·제어 저장소·인증 adapter·전환 보호 관련 86개 시험 통과.
- Next.js 프로덕션 빌드 성공 및 route 등록 확인. 마지막 오류 코드 화이트리스트 보강은 동일 요청 시험으로 재검증했다.
- route GET 함수를 직접 불러 무쿠키 401, 형식 시험 쿠키 503 SETUP_REQUIRED와 no-store 확인. 실제 운영 서버 HTTP 인증 검증이 아닌 로컬 route 호출이다.
- 정상/빈 목록, 형식 오류, 중복 식별자, 권한 값 오류, 지연, 내부 오류와 쿠키 예외 검증.

새 EXE 생성·설치 변경·운영 DB 수정·유료 자원 생성 없음. 앱은 0.15.1 유지. 운영 배포 성공은 별도 확인하지 않았다.
