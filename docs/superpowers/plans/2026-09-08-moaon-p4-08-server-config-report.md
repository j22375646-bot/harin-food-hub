# P4-08 서버 전용 DB 설정 입력 경로

## 구현

lib/tenancy/control-database-config.js에 전용 환경 설정 reader와 제한 PostgreSQL adapter 생성 함수를 추가했다. host/port/name/password 네 필드를 명시적으로 받으며 역할은 moaon_control_app, TLS 인증서 검증은 true로 고정한다. 풀 최대 연결 2개, 연결 대기 제한 5초. 직접 연결 기준이며 pooler의 프로젝트 접미사 사용자 이름은 이번 구현 범위가 아니다.

전체 미설정은 null, 부분 입력/잘못된 입력은 값이 없는 고정 오류로 구분한다. DATABASE_URL, PGUSER, PGOPTIONS, 서비스 키로 대체하지 않는다. 브라우저 실행을 거부하고 생성 시 네트워크 연결을 열지 않는다. 반환 설정은 서버 내부 비밀 객체이므로 JSON 응답/로그로 직렬화해서는 안 된다.

.env.example에 빈 설정 이름만 추가했다. 실제 비밀번호 생성, 운영 환경 변수 등록, LOGIN 활성화, API route 연결은 하지 않았다. 이 구현 자체가 운영 접속 성공을 의미하지 않는다.

## 검증

새 테스트 4개: 미설정 대체 연결 금지, 부분/오류 설정 비밀값 비노출, 고정 역할·TLS 및 환경 옵션 격리, 브라우저 차단. 구현 파일 부재로 최초 실패를 확인한 후 구현했다. 관련 5개 테스트 파일 총 79개 통과, 실패 0개.

이번 변경은 아직 route가 사용하지 않는 서버 모듈이다. Next.js UI/route 변경·빌드·웹 배포·EXE 배포는 수행하지 않았다. 로컬 시험은 실제 운영 DB 연결 검증이 아니다.

## 다음 작업

전용 접속 자격 증명을 서버 비밀 설정에 안전하게 제공하고 직접 연결의 DNS/네트워크/TLS/권한 검사를 인수한다. 이후 사업장 소유권 대조와 목록 서비스 route 연결을 진행한다. 자격 증명은 채팅이나 EXE에 저장하지 않는다. 현재 운영 역할은 이전 NOLOGIN 상태를 변경하지 않았으며 사업장 API는 미설정 상태를 유지한다.

기존 주문·정산·로그인 데이터 및 유료 인프라 변경 없음.
