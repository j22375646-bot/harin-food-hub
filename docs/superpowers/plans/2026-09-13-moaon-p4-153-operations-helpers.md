# P4-153 · 고객 응대, 반복 업무, 행사 재고

사용자 승인: 고객·CS, 업무 캘린더, 재고 추천 기능 적용.

- CS: 플랫폼별 팀 목표 응답시간(기본 24시간), 임박/초과 정렬·필터, 공용 답변 템플릿 편집/저장과 접수별 문구 복사. 플랫폼 직접 전송은 기존 연결이 없어 판매자센터에서 확인·발송한다.
- 업무: 매일/매주/매월 2~52회 일괄 등록. 월말은 해당 월 마지막 날로 조정. 담당자·체크리스트 복제, 회차별 완료, 이번만/이후 미완료 회차 수정·삭제. 서버 트랜잭션·중복 요청 및 동시 수정 방어.
- 재고: 같은 상품·단위의 유통기한별 출고 순서와 행사별 확보 기록. 기한 경과/누락은 출고 추천 제외, 행사 확보는 실수량 차감과 구분. 초과 확보 차단, 재고 감소 후 부족 상태 표시, 행사 종료·삭제 시 해제된 가용 수량 계산.
- 기존 공통 토큰·카드·읽기 크기 사용. 가시 격리 Electron으로 밝음/다크 및 폭별 확인. 운영 고객에게 메시지를 전송하거나 실제 출고하지 않는다.

검증·배포 기록은 작업 후 갱신.
