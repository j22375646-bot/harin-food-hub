# P4-60E / 0.49.2 — 상단 상태 안내 정리

기존 '조회 · 하린식품 주문 조회·확인 후 발급'은 로딩 표시가 아니라 상시 안내였다.

- 정상 연결은 안내 텍스트와 배지를 숨긴다. 공간은 유지해 검색/사업장 위치가 상태마다 흔들리지 않는다.
- 일부 자료 미확인은 '일부 자료 확인 필요', 처리 중은 '처리 중…', 연결 오류는 설정 확인 안내를 표시한다.
- 샘플 모드는 실제 자료와 구별하기 위해 표시를 유지한다.
- UI 스킬의 불필요한 상시 장식 제거 원칙을 적용했다. 송장 발급·등록 로직과 데이터 조회 경로는 변경하지 않았다.

검증: 정상 연결 상시 안내가 남는 실패를 먼저 확인하고 수정했다. 앱271개 통과. 운영 API 성공이나 실제 송장 시험을 의미하지 않는다.

빌드 중 ENOSPC로 중단되어 dist의 0.1~0.20 과거 설치 파일과 blockmap 58개(3.02GiB)를 삭제했다. 이전 소스로 재빌드할 수 있으나 바이너리 자체는 삭제되었다. 최근 설치본/로그인 프로필/운영 자료는 보존했다.

기존 캘린더 서버 배포·실데이터 대조는 아직 미완료이며 다음 기능 개발 항목으로 유지한다.

패키지 상태 전환/주문 레이아웃 시험 통과(임시 프로필·시험 응답). 0.49.2 설치 종료 코드 0, 설치 app.asar와 빌드 SHA-256 일치 확인.
