# P5-05 — 모아온 0.5.0 PC 작업 공간

## 무엇이 달라졌나요?

사용자가 요청한 설치형 앱 UI 개선을 이번 개발 범위에 포함했다. 웹페이지처럼 큰 제목과 여백을 사용하는 대신 창 안에서 목록과 상세를 함께 보는 업무형 구성으로 조정했다. 기존 청색·남색 계열, 읽기 쉬운 한글, 라이트·다크, 포커스 표시, 동작 줄이기 설정은 유지한다. Windows 기본 제목줄/창 이동/최대화도 유지한다.

- 왼쪽 메뉴 접기/펼치기: 접으면 아이콘 메뉴로 바뀌어 작업 공간이 넓어진다. 접근성 메뉴 이름은 유지한다. 접기 상태는 종료 시 초기화된다.
- 상단 검색과 테마 전환: 설정 화면에 들어가지 않고도 테마를 바꾼다. 검색은 현재 페이지 주문에만 적용된다.
- Alt+1 오늘, Alt+2 주문·배송, Alt+3 설정. Ctrl+K 검색, Esc 상세 닫기도 유지한다.
- 주문 목록과 오른쪽 상세를 독립적으로 스크롤한다. 목록을 내려도 상태 선택과 페이지 이동은 남는다.
- 오른쪽 상세의 이전/다음 주문: 현재 검색 결과와 현재 페이지 안에서 이동한다. 첫 주문/마지막 주문은 해당 버튼을 비활성화한다. 페이지를 넘어 자동 조회하지 않는다.
- 검색으로 상세 선택 주문이 제외되면 상세를 닫는다. 선택 주문이 남아 있으면 입력 포커스를 유지하면서 이전/다음 범위를 갱신한다.

## 기능과 데이터 경계

이번 단계는 UI와 상세 탐색 강화이며 새 주문 데이터 필드를 추가한 단계는 아니다. 수취인 개인정보, 송장 발급, 인쇄, 주문 상태 변경, 새 사업장 가입/API 키 입력은 제공하지 않는다. 운영 웹사이트/서버/API/인증/DB는 변경하지 않았다. 기존 저장 주문 조회와 샘플/실제 구분, 금액 확인 필요 표시는 유지한다.

별도 유료 자원이나 클라우드 테스트 브랜치를 만들지 않았다. 공개 배포/자동 업데이트는 없으며 개인용 미서명 Windows 설치본이다. 설치 업데이트로 앱을 정상 종료했으므로 다시 로그인해야 한다.

## 검증

- 데스크톱 단위 테스트 34/34 통과.
- 변경하지 않은 기존 허브 테스트 2,541/2,541 통과.
- workspace 검사: 1040×720 / 1440×900 / 1920×1080 창, 라이트·다크 6조합에서 가로 넘침/목록과 상세 겹침/하단 상태줄 침범 없음. 키보드 이동, 접힌 메뉴 접근, 검색 포커스, 상세 이동, 동작 줄이기 검증.
- 상태 조회 검사: 20행 목록을 마지막까지 내린 후 상세 선택 가능, 페이지 이동 버튼 화면 안 유지, 1건 검색 결과에서 양쪽 상세 이동 비활성화.
- 검토에서 발견한 검색 후 오래된 상세 이동 대상 문제는 실패 테스트로 재현한 뒤 수정했다. 검색 축소/해제 중 상세 이동 범위와 입력 포커스 회귀 검증 통과. 제한 재검토에서 추가 지적 없음.
- 최종 설치된 EXE 직접 실행으로 workspace / status / basic smoke / login-submit 모두 통과. 기본 보안 설정 sandbox/contextIsolation/webSecurity 유지, Node 노출 없음.
- API 화면 검사는 합성 HTTP 응답을 사용했다. 실제 사용자 비밀번호를 입력하거나 채널 원본과 실제 주문 전체를 대조한 것은 아니다. 로그인 제출 검사는 비밀번호 없는 시험 폼을 네트워크 전송 전에 취소한다.
- 중간 패키지의 로그인 제출 검사는 1회 기대 요청 미관측으로 실패했다. 인증 코드를 변경하지 않았으며 소스 재실행, 최종 패키지, 설치 EXE에서는 통과했다. 단발 실패 원인은 확정하지 않았고 모든 시도가 성공했다고 보고하지 않는다.
- 최종 패키지 런타임 소스 8개 바이트 일치, 설치된 app.asar 해시 일치. Windows 등록 버전 0.5.0 확인.
