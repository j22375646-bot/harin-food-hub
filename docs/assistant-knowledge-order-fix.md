# 비서 지식 메뉴와 신규 주문 알림 수정

## 확인된 원인
- Telegram 지식 메뉴는 모아온의 승인 자료 CATALOG만 읽고, 기존 Hermes 회사 원본 검색 도구와 연결되어 있지 않았다.
- 카페24 세 번째 주문: 주문 시각 2026-09-19 19:12:30 KST, 알림기 첫 관측 20:02:29. 기존 08:00~20:00 발송 제한에 걸려 대기. 관측 사이에는 별도 수집 지연도 있어 실시간 수집 해결로 주장하지 않는다.
- 설정 화면은 이미지 발송 구현 이후에도 텍스트 알림이라고 안내했다.

## 변경
- Telegram 최신 자료/지식 목록이 원본 회사 문서와 모아온 자료를 함께 조회. 현재 원본을 매번 읽으며 별도 승인 대기 없음. 개인 메모리 제외와 원본 해시 검증 유지.
- 새 LEARN_SUBMIT은 기존 권한·충돌·용량 검사 후 한 트랜잭션으로 공유 지식 저장. AUTO_PUBLISH 이력. 기존 상태 enum은 호환성 때문에 APPROVED 사용. 과거 대기 자료 일괄 승인하지 않음.
- 신규 주문 개인 알림의 숨겨진 시간 제한 제거. 저장자료 확인 제한을 10분에서 2분으로 단축. 채널별 묶음과 중복 억제 유지. 판매채널 동기화 주기와는 별개.
- 신규 주문 카드 제목·조회 시각 표시. 설정 안내를 이미지/시간 제한 없음으로 수정.
- 공용 예약 및 다른 가족의 개인 신규 주문 수신 설정은 유지.

## 검증
- Python 메뉴 11개, 회사 지식 6개, 자동화 12개 통과. 봇 프로필 실행기 테스트 통과.
- 새 SQL 시험: 자동 저장·중복 제출·동시 수정 방어, 야간 2건 후 추가 1건만 별도 알림. 관련 개인 설정 SQL/발송 시험 통과.
- 실제 DB 패치 확인. 대기 주문은 2026-09-20 04:42:13 KST에 개인 전달 SENT 확인.
- 서버 1.87.0 운영 READY. 실제 Hermes 메뉴에서 회사 문서 3개+참고 스킬 3개 목록과 갱신 방식 확인.
- Electron 개인 설정 5역할·계정 분리·연결 인증·지연응답 격리 시험 통과. 격리 시험이며 실제 가족 계정 로그인 시험은 아님.
- 신규 주문 PNG 실제 렌더링·시각 확인.
