# 통합 관리 단톡방 기획안

목표: 가족이 한 방에서 비서 상태와 공용 설정을 관리한다. 개인 대화와 개인 알림은 각자의 DM에 유지한다.

## 권장 구성

- 방 이름: 모아온 비서 관리실
- 대표 응답 봇: 기존 @moaon_sup_bot 관리비서
- 업무·개인·학습·광고 봇은 서버에서 연결하고 단톡방에 모두 초대할 필요는 없다.
- 방에 고정한 관리 카드의 버튼으로 조작한다. 여러 봇이 서로 대화를 읽어 지시하는 구조를 사용하지 않는다.

## 메뉴

| 메뉴 | 동작 |
| --- | --- |
| 전체 상태 | 봇 실행, 마지막 확인, 실패·반영 대기 표시 |
| 알림 설정 | 봇별 공용 예약 시각·요일·수신처, 이미지 브리핑 설정 |
| 신규 주문 | 마지막 확인·발송 시각, 새 주문 수, 시간대 설정 |
| 공유 자료 | 엄마 Hermes 최신 자료 목록, 버전·원본 상태 확인 |
| 시험 발송 | 선택한 봇을 현재 관리방 또는 요청자 DM으로 시험 |
| 변경 이력 | 누가 어떤 값을 언제 변경했고 서버에 반영됐는지 확인 |
| 내 설정 | 개인 설정은 본인 봇 DM이나 모아온으로 이동 |

## 변경 흐름

버튼 선택 → 현재 설정 확인 → 값 선택 → 저장 → 서버 반영 상태 표시.
한 개의 상태 메시지를 갱신하며 중간 단계마다 새 메시지를 보내지 않는다.
설정 변경 이력과 충돌 검사를 유지한다. 비서 중단·수신처 변경처럼 영향이 큰 변경은 적용 대상을 보여주고 한 번 확인한다.

## 권한

그룹 참여만으로 설정 권한을 주지 않는다. Telegram 사용자 ID와 인증된 모아온 회원을 연결하고 변경마다 현재 권한을 확인한다. 방과 회사의 연결도 확인한다. 개인 설정을 다른 가족이 대신 변경하지 않는다. 토큰이나 비밀번호를 그룹에 표시하거나 입력받지 않는다.

## 알림

9시 공용 요약은 한 카드로 묶고 신규 주문만 별도 이미지 알림. 개인 DM과 그룹 중 어디로 받을지 선택하며 의도치 않은 이중 발송을 막는다. 상태 변동이 없는 점검 메시지는 보내지 않는다.

## 개발 순서

1. 그룹 연결 및 인증, 읽기 전용 통합 상태 카드
2. 기존 모아온 설정 API와 공용 설정 버튼 연결
3. 시험 발송, 변경 이력, 개인/공용 중복 방지
4. 가족별 권한·그룹 탈퇴·봇 제거·동시 수정 검증

현재는 기획안이며 그룹 생성·초대·설정 변경은 실행하지 않았다.
