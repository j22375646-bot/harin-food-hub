# 22단계 운영 전환·복구 기록

22단계는 사장님 단독 운영 흐름, 일괄 선택, 메뉴 재정리와 파스텔 UI를 적용한 화면·서버 코드 변경입니다. 22-8의 기존 주소 이동 처리도 데이터 자체를 수정하지 않습니다.

## 정상 운영 기준

- 고정 운영 주소: `https://harin-cafe24-sync.vercel.app/`
- 예전 경로와 `/?view=...` 즐겨찾기는 새 고유 주소로 한 번만 이동합니다.
- 네이버와 쿠팡 키워드·상품 선택·실행 대상은 서로 섞이지 않습니다.
- 페이지별 AI는 각 페이지 자료만 사용하며 서로 합치지 않습니다.
- 외부 플랫폼 쓰기는 확인창, 최신값 확인, 멱등키, 결과 재조회와 변경 기록을 유지합니다.

## 복구 경계

- 22-7 직전 정상 태그는 `v1.34.0`입니다.
- 22-8에는 Supabase 스키마 변경이 없으므로 데이터베이스 되돌리기 불필요합니다.
- 화면 또는 주소 이동 문제가 생기면 운영 데이터는 유지하고 애플리케이션만 직전 태그로 다시 배포합니다.

```powershell
git fetch --tags origin
git checkout v1.34.0
pnpm test
pnpm build
pnpm dlx vercel@58.9.4 --prod --yes
```

복구 배포 뒤 `X-Harin-Version`, 로그인, 메인, 주문, 상품, 키워드, 데이터수집과 예전 주소 이동을 확인합니다. 외부 쓰기 실패 기록은 삭제하지 않고 재시도 목록에 남깁니다.
