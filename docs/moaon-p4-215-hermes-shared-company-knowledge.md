# P4-215 · 어머니 Hermes의 최신 회사 지식 공유

## 사용자 사용법

어머니는 기존 Hermes에 회사 자료를 계속 올린다. 다음처럼 요청한다.

> 이 자료를 하린식품 공용 업무 지식으로 저장해 줘. 기존 회사 자료 폴더에 보관하고, 최신본 목록에 문서명·버전·승인 상태·파일 경로·SHA-256을 갱신해 줘. 개인 대화나 비밀번호는 공용 지식에 넣지 마.

기존 회사 스킬에도 최신본 목록 갱신 절차가 있다. 원본 파일과 최신본 목록의 저장이 끝나면 다음 비서 조회부터 반영된다. 단순 채팅 입력이나 임시 첨부만으로는 공유 저장이 완료된 것으로 보지 않는다.

업무·개인·학습·관리·광고 비서에 질문하면 `moaon_company_knowledge`로 현재 원본을 검색한다. 예: “최신 하린식품 운영 기준서와 콘텐츠 기준의 버전·승인 상태를 알려줘.”

## 연결 범위

- `/opt/data/company_documents` 아래 최신본 목록 `*LATEST.md`가 가리키는 현재 문서. DOCX/Markdown/TXT 지원.
- 여러 형식과 과거 이력이 있는 목록은 첫 번째 현재 버전 섹션만 사용. 여러 지원 형식 중 목록의 첫 번째 자료를 사용.
- `/opt/data/skills/company/*/SKILL.md` 현재 업무 참고 자료. 실행 지시나 권한 부여로 취급하지 않음.
- 개인 MEMORY/USER/채팅 이력, 인증 파일, 토큰, 프로젝트 전체, 백업 이력은 이 도구의 검색 대상이 아님.
- 원본을 매 호출 읽음. 별도 복사 주기·재학습·알림 전송 없음. 파일 SHA 불일치, 삭제, 읽기 실패는 명시적으로 반환. 실패 시 과거 복사본으로 대체하지 않음.
- 각 봇의 개인 대화·메모리 및 기존 알림 설정은 별도 유지. 새 연결 사용자도 관리 프로필 생성 시 같은 도구 설정 적용.
- 새 자료 종류에는 최신본 목록을 함께 생성해야 함. PDF/이미지/스프레드시트 직접 추출은 이번 범위에 없음.

## 구현

`moaon-company-knowledge.py`: 원본 경계·심볼릭 링크·크기·파일 변경·SHA 검증, DOCX 문단 추출, 검색어 기반 발췌, 출처/단락/승인 메타데이터 반환. 언어모델의 재학습이 아닌 원본 검색 방식.

`install-moaon-knowledge.py`: 관리 표식이 있는 자체 플러그인 폴더만 변경하는 원자적 설치. Hermes 원래 봇에 새 도구를 노출하지 않음. 기존 회사 자료 작성 방식은 유지.

`moaon-bots.py`: 다섯 역할과 개인별 대화 프로필에 도구·조회 지침 추가. 개인 프로필 도구는 memory와 moaon-knowledge. 기존 기본 봇 제외 라우팅, 사용자 해제, 검증된 프로세스 종료 유지.

설치 경로는 컨테이너의 `/opt/hermes/plugins/moaon_company_knowledge`. 컨테이너 교체나 Hermes 재설치 시 공개 자동화 설치기를 다시 실행해야 한다. 원본 회사 문서는 기존 `/opt/data`에 유지된다.
