## 5단계 구현

- 기본은 접힌 요약이며 상세 목록은 높이를 제한하고 스크롤한다.
- 다른 메뉴에서도 전역 진행 안내와 진행 보기 버튼을 제공한다.
- 주문별 승인 대기, 주문 재확인, 상품 준비, 송장 발급, 쇼핑몰 등록, 배송 조회 단계를 표시한다.
- 현재 단계 경과 시간과 마지막 상태 변경 시각을 표시한다.
- 45초간 새 단계/상태가 없으면 응답 확인 중으로 안내하며 실패로 단정하지 않는다.
- 등록 확인, 처리 대기, 결과 미확인, 취소, 미시작을 구분한다. 중간 단계 성공은 전체 등록 완료로 집계하지 않는다.
- 마지막 응답을 받은 시점의 화면 확인이 끝나도 서버 처리 대기 요청은 완료라고 표시하지 않는다.
- 자동/수동 등록에 같은 진행판을 사용하고 로그아웃 시 비운다.
- 기존 발급 횟수, 동시 처리 수, 재시도 정책, 승인 절차는 변경하지 않는다.
