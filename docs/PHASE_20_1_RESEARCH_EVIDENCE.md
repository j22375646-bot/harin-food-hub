# Phase 20-1 · 연구·임상 Evidence

## 목적

선택한 기준상품마다 PubMed 논문 색인과 ClinicalTrials.gov 시험등록 자료를 따로 찾고, 사장님이 선택한 후보만 기존 자료실 Evidence 검수 흐름에 저장한다.

## 공급자 역할

| 공급자 | 사용 범위 | 저장하지 않는 것 |
|---|---|---|
| PubMed E-utilities | PMID, DOI, 학술지, 저자, 자료유형, 발행일 | 논문 원문, 초록, API 키 |
| ClinicalTrials.gov API v2 | NCT 번호, 등록상태, 연구유형, 단계, 조건, 중재, 등록인원 | 연락처, 대상자 정보, 결과의 자동 해석 |
| Crossref REST API | DOI 출판사, 자료유형, 발행일, 인용 메타데이터 | 초록, 원문, 자동 효과 판정 |

## 운영 흐름

1. 시장·전환에서 기준상품 프로젝트를 선택한다.
2. 자료실의 `연구·임상 근거 찾기`에서 상품명, 원료명 또는 학명을 입력한다.
3. 필요한 공급자를 선택하고 수동 확인한다.
4. 공식 원문을 읽어본 뒤 관련 후보만 `근거 후보 저장`한다.
5. 저장된 후보는 `PROXY · OWNER_CONFIRMATION_REQUIRED`로 자료실 검수 흐름에 들어간다.
6. 사장님 확인 전에는 페이지별 AI, 건강표현, 판매문구, 플랫폼 쓰기에 사용하지 않는다.

## 비용과 키

- ClinicalTrials.gov와 Crossref는 이 기능에서 별도 API 키가 필요 없다.
- PubMed도 키 없이 기본 한도로 수동 조회할 수 있다.
- `NCBI_EUTILS_API_KEY`는 호출 한도를 높이는 선택사항이며 Phase 18~21 최종 키 입력 단계까지 비워둔다.
- 모든 키와 개발자 연락용 이메일은 서버 환경변수에만 저장하며 `NEXT_PUBLIC_`을 사용하지 않는다.

## 실패 처리

- 공급자별 요청은 `Promise.allSettled`로 격리한다.
- Crossref 보완이 실패해도 PubMed 후보는 보존한다.
- 자료 없음은 0이나 효과 없음으로 바꾸지 않고 `NO_DATA`로 표시한다.
- 안전 스위치가 꺼진 공급자는 외부 호출 없이 `LOCKED`로 표시한다.
