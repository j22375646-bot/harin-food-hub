# 자동 발급 결과 확인 수정 (0.176.1)

## 실제 기록
2026-09-21 KST. HR-C24-528CDB39, HR-C24-4905086B, HR-C24-ED3E5887은 EPOST_LIVE_ISSUE와 CAFE24_UPLOAD_INVOICE가 모두 SUCCESS. 발급 접수부터 성공까지 약 3~4초, 카페24 등록 약 2~3초. 진단 중 실제 발급/등록 요청은 보내지 않았다.

## 원인과 수정
- 앱이 등록 후 REGISTER 목록만 조회했으나, 카페24 배송중 상태의 주문은 IN_TRANSIT 목록에 속한다. 성공해도 CHECK_REQUIRED로 남는 상황을 재현했다.
- 복구 및 등록 검증에서 IN_TRANSIT/COMPLETED도 확인한다. 같은 주문 지문과 같은 송장번호, 등록 성공 기록 검증을 유지한다. 취소/취소요청은 등록 성공으로 표시하지 않는다.
- 전체 선택 건에 공유하던 60초 제한을 건별 제한으로 바꿨다. 개별 요청 15초 제한과 인증 변경·취소·중복 방지 장부는 유지한다.

## 검증
- 변경 전 배송중 이동 회귀시험 CHECK_REQUIRED로 실패 재현.
- 변경 후 발급/등록·통신·기록 시험 48개 통과. 여러 건 시간 예산, 취소 주문, 응답 유실 재전송 차단 포함.
- 공통 연결 시험 120/121 통과. 기존 preload API 목록 시험은 이번 수정과 무관한 openAssistantBot 누락 때문에 실패. 이 시험/실제 preload는 변경하지 않았다.
- 운영 성공 기록 확인은 API 실행 이력이며 고객 수령/실제 배송 완료를 뜻하지 않는다.
