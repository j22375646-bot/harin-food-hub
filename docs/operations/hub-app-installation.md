# 하린식품 허브 앱 설치

허브의 HTTPS 운영 주소를 브라우저에서 열어 설치합니다. 설치 후에도 기존 로그인과 권한이 적용되며, 브라우저·기기별 저장소 차이 때문에 다시 로그인해야 할 수 있습니다. 설치는 별도 네이티브 프로그램이 아닌 웹앱 창과 실행 아이콘을 추가합니다. 화면과 업무 처리 방식은 기존 허브와 같습니다.

## Windows Chrome·Edge

1. Chrome 또는 Edge에서 허브를 열고 로그인합니다.
2. 주소 표시줄의 설치 아이콘이나 브라우저 메뉴에서 앱 설치 항목을 선택합니다. Chrome은 '페이지를 앱으로 설치', Edge는 '앱 → 이 사이트를 앱으로 설치' 등으로 표시될 수 있습니다. 메뉴 이름은 브라우저 버전에 따라 다릅니다.
3. 이름이 하린식품 허브인지 확인하고 설치합니다. 시작 메뉴에서 실행하고 필요하면 작업 표시줄에 고정합니다.
4. 제거하려면 설치한 앱 창의 메뉴에서 제거하거나 Windows 설정의 설치된 앱 목록에서 하린식품 허브를 제거합니다. 브라우저 데이터 삭제 옵션을 선택하면 로그인·테마 등의 기기 설정도 지워질 수 있습니다.

## 휴대폰 홈 화면

- Android: Chrome에서 운영 주소를 열고 메뉴의 '앱 설치' 또는 '홈 화면에 추가'를 선택합니다. 실행 후 기존 계정으로 로그인합니다. 제거할 때는 홈 화면 아이콘을 길게 눌러 제거/삭제합니다. 바로가기만 추가되는 브라우저도 있습니다.
- iPhone·iPad: Safari에서 운영 주소를 열고 공유 메뉴의 '홈 화면에 추가'를 선택합니다. 기기에서 '웹 앱으로 열기' 옵션이 보이면 활성화합니다. 제거는 홈 화면 아이콘을 길게 눌러 앱 삭제로 진행합니다.
- 앱 내장 브라우저, 시크릿 모드, 관리되는 기기에서는 설치 메뉴나 저장소 사용이 제한될 수 있습니다. 일반 브라우저 탭에서 이용할 수 있습니다. 실제 설치·재실행은 각 기기에서 확인해야 합니다.

## 데이터와 오프라인 한계

주문·매출·고객 데이터와 API 응답, 로그인된 HTML, RSC 응답은 서비스 워커 캐시에 저장하지 않습니다. 캐시에는 개인정보가 없는 `/hub-offline-v1.html` 안내만 들어갑니다. 설치 후 온라인 방문과 브라우저의 자연스러운 워커 활성화가 끝나야 오프라인 안내가 제공됩니다. 최초 방문 또는 저장소 제한·삭제 시에는 브라우저 기본 연결 오류가 나올 수 있습니다.

오프라인 안내는 전체 페이지를 열 때 네트워크 연결이 실패한 경우에만 표시됩니다. 이미 열린 화면이나 화면 내부 이동은 과거에 표시된 내용을 계속 보여 주거나 기존 오류 처리를 따를 수 있습니다. 표시 중인 값을 최신 데이터로 간주하지 말고 연결 복구 후 다시 열어 서버 데이터를 확인합니다. HTTP 401·403·500 응답을 오프라인 안내로 숨기지 않습니다.

배송·환불·기타 변경 작업에는 인터넷 연결과 최신 서버 데이터 확인이 필요합니다. 오프라인 작업 예약이나 연결 후 자동 재실행 기능은 없습니다. 연결이 끊겼다면 기존 작업 결과·이력을 먼저 확인하고 중복 실행을 피합니다. 네이버·쿠팡 등 기존 채널 구분과 실행 안전장치는 유지됩니다.

## 업데이트와 알림

앱이 작업 중 강제로 새로고침되거나 새 서비스 워커로 즉시 전환되지는 않습니다. 업데이트를 적용하려면 작업을 저장하고 처리 결과를 확인한 뒤, 허브 앱 창과 같은 사이트의 브라우저 탭을 모두 닫았다가 온라인 상태에서 다시 엽니다. 필요하면 직접 새로고침합니다. 열려 있는 창이 있으면 새 워커 활성화가 대기할 수 있습니다.

푸시 알림은 아직 활성화되지 않았습니다. 설치 여부가 알림 수신 가능 상태를 뜻하지 않으며 알림 권한을 요청하지 않습니다.

## 개발·검증

- `node scripts/generate-hub-install-icons.cjs`: 저장소의 `app/icon.svg`와 Next에 설치된 sharp로 PNG 192·512·180px을 재생성합니다. 외부 이미지나 새 패키지가 필요하지 않습니다.
- `node --test test/hub-pwa.test.js`: manifest, 이미지 크기, 실제 워커 이벤트, 등록 수명주기, 인증 경계를 검증합니다.
- 서비스 워커는 production에서만 load 이후 idle 또는 지연 타이머로 등록됩니다. 개발 서버에서는 새로 등록하지 않습니다. 같은 origin에 이전 production 워커가 남아 있으면 브라우저 개발자 도구에서 확인합니다.
- 오프라인 안내 수정 시 HTML 파일 이름과 워커 캐시 버전을 함께 올립니다. 이전 버전 안내는 기존 워커를 사용하는 탭을 위해 보존하며, 다른 앱 캐시를 일괄 삭제하지 않습니다.
- 출시에 앞서 production 빌드의 manifest/worker 응답, Windows 설치·제거, Android와 iOS 재실행·로그인, 오프라인 안내, 업데이트 대기와 여러 탭 동작을 실제 기기에서 확인합니다.
