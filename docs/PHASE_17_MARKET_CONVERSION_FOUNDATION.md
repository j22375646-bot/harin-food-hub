# 17단계 시장·전환·재구매 성장센터 기반

- 기준일: 2026-08-17
- 현재 단계: 17-0 기능 보존표·골드셋·디자인 기준
- 원칙: 새 성장센터는 기존 운영 기능을 복제하지 않고, 선택한 상품의 시장 근거와 구매 전환 결정을 연결한다.

## 재사용 가능한 상품 프로젝트

작수차는 첫 검증용 골드셋일 뿐 고정 상품이 아니다. 사용자는 판매 중인 기준상품 가운데 `분석할 상품`을 언제든 선택할 수 있다.

1. 상품을 선택하면 해당 `master_product_id`의 기존 프로젝트를 열거나 새 프로젝트를 만든다.
2. 시장범위, 경쟁근거, 전환 장벽, 실험, AI 분석 버전은 상품별로 격리한다.
3. 다른 상품으로 전환할 때 저장되지 않은 변경이 있으면 경고한다.
4. 템플릿 구조는 복제할 수 있지만 이전 상품의 근거·경쟁사·수치 데이터는 자동 복사하지 않는다.
5. 마지막으로 본 상품은 편의를 위해 기억하되 URL과 저장 키에는 상품 프로젝트 ID를 사용한다.

## 실제 주소

| 화면 | 주소 | 역할 |
|---|---|---|
| 프로젝트 홈 | `/market-intelligence` | 상품 선택, 프로젝트 생성, 최근 작업 |
| 자료실 | `/market-intelligence/[projectId]/data` | 파일, OCR, 출처, 근거 검수 |
| 시장 분석 | `/market-intelligence/[projectId]/market` | 사장님이 승인한 시장범위와 수요 신호 |
| 경쟁 분석 | `/market-intelligence/[projectId]/competition` | 경쟁 상품, 리뷰 불편, 차별화 근거 |
| 구매 전환 | `/market-intelligence/[projectId]/conversion` | 장벽, 상세페이지, 구성, 재구매, 실험 연결 |

## 기존 기능 보존표

| 기존 화면 | 계속 맡는 기능 | 성장센터에서 하지 않는 일 |
|---|---|---|
| 키워드 | 네이버·쿠팡 광고 키워드와 입찰 운영 | 입찰 쓰기 기능을 복제하지 않음 |
| 상품 | 상품 매칭·원가·수수료·실제 이익 | 원가 입력 화면을 복제하지 않음 |
| 주문 | 주문·배송·송장 운영 | 주문 개인정보를 성장센터로 복사하지 않음 |
| 인사이트 | 전체 채널 성과 요약 | 상품별 시장 근거를 한 화면에 섞지 않음 |
| 데이터수집 | API·고정 IP·재시도 | 수집 운영 도구를 복제하지 않음 |
| A/B 테스트 | 실험 계산 | 별도 실험 엔진을 만들지 않음 |
| 실행검증 | 7일·14일 결과 | 검증 결과를 임의 생성하지 않음 |
| 진단목록 | 보고서와 버전 보관 | `family=market-conversion`으로 연결 |

직접 겹치는 `product_growth_profiles`, `product_detail_checklists`만 읽기 호환부터 옮긴다. 행 수 일치, 필드 일관성, 새 화면 저장, 롤백 기간을 모두 통과한 뒤 구 화면만 제거하며 원본 테이블은 즉시 삭제하지 않는다.

## 근거와 표현 안전선

- 근거는 직접 측정, 비교 계산, 대체 지표, OCR 추정, AI 가설로 구분한다.
- OCR 신뢰도 95% 미만 또는 사장님 미확인은 `확인 필요`다.
- 경쟁 불편 근거와 우리 상품 해결 근거가 둘 다 검수돼야 차별화로 표시한다.
- 치료·완치·무조건·부작용 없음·100% 안전·최고·유일 표현은 차단한다.
- 건강 기능 표현은 근거 검수 전까지 `확인 필요`다.
- 없는 시장규모·재구매율·실제 이익은 0이 아니라 `UNKNOWN` 또는 `판단 보류`다.

## 기본 UI 프리셋

- 라벤더·블루·피치·민트 파스텔과 진한 네이비 글자
- 기본 본문 16px 이상, 보조글 14px 이상, 입력·버튼 15px 이상
- 클릭·터치 영역 48px 이상
- 대표 행동과 주요 구분에는 픽토그램 사용
- 초록색은 정상·성공 상태에만 사용
- 페이지별 AI는 합치지 않고 기본 접힘
- 모바일은 하단 고정 메뉴와 카드형 상세, PC는 표와 오른쪽 상세 패널
- 과도한 움직임을 피하고 `prefers-reduced-motion`을 지원

## 작수차 골드셋

작수차의 30·90·150개 구성은 첫 구현을 검증하는 예제다. 시장규모·재구매율·실제 이익은 실제 근거가 들어오기 전까지 `UNKNOWN`이다. 동일한 검증을 다른 판매 중 상품에도 그대로 실행할 수 있어야 17-0을 통과한다.
