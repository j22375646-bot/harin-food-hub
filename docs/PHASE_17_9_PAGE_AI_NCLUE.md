# 17-9 페이지별 독립 AI와 NCLUE 준비도 파일럿

- 기준일: 2026-08-17
- 목적: 선택 상품의 네 작업공간을 서로 섞지 않는 AI 입력 계약으로 고정하고, 외부 AI 사용 전 서버 미리보기와 NCLUE 연동 준비 조건을 검증한다.

## 페이지별 AI 계약

| 작업공간 | 분석 종류 | 사용하는 자료 |
|---|---|---|
| 자료실 | `MARKET_DATA_AI` | 출처·OCR 검수·검증 Evidence 집계 |
| 시장 분석 | `MARKET_SCOPE_AI` | 시장범위·리뷰 표본·페르소나 집계 |
| 경쟁 분석 | `MARKET_COMPETITION_AI` | 경쟁상품·리뷰 불편·확정 소구점 집계 |
| 구매 전환 | `MARKET_CONVERSION_AI` | 채널 흐름·구매장벽·성장 가설·승인 실행계획 집계 |

모든 입력은 `project_id`와 `master_product_id`를 함께 저장한다. 같은 화면 구조를 재사용해도 다른 상품의 Evidence와 결과는 복사하거나 조회하지 않는다.

## 현재 운영 모드

- `OPENAI_ANALYSIS_ENABLED`는 사용 전 상태를 유지한다.
- 화면을 열 때 외부 AI를 호출하지 않고 서버 집계로만 미리보기를 만든다.
- 미리보기 저장 비용은 0원이며 고객명·연락처·주소·이메일·주문번호를 포함하지 않는다.
- AI 역할은 관찰·영향·근거·추천 설명이며 가격·광고·재고·주문과 플랫폼 쓰기를 실행하지 않는다.
- 부족하거나 오래된 자료는 0으로 채우지 않고 `BLOCKED` 또는 판단 보류로 표시한다.

## NCLUE 파일럿 범위

NCLUE는 소비자용 챗봇이 아니라 기업 보유 행동 데이터 기반의 CRM 예측 연동 후보로 다룬다. 현재 단계는 실제 고객 세그먼트 생성이나 API 연동이 아니라 다음 다섯 조건의 준비도만 확인한다.

1. 행동 이력 90일 이상
2. 재구매 간격 표본 3개 이상
3. 마케팅 수신 동의 근거
4. 개인정보·법적 적합성 검토
5. 계약·비용·API 연동 범위 승인

카페24 고객과 네이버 사용자를 결합하거나 재식별하지 않는다. 화면에는 집계 숫자만 표시하고 개별 고객 목록과 자동 캠페인 실행은 만들지 않는다.

## 완료 기준

- [x] 상품 프로젝트와 Evidence가 DB 제약으로 격리된다.
- [x] 기본 접힘 상태에서 열 때만 현재 서버 집계를 읽는다.
- [x] OpenAI 호출 없이 관찰 → 영향 → 추천 미리보기를 확인하고 저장한다.
- [x] 구매 전환 화면의 NCLUE는 준비도 파일럿으로만 표시된다.
