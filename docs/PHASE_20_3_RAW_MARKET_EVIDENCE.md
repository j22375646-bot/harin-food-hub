# Phase 20-3 · 원재료·시장환경 공식 근거

## 목적

선택한 기준상품별로 원재료 수급과 시장환경을 설명할 때 참고할 공식 자료를 서로 섞지 않고 확인한다.

- 관세청 품목별 국가별 수출입실적: HS 코드·국가·월별 통관량과 금액
- 한국수출입은행 환율정보: 기준일별 공식 환율
- KOSIS 국가통계포털 통합검색: 관련 공식 통계표 후보

세 공급자의 값은 하린식품의 실제 매입량, 계약환율, 원가, 판매량 또는 미래 수요를 직접 증명하지 않는다. 저장할 때도 `PROXY`와 `OWNER_CONFIRMATION_REQUIRED` 상태를 유지한다.

## 운영 흐름

1. 시장·전환의 시장 화면을 연다. 이때 외부 API는 호출하지 않는다.
2. 대표 원재료·HS 코드·상대국·기간을 확인한다.
3. 필요한 공급자만 선택하여 수동 조회한다.
4. 공급자별 성공·자료 없음·설정 필요·오류를 따로 표시한다.
5. 공식 원문을 확인한 후보만 선택 상품의 Evidence 자료실에 저장한다.

한 공급자가 실패해도 다른 공급자의 성공 결과와 기존 저장 근거는 유지한다. 자료 없음은 0 또는 영향 없음으로 바꾸지 않는다.

## 서버 설정

API 키는 모두 서버 환경변수로만 보관한다. Phase 18~21 최종 키 입력 단계 전까지 UI에는 `마지막에 키 연결`로 표시한다.

- `KCS_TRADE_ENABLED`, `DATA_GO_KR_SERVICE_KEY`
- `KOREA_EXIM_FX_ENABLED`, `KOREA_EXIM_API_KEY`
- `KOSIS_MARKET_ENABLED`, `KOSIS_API_KEY`

## 안전 기준

- 고객 개인정보를 외부 공급자에 보내지 않는다.
- 외부 호출은 사장님이 조회 버튼을 눌렀을 때만 실행한다.
- 비밀키가 포함된 요청 주소를 브라우저·DB·로그에 저장하지 않는다.
- 공식 원문 호스트만 저장 후보로 허용한다.
- 국가표준식품성분표는 상업적 이용·변형 범위 검토 전 자동연결 대상에서 제외한다.
