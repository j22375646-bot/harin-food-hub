# 17-10 정리·모바일·성능·실패 격리

## 적용 내용

- 시장·전환 셸이 서버에서 만들어진 화면을 즉시 보여주며, hydration 전용 전체 로딩 화면으로 다시 덮지 않습니다.
- 구매 전환의 핵심 분석만 먼저 불러오고 성장 흐름과 실행 연결은 사장님이 열 때 동적으로 로드합니다.
- 상품 기준선, 자료실, 시장, 경쟁, 전환, 성장, 실행 작업은 15초 타임아웃과 화면 이동 취소를 지원합니다.
- 작업 하나가 실패하면 해당 카드에서만 쉬운 오류와 `다시 불러오기`를 표시합니다.
- 예상하지 못한 시장·전환 경로 오류는 전용 오류 경계에서 격리하며 다른 운영 화면과 저장 자료는 유지합니다.
- 모바일 분석 단계는 세로로 길게 쌓지 않고 가로 스크롤 카드로 표시합니다.

## 실패 주입 기준

- HTTP 오류와 잘못된 JSON은 원문 HTML을 노출하지 않습니다.
- 장기 응답은 무한 대기하지 않고 타임아웃 후 재시도를 제공합니다.
- 화면을 이동하면 이전 요청을 취소하여 늦은 응답이 새 화면을 덮지 않게 합니다.
- 페이지별 AI는 기존처럼 각 페이지에 따로 남고, `OPENAI_ANALYSIS_ENABLED`가 꺼진 동안 외부 호출을 하지 않습니다.
