        상품별 재고·입고 계획
        예상 수량은 어떻게 계산하나요?

        하루 평균 판매 = 최근 30일 판매 ÷ 30. 30일 뒤 예상 잔량과 소진 시점은 마지막 수집 시점부터 같은 판매 속도가 유지되고 추가 입고가 없다는 가정입니다. 목표 보충량 = 목표일 판매 예상량 − 현재 재고(올림, 최소 0개). 판매 0개·자료 누락·갱신 필요 상품은 예측을 보류합니다. 쿠팡에 실제 입고를 신청하거나 재고를 변경하지 않습니다.

        주문 자동 차감연동 상품은 기본 1개씩 · 여러 개입만 변경하세요.

        상품 · 제조번호보유 수량제조일 · 유통기한보관방법기한 상태

        주문 자동 차감 · 세트 구성

        기본은 주문 1개당 재고 1단위입니다. 3개입을 주문 수량 2개로 구매하면 3 × 2 = 6개를 차감합니다.

        차감 이력 · 확인할 주문 (최근 100건)

        저장 이후의 새 주문부터 적용합니다. 이미 차감한 주문은 다시 차감하지 않습니다. 유통기한이 빠른 재고부터 사용하며 부족하면 차감을 보류합니다. 취소·반품·수량 변경은 실물 확인 후 재고 페이지에서 입고/출고로 조정하세요. 상품 연결은 다른 단위나 서로 다른 구성품을 자동 환산하지 않습니다.

            주간 보고서와 중요한 이상 징후를 휴대폰에서 받도록 연결할 수 있습니다. 앱이 꺼져 있어도 서버에서 실행합니다.

            봇 연결 준비 방법
            1. 텔레그램의 공식 @BotFather에서 /newbot으로 봇을 만듭니다.
            2. 받은 봇 토큰은 채팅이나 앱 메모에 붙여 넣지 말고 서버 비밀 설정에 보관합니다.
            3. 사용할 봇 대화에서 시작을 누르고, 알림을 받을 대화를 정합니다.
            4. 서버의 봇·수신 채팅 설정과 발송 사용 설정을 마친 뒤 실제 수신을 확인합니다.

            현재 화면은 설정 상태만 조회합니다. 실제 연결과 발송 설정은 아직 이 화면에서 변경할 수 없습니다. 텔레그램 조회 명령은 후속 기능입니다.
