          플랫폼 API 연결

          사업장별 설정

          하린식품은 현재 서버의 인증정보를 계속 사용합니다. 키 원문을 앱으로 복사하거나 다시 입력할 필요가 없습니다.

          Cafe24·네이버·쿠팡·우체국의 개별 키 등록 상태와 유효성 검사는 아직 이 화면에 연결되지 않았습니다.

          소유자 사업장은 서버 저장 상태를 확인하고 키를 저장할 수 있습니다. 서버 준비와 별도 플랫폼 인증이 필요하며, 저장만으로 주문 수집이 시작되지 않습니다.

          키 원문은 저장 후 다시 표시하지 않습니다. PC 암호화 저장은 이 PC에만 보관됩니다.

          서버 API 설정

          먼저 현재 저장 상태를 조회하세요. 조회와 저장은 각각 요청 한도를 사용합니다.

          서버에 이 설정을 저장할까요?

          기존 서버 설정이 있으면 입력한 값으로 교체합니다. 저장 후에도 플랫폼 인증과 실제 연결 검증이 필요합니다.
